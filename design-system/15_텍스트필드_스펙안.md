# TextField 스펙안 (제안, 피그마 작업 전)

`14_텍스트필드_조사.md`의 조사와 2026-10-16 결정을 바탕으로 한 스펙입니다. 5절의 ⚑ 7개는 2026-10-16 모두 추천대로 확정했습니다.

- 기준일: 2026-10-16
- 범위: 한 줄 입력창. 여러 줄 입력(textarea), 드롭다운, 글자 크기 숫자 칸(편집 도구의 보여 주기용 칸)은 넣지 않습니다.
- 입력창 안의 버튼은 `IconButton`을 넣어 씁니다(새로 그리지 않음).

## 1. 종류와 상태 나누기

| 구분 | 무엇 | TextField에서 |
|---|---|---|
| 크기 | 높이·여백·글자가 함께 바뀜 | `Size` (Variant) |
| 상호작용 상태 | 마우스 올림, 입력 중(포커스) | `State` (Variant). 코드에서는 브라우저가 정함 |
| 결과 상태 | 오류, 성공 | `State` (Variant). 코드에서는 Prop |
| 쓸 수 없음 | 비활성 | `State` (Variant). 코드에서는 Prop |
| 내용 | 비어 있음(안내 문구) / 입력됨(입력값) | `Value` (Variant). 글자색이 다름 |
| 붙는 요소 | 제목, 필수 표시, 아래 문구, 앞 아이콘, 뒤 버튼 | 켜고 끄기(Boolean) |

- 조사 때의 "입력 중(Typing)"은 `State=Focus` + `Value=Filled` 조합이라 따로 만들지 않습니다.
- 크기와 상관없는 것(색, 상태 표현, 붙는 요소)은 모든 크기에서 같게 합니다.

- Variant 수: Size 4 × State 6 × Value 2 = **48개**(모든 조합).
- 크기 이름은 Button과 같습니다(높이도 같음: 32·40·48·52). 입력창 옆에 같은 높이 버튼을 붙일 때(예: 이메일 + 중복확인) 같은 이름을 고르면 됩니다.
- 기본 크기 `Small`(40)은 Button 기본값과 같습니다.
- 뒤 아이콘은 처음에 IconButton을 통째로 넣었다가, 입력칸 안 버튼이 전체 화면에서 비밀번호 보기 한 종류(Plain·회색·24)뿐이라 켜고 끄기 + 아이콘 교체만 남겼습니다(2026-10-16). IconButton의 Style·Size·Icon Color·Floating 선택지는 입력칸 안에서 쓰지 않습니다.

## 7. 아이콘 크기·뒤 아이콘 정리와 Variant 완성 (2026-10-16)

- **아이콘은 모든 크기 24 하나**(`Size/Icon/Medium`). 입력칸 안 아이콘은 48·52에만 쓰이고(검색 2곳, 비밀번호 보기 5곳) 40·32에는 없어서, 크기별 아이콘을 미리 그리지 않습니다. 근거: Material은 24 하나, Carbon은 모든 크기 16 하나, SF Symbols는 글자 크기를 따라감. 작은 입력칸에 아이콘이 실제로 필요해지면 그때 그 크기만 그립니다.
- **뒤 아이콘:** `Trailing Button`(IconButton 통째) → `Trailing Icon`(켜고 끄기) + `Trailing Icon Swap`(추천 `VisibilityOff`, `Visibility`). 앞 아이콘 추천은 `Search`.
- **글자:** Pretendard를 불러올 수 있음을 확인하고 Text Style을 직접 적용(칸 안 XSmall `13/Medium`, Small `14/Regular`, Medium·Large `15/Regular`, 제목 `15/SemiBold`, 필수 `14/Regular`, 문구 `12/Regular`).
- **세트:** `TextField`(node `188:16373`, key `3bacaf49170cda62bfa0bf99c0ef06970f5e4dba`) 48 Variant. 패널 순서 Size `XSmall/Small/Medium/Large`, State `Default/Hover/Focus/Error/Success/Disabled`, Value `Empty/Filled`. 기본값 `Small/Default/Empty`(왼쪽 위). 배치: 줄 = Small·XSmall·Medium·Large × Empty·Filled, 칸 = State.
- **커서:** `Focus`에만 보임. Empty는 안내 문구 앞, Filled는 입력값 뒤. 두께 `Size/Border/Default`, 높이 `Font/LineHeight/{글자 크기}`.
- **검사:** 원시 색·여백 0, 이름 중복 0, 모든 글자 Text Style 연결, 속성 참조 끊김 0. 스크린샷으로 확인.

  - `edit_focused`·`edit_typing`: TextField `XSmall/Focus`(210) · 간격 `Spacing/Scale/8` · IconButton Outline 24 확인(`Check` 20) · 8 · 취소(`Close` 20) = 274×32.
