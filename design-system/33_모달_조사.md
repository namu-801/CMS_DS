# Modal 조사 (결정 전, 조사 결과만)

화면 위에 떠서 입력을 받거나 결과를 알리는 팝업을 조사했습니다.

- 기준일: 2026-10-26
- 조사 범위: 시안 화면의 외부 라이브러리 `Modal-topbar`(머리), `Modal/Btn`(하단 버튼), `Popup_btn`·`popup/LNB`(팝업 왼쪽 메뉴), 일반 프레임으로 그린 확인 모달(`Modal_Warning` 등), 로컬 가이드 프레임 `WSG_Layout_Popup`(node `53:21562`).

## 1. 우리 시안의 팝업

### 1-1. 두 종류

| 종류 | 쓰이는 곳 | 크기 | 구성 |
|---|---|---|---|
| **입력 팝업** | 콘텐츠 업로드(12화면), GPS·시간·조건 설정, 차량 등록 | 대 1100×700, 중 680×480, 소 400×480(가이드 이름: 팝업_대·팝업_소) | 보라 머리(제목) + 본문 + 하단(위 선, 오른쪽 "취소"·"저장") |
| **확인 모달** | 삭제 확인, 저장 완료·실패, 인증 메일 재발송 | 너비 400 고정, 높이 최대 370(가이드) | 상태 그림 48 + 제목 + 설명 + 가운데 버튼 1~2개. 한 시안은 오른쪽 위 닫기(×) |

- `Modal-topbar` 39개 · 20화면, `Modal/Btn`은 4개(대부분의 팝업은 하단 버튼을 직접 그림).
- 팝업 뒤는 검정 40% 덮개(`dimmed`, `#000000` 40%). 시맨틱 `Surface/Dim/Primary`는 `#111111` 40%.
- 콘텐츠 업로드 팝업에는 왼쪽 메뉴(`popup/LNB` + `Popup_btn` 71개 · 12화면)가 있습니다.

### 1-2. 입력 팝업 모양

| 부분 | 값 |
|---|---|
| 머리 | 높이 56, 배경 `#7778FD`, 제목 흰색 `20/Medium`, 좌우 여백 24. **닫기 버튼 없음** |
| 본문 | 좌우 여백 40, 위 32(소 기준), 제목+입력칸 묶음 간격 20 |
| 하단 | 위 선 `#D6D6D6` 1, 버튼 오른쪽 정렬, 여백 위 12·오른쪽 40·아래 20, 버튼 간격 16. 버튼은 외부 `btn-fill-gray-xs`("취소", `#494949`)·`btn-fill-purple`("저장", `#7778FD`) 100×42 |
| 상자 | 흰색, 모서리 0, 그림자 없음 |

### 1-3. 확인 모달 모양

| 부분 | 값 |
|---|---|
| 상태 그림 | 48(경고: 노란 원 + 느낌표, 성공: 초록 체크, 실패: 빨간 ×). 아이콘 세트 `Pictogram/Status/Warning`·`Success`·`Error` 48과 같은 역할 |
| 제목 | `#2D2D2D` `22/SemiBold`, 가운데 |
| 설명 | `#767676` `16/Regular`, 가운데, 여러 줄 |
| 버튼 | 가운데, 1개("확인") 또는 2개("취소" + "삭제"·"다시시도"), 100×42 |
| 여백 | 위 36, 좌우 70(글자 폭 260), 그림↔제목 20, 제목↔설명 4, 설명↔버튼 36, 아래 24 |
| 삭제 확인 | "삭제" 버튼이 **보라**(`btn-fill-purple`) |

### 1-4. 관찰된 특징 (아직 판단하지 않음)

- 입력 팝업에 닫기(×)가 없어 "취소"로만 닫습니다.
- 머리 제목 흰색 / `#7778FD`는 **대비 3.57**(20 Medium은 큰 글자 기준에 들지 않아 4.5:1 필요).
- 하단 버튼 높이 42는 우리 Button 크기(32·40·48·52·56)에 없습니다.
- 삭제 확인의 "삭제"가 보라입니다. Button 계약은 "삭제를 최종 확인하는 모달 버튼"에 `Destructive`(빨강)를 쓰기로 정했습니다.
- 하단 버튼 묶음을 컴포넌트(`Modal/Btn`)로 쓴 곳이 4곳뿐이고 나머지는 직접 그렸습니다.
- 본문은 팝업마다 다름(입력 폼, 지도 + 목록, 표).

## 2. 시중 디자인 시스템

| 항목 | Material 3 | Apple HIG | shadcn/ui |
|---|---|---|---|
| 이름 | Dialog(기본·전체 화면) | Alert, Sheet | Dialog, AlertDialog |
| 구성 | 아이콘(선택) · 제목 · 내용 · 버튼(오른쪽) | 제목 · 메시지 · 버튼(1~3개) | 머리(제목·설명) · 내용 · 하단 버튼, 오른쪽 위 닫기 |
| 닫기 | 버튼, 바깥 누르기, 뒤로 | 버튼 | ×, Esc, 바깥 누르기(AlertDialog는 버튼으로만) |
| 위험 동작 | 버튼 글자색 | 빨간 "삭제"(destructive) 버튼 | `destructive` 버튼 |
| 접근성 | 포커스를 대화상자 안에 가둠 | — | `role="dialog"`/`alertdialog`, 제목·설명 연결, 포커스 가둠, 닫으면 원래 자리로 |

**공통점:** 위험한 동작은 빨간 버튼으로 구분하고, 대화상자가 열린 동안 포커스를 안에 가두며, Esc로 닫을 수 있습니다. 확인용(Alert)은 버튼으로만 닫습니다.
