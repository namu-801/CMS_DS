## 2. 만들 때 결정해야 할 항목 (모든 컴포넌트 공통)

1. **이름과 Variant 속성 규칙**: 지금 라이브러리는 `Property 1=pressed`, `Component 79`, `large/fill/purple/default/xs`처럼 규칙이 섞여 있습니다. 예: `Button` / `Style=Primary, Size=M, State=Default`.
2. **크기 단계**: Foundation의 `Size/Height/Control*`(32·40·48·52)과 `Bar`(56)에 맞출지.
3. **상태(State) 목록**: Default, Hover, Pressed, Disabled, Focused, Error, Selected 중 컴포넌트마다 무엇을 둘지.
4. **아이콘 처리**: 아이콘 자리는 Instance swap 하나로 두고, 왼쪽·오른쪽 표시는 켜고 끄는 속성으로 둘지.
5. **토큰 연결 범위**: 색(Semantic), 간격·모서리·선 두께(Foundation), 글자(Text Style)를 모두 연결. 스케일 밖 값(간격 5, 3 등)은 반올림 규칙 적용.
6. **기존 라이브러리와의 관계**: 기존 컴포넌트를 고쳐서 쓸지(화면 연결 유지), 새로 만들어 화면을 바꿔 끼울지.
7. **글꼴 제약**: 이 작업 환경에서는 Pretendard를 불러올 수 없어서 새 텍스트 레이어를 만들거나 글자를 바꿀 수 없습니다. 기존 텍스트를 복제해서 쓰거나, 데스크톱 앱에서 처리해야 합니다.
