# IconButton 조사 (결정 전, 조사 결과만)

아이콘만 있고 글자가 없는 버튼을 조사했습니다. 글자가 있는 버튼은 `Button`(확정, `10_버튼_계약.md`)이 맡습니다.

- 조사 범위: 시안 화면의 인스턴스(외부 라이브러리), 로컬 컴포넌트 세트(`Button`, `Icon/Image button`, `Map` 프레임)
- 라디오·체크(`btn-radio`, `btn-check`)는 이름에 btn이 있지만 선택 컨트롤이라 제외했습니다.

## 1. 우리 시안의 아이콘 버튼

조사 방법(2026-10-08 다시 검토): 이름이 아니라 **모양**으로 찾았습니다. 화면 70개에서 16~60px 정사각형에 아이콘이 있고 글자가 없는 요소를 모두 모은 뒤, 클릭되는 것만 남겼습니다. 컴포넌트가 아닌 일반 프레임(텍스트 편집 도구 등)도 포함합니다.

### 1-3. 로컬 세트에만 있는 것 (시안 화면은 일반 프레임으로 따로 그림)

| 컴포넌트 | 대응하는 화면 요소 | 상태 |
|---|---|---|
| `Quantity Input button`(+/−, 40×40) | 텍스트 편집 도구의 글자 크기 −/+ | default, hover(배경 `#F1F3F6`·선 `#A3A3A3`), disabled |
| `Iconbtn_xxs`(40×40) | 텍스트 편집 도구의 정렬 버튼 | default, hover(선 `#7778FD`), selected(배경 `#F3F3FF`·선 `#7778FD`·아이콘 `#5D5FEF`), disabled |

### 1-4. 아이콘 버튼이 아닌 것 (확인 후 제외)

- 행의 수정·삭제 아이콘(`ic-edit-20-*`, `ic-delete-20-*`)과 « » 화살표(`ic-double arrow`): 글자 버튼(`btn-edit-h48`, "콘텐츠 추가" 등) 안에 든 아이콘입니다. 지난번 표에서 잘못 넣어서 뺐습니다.
- 라디오·체크, 상태 아이콘(성공·실패·경고), 콘텐츠 타입 아이콘, 좌측 메뉴 아이콘, 경로 구분 화살표, 드롭다운 화살표: 버튼이 아니거나 다른 컴포넌트의 일부입니다.

### 1-5. 관찰된 특징 (아직 판단하지 않음)

- **틀 크기:** 20, 24, 40, 48 네 가지입니다. 48은 40짜리 원본을 늘려서, 테두리가 0.83px로 얇아졌습니다.
- **클릭 영역이 작음:** 20·24 버튼과 틀 없는 아이콘(약 160곳)이 최소 클릭 영역 32보다 작습니다. 가장 많은 것은 목록 펼치기 65곳, 상단 바 64곳입니다.
- **선택(켜짐) 상태가 두 종류:**
  - 하나만 고르는 묶음(가로 정렬, 세로 정렬)
  - 여러 개를 켜고 끄는 것(굵게·기울임·밑줄, 지도 위치 추가 모드)
- **선택 표시 방식:** 텍스트 편집 도구는 배경 `#F3F3FF` + 보라 선입니다. 지도 Pin은 배경이 흰색으로 바뀌면서 아이콘 모양까지 바뀝니다.
- **hover 표현이 세 가지로 섞임:** 배경이 진해짐(입력창 안), 아이콘이 옅어짐(지도), 선이 보라로 바뀜(로컬 정렬 세트). 텍스트 편집 도구는 시안에 hover가 없습니다.
- **같은 기능이 두 방식:** 텍스트 편집 도구는 로컬 컴포넌트(`Iconbtn_xxs`, `Quantity Input button`)가 있는데도 화면에서는 일반 프레임과 벡터로 다시 그렸습니다.
- **아이콘 색이 제각각:** 기본 상태 아이콘이 `#767676`, `#A3A3A3`, `#2D2D2D`로 섞여 있습니다.
- **비활성:** 입력창 안 확인·취소, 로컬 세트에만 있습니다.
- **모양:** 대부분 직각이고, 지도 컨트롤만 모서리 2와 그림자가 있습니다.
- **토큰 밖 색:** `#5F60CA`(Pin hover), `#F1F3F6`(로컬 수량 hover)
- **모달 상단바에 닫기 버튼 없음:** 닫기는 하단 "취소" 버튼으로 합니다.

## 2. 시중 디자인 시스템의 아이콘 버튼

| 항목 | Material 3 | Apple HIG | shadcn/ui |
|---|---|---|---|
| 부르는 이름 | Icon button (FAB는 별도 컴포넌트) | 아이콘·심볼 버튼. macOS는 Image button, Square button | 별도 컴포넌트 없음. `Button`의 `size="icon"` |
| 종류(스타일) | Standard, Filled, Filled tonal, Outlined | 일반 버튼과 같은 스타일(bordered, borderless 등) | Button과 같음: default, secondary, outline, ghost, destructive, link |
| 유형 | Default(누르기), Toggle(켜기/끄기) | 누르기 버튼, 토글처럼 동작하도록 설정 가능(Square·Image button). 토글은 별도 Toggle 컴포넌트 | 토글은 별도 `Toggle`·`Toggle Group` 컴포넌트 |
| 크기 | Extra small, Small(기본), Medium, Large, Extra large (문서에 dp 값 없음) | visionOS: Mini 28, Small 32, Regular 44, Large 52, Extra large 64 | `icon-xs` 24, `icon-sm` 32, `icon` 36, `icon-lg` 40 |
| 너비 | Narrow, Default(정사각), Wide | — | 정사각 |
| 모양 | 둥근형·사각형. 누르거나 선택하면 모양이 바뀜 | 아이콘만 있는 버튼은 원형 권장(visionOS) | 둥근 모서리(`icon-xs`는 `rounded-md`) |
| 상태 | 기본, hover, focus, pressed, disabled + 토글은 selected / unselected | hover 시 툴팁(macOS·visionOS), 토글 상태는 다른 모양으로 구분 | hover, focus-visible(포커스 링), disabled, aria-invalid |
| 선택 표시 | 선택 안 됨은 선 아이콘, 선택됨은 채운 아이콘 | 토글 상태마다 다른 모양 | Toggle의 `data-state=on` |
| 최소 터치 영역 | 48dp | 44×44pt(visionOS 60×60) | 규정 없음 |
| 이름(접근성) | `contentDescription` 필수(스크린리더용) | 목적이 분명한 익숙한 아이콘을 쓰고, 글자가 더 분명하면 글자를 쓰라고 안내 | 문서 예시에서 `aria-label`·숨김 글자로 이름을 줌 |
| 툴팁 | — | macOS·visionOS는 hover 시 시스템 툴팁 | 별도 `Tooltip` 컴포넌트와 함께 씀 |
| 묶음 | Button group(연결형) | — | `Button Group` |

### 2-1. 상태 표현 방식 (2026-10-09 추가)

| 상태 | Material 3 | Apple HIG | shadcn/ui (실제 코드) |
|---|---|---|---|
| 기본 이름 | Enabled | 기본(Idle) | 기본 |
| 마우스 올림 | Hovered: 아이콘 색을 8% 덮는 상태 레이어(배경이 살짝 진해짐) | 마우스·시선을 올리면 강조 표시(macOS·visionOS), 툴팁 | `hover:bg-accent`(배경이 바뀜, 아이콘은 그대로) |
| 키보드 포커스 | Focused: 12% 레이어 + 포커스 링 | 포커스 링 | `focus-visible:ring-[3px]` |
| 누름 | Pressed: 12% 레이어 | 누른 상태 표시 필수 | (브라우저 기본, 별도 지정 없음) |
| 선택(켜짐) | Selected: 채운 아이콘·컨테이너 색 변경(Toggle 유형) | 토글은 다른 모양으로 구분 | `Toggle`의 `data-[state=on]:bg-accent`(배경이 바뀜) |
| 비활성 | Disabled: 아이콘 38% 불투명, 컨테이너 12% | 흐리게 표시 | `disabled:opacity-50` |

**공통점:**
- hover·pressed는 **배경(레이어)이 진해지는** 방식이고, 아이콘을 옅게 만드는 방식은 세 시스템 모두 없습니다.
- 아이콘이 옅어지는 것은 비활성(Disabled) 표현입니다.

## 3. 시중에는 보통 있는데 우리 시안에 없는 것

| 항목 | 시중 | 우리 시안 |
|---|---|---|
| 접근 가능한 이름(aria-label) 규칙 | 세 시스템 모두 필요 | 없음. 아이콘만 있어서 스크린리더가 읽을 이름이 없음 |
| 툴팁 | Apple 기본, shadcn은 Tooltip과 함께 | 없음 |
| 포커스 상태 | 세 시스템 모두 | 없음 |
| 하나로 정한 크기 체계 | 3~5단계 | 20, 24, 40, 48이 따로 정해짐 |
| 최소 터치 영역 | 48dp / 44pt | 20·24 버튼과 틀 없는 아이콘(약 160곳)이 미달 |
| 스타일 체계 | Standard·Filled·Tonal·Outlined / Button과 같은 variant | 채움(Pin), 선(지도·순서 이동·닫기), 배경 없음(입력창 안)이 이름 없이 섞여 있음 |
| 토글 규칙 | Toggle 유형 또는 별도 Toggle 컴포넌트, 선택 시 채운 아이콘 | 지도 Pin(Pressed), 정렬 선택(selected)이 서로 다른 방식 |
| 일관된 hover | 배경이 진해지는 방식 | 세 가지가 섞임. 지도 확대·축소·현재 위치의 Hover는 아이콘이 옅어지는데, 시중 기준으로는 비활성 모양(정의 오류로 보임) |
| 버튼 틀(클릭 영역) | 아이콘보다 큰 틀이 항상 있음 | 틀 없이 아이콘만 놓인 곳이 약 160곳 |
| 선택 묶음(하나만 고르기) | Material Button group·Toggle group, shadcn Toggle Group | 정렬 버튼이 묶음처럼 보이지만 규칙 없음 |
