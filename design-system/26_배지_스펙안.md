## 1. 종류와 상태 나누기

| 조사에서 나온 차이 | 종류인가 상태인가 | 이유 |
|---|---|---|
| 태그 / 알약 / 상태 글자 | **종류 → 컴포넌트 셋** | 모양(모서리·점·배경 유무)과 쓰는 곳(분류 / 운행 상태 / 처리 결과)이 다름 |
| GPS·시간·반복·반복 안 함 | **종류 → 태그 `Type`** | 같은 모양에 색과 아이콘만 다름 |
| 운행중·운행종료, 성공·실패 | **종류 → 상태 값** | 데이터 값에 따라 정해짐. 사용자가 바꾸는 상태가 아님 |
| GPS 태그 연함 / 채움 | 같은 뜻의 두 모양 ⚑ B | 하나로 합침 |
| 마우스 올림·비활성 | 해당 없음 | 누르지 않음 |

## 2. Component property

### 2-1. `Tag` (분류 태그)

| 속성 | 타입 | 값 | 기본값 |
|---|---|---|---|
| `Type` | Variant | `GPS`(초록·위치 아이콘), `Time`(보라·시계), `Repeat`(회색·반복), `RepeatOff`(회색·반복 안 함) | `GPS` |
| `Text` | Text | 글자 | `GPS` |

- 처음에는 `Color`(3색) + 아이콘 바꿔 끼우기(Instance swap)로 제안했지만, Figma에서 아이콘을 바꿔 끼우면 덮어쓴 아이콘 색이 따라오지 않아(새 아이콘의 기본 색 `#2D2D2D`로 돌아감) 시안의 쓰임 4가지를 `Type`으로 바로 고르게 바꿨습니다(2026-10-26, ⚑ F).
- 아이콘은 항상 있음. 켜고 끄는 속성은 만들지 않음.

## 8. 종류별 기본 글자 (2026-10-27)

- `Status Text`·`Status Badge`·`Event Label`은 글자 속성(`Text`)을 없애고 종류마다 기본 글자를 둠: 성공/실패, 운행중/운행종료, 위험/경고/주의. 종류를 바꾸면 글자도 같이 바뀜(시험 완료). 글자는 캔버스에서 바로 고침.
- 글자를 직접 고친 인스턴스(예: "다운로드 성공")는 종류를 바꿔도 고친 글자가 남음(Figma 기본 동작) → 글자도 같이 고쳐야 함.
- `Tag`와 `Count Badge`는 글자를 매번 직접 쓰므로 글자 속성을 그대로 둠.
