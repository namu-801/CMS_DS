# PBV 관제 시스템 — 시안에서 쓰이는 값 인벤토리

- 원본: Figma `CMS_DesignSystem` (Page 1 한 페이지)
- 성격: **있는 값을 그대로 적은 목록**입니다. 이름은 붙이지 않았고, 값을 합치지도 않았으며, Figma 변수도 만들지 않았습니다(읽기 전용 조회만 수행).
- 용어: "횟수"는 해당 값이 쓰인 레이어 수, "화면"은 그 값이 등장한 화면(최상위 프레임) 수입니다.
- "쓰인 곳"은 레이어·컴포넌트 이름에서 뽑았습니다. `A<B`는 B 안의 A를 뜻합니다.
- "연결된 기존 스타일"은 시안 파일에 **이미 연결돼 있던 외부 라이브러리 스타일명을 원문 그대로** 옮긴 것입니다. 제가 새로 붙인 이름이 아닙니다. 비어 있으면 스타일 연결 없이 값을 직접 입력한 것입니다.

### 이상 징후(확인 필요)
- **`Select mode`, `Edit mode`, `Save default mode`**(220×220 인스턴스)가 스타일 연결 없는 `#9747FF` 보라(stroke 33, fill 투명도 0.2, text 15)를 씁니다. Figma 기본 보라와 같아서, 실제 제품 값인지 작업용 표시인지 확인이 필요합니다.
- **`.anno_i_717:1446_1`**(번호 핀)은 Inter 폰트, `#F64C4C`, 그림자 r16을 씁니다. 주석성 요소로 보입니다.
- **비정수 값**은 `차량관리_리스트뷰`와 `차량관리_차량 상세`에 몰려 있습니다. 글자 크기 9.46·9.2·12.48, 모서리 4.96·2.32·1.35·1.31, 패딩 2.7·4.05 같은 값입니다. 프레임을 스케일하면서 생긴 흔적으로 보입니다.
- **같은 색에 스타일이 여러 개** 연결된 경우가 있습니다. 예: `#2D2D2D` 텍스트에 `Black-90`, `Black-90-MiddleTitle`, `Black_90_MiddleTitle`이 모두 붙어 있습니다. 색 표에 그대로 적었습니다.
