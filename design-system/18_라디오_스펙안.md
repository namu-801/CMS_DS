# Radio 스펙안 (제안, 피그마 작업 전)

근거: `17_라디오_조사.md`. Button·IconButton·TextField에서 정한 규칙(토큰, 포커스 링, 비활성 모양, 클릭 영역)을 이어 씁니다. ⚑는 정해 주셔야 하는 항목이고 5절에 이유와 선택지를 적었습니다.

- 기준일: 2026-10-17

## 1. 종류와 상태 나누기

| 조사에서 나온 차이 | 종류인가 상태인가 | 이유 |
|---|---|---|
| 글자 있음(`radiobutton`) / 없음(`btn-radio`) | **종류 → 켜고 끄기** | 같은 컨트롤에 글자만 붙은 것. 컴포넌트를 둘로 나눌 이유가 없음 |
| 선택됨 / 선택 안 됨 | **상태(값)** | 사용자가 고르면 바뀌는 값. 다른 상태(마우스 올림·비활성)와 겹칠 수 있어서 따로 둠 |
| 기본 / 마우스 올림 / 비활성 | **상태(상호작용)** | 사용 중에 바뀌는 모습 |
| 포커스 | 상태, 코드에만 | Button·IconButton과 같은 포커스 링 규칙. Figma는 `Focus Ring · Guide` 프레임으로 안내 |
| 크기 | 해당 없음 | 시안에 20 하나뿐 |
| 행 배경 `#F3F3FF`, 팝업 메뉴 왼쪽 보라 막대 | **라디오가 아님** | 표·목록·메뉴의 "선택된 행" 모양. 그 컴포넌트를 만들 때 정함 |
| 묶음 제목 + 가로·세로 배치("반복 재생") | **묶음(배치)** | 라디오 하나의 속성이 아니라 여러 개를 놓는 방식. 6절 |

## 2. Component property 제안

| 속성 | 타입 | 값 | 기본값 | 정하는 것 |
|---|---|---|---|---|
| `Selected` | Variant | `Off`, `On` | `Off` | 선택 여부(원 안 점) |
| `State` | Variant | `Default`, `Hover`, `Disabled` | `Default` | 상호작용 모습 |
| `Label` | Boolean | 켬 / 끔 | 켬 ⚑ | 옆 글자 |
| `Label Text` | Text | 글자 | `선택지` | |

- Variant 수: Selected 2 × State 3 = **6개**(모든 조합. 지금 없는 "선택됨 + 비활성", "선택됨 + 마우스 올림"도 만듦).
- 이름을 `pressed` 대신 `Selected`로: 지금 이름 `pressed`는 "누르는 중"으로 읽혀서 헷갈립니다. IconButton의 `State=Selected`와도 맞춥니다. 오타 `defualt`도 정리됩니다.
- 코드에서는 라디오 하나(`Radio`)와 묶음(`RadioGroup`)을 함께 만듭니다(6절).

## 8. Figma base 제작 (2026-10-17)

- 같은 역할의 기존 컴포넌트: `btn-radio`(53:19455), `radiobutton`(53:19508), 프레임 `check,radio..`. 토큰이 연결돼 있지 않고 두 개로 나뉘어 있어 새로 만들었습니다. 기존 것은 지우지 않고 보관합니다.
- 프레임 `Radio · Component`(node `204:15899`, TextField 프레임 아래), 세트 `Radio`(node `204:15904`, key `561050770ae7a49159623c81995d79360f8f5aec`), base `Selected=Off, State=Default`(node `204:15900`).
- 구조: `Radio`(가로 Auto Layout, 간격 `Spacing/Scale/8`, 가운데 정렬, Hug) > `Control`(20×20 `Size/Icon/Small`, 모서리 `Radius/Scale/Full`, 테두리 `Border/Neutral/Tertiary`·`Size/Border/Default`·안쪽, 가운데 정렬) > `Dot`(10, `Surface/Brand/Primary`, Off에서는 숨김) / `Label`(`15/Medium`, `Foreground/Neutral/Secondary`).
- 속성: `Selected`, `State`, `Label`(기본 켬), `Label Text`(기본 `선택지`). 원시 값 0(검사). 점 10은 토큰이 없는 원 안쪽 크기(스펙 3-2).
- 미리보기 프레임 `_preview(삭제 예정)`: 글자 있음, 선택 모습(점만 켠 미리보기), 글자 없음.

## 10. 검사 후 정리 (2026-10-17)

- 검사 결과: 빠진 조합 0, 직접 값은 선택 점 10(스펙상 허용) 하나, Variant 축·기본값 스펙대로, Auto Layout 정상.
- 결정: 너비는 글자 길이에 맞춰 자동(Hug)으로 두고, 인스턴스 너비를 직접 줄이지 않는다(줄이면 글자가 넘침). 선택지 글자는 짧게 쓴다. Figma 세트 설명에 적음.
- 참고: 글자를 끄면 높이 20(원 크기), 켜면 24(줄 높이). 이전 `btn-radio`와 같음.
