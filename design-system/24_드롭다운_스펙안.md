# Dropdown 스펙안 (제안, 피그마 작업 전)

근거: `23_드롭다운_조사.md`. 칸 모양은 TextField(`16_텍스트필드_계약.md`)에서 정한 규칙(테두리·안내 문구·마우스 올림·비활성 색, 크기 이름)을 이어 쓰는 쪽으로 제안합니다. ⚑는 정해 주셔야 하는 항목이고 5절에 이유와 선택지를 적었습니다.

- 기준일: 2026-10-25
- 범위: 목록에서 값 **하나**를 고르는 드롭다운. 글자를 쳐서 찾는 칸(검색·자동 완성), 명령을 실행하는 메뉴, 여러 개 고르기는 넣지 않습니다(4절).

## 1. 종류와 상태 나누기

| 조사에서 나온 차이 | 종류인가 상태인가 | 이유 |
|---|---|---|
| 높이 48(`S`) / 40(`XXS`) | **종류 → 크기** | 놓이는 곳(목록 위 필터 / 편집 도구)에 따라 고르고, 쓰는 중에 바뀌지 않음 |
| 안내 문구(`empty`) / 값 있음(`selected`) | **상태(값)** | 사용자가 고르면 바뀜. TextField의 `Value=Empty/Filled`와 같은 성격 |
| 기본 / 마우스 올림 / 비활성 | **상태(상호작용)** | 사용 중에 바뀌는 모습 |
| 열림(`Focused-open`, `selected-open`) | **상태(상호작용)** | 누르면 열리고 고르면 닫힘. 지금 이름의 "Focused"와 "selected"는 값 상태가 섞인 것 → 열림 하나 + 값 상태로 나눔 |
| 닫힌 채 키보드 포커스 | 상태, 코드에만 ⚑ E | 시안에 없음 |
| 목록 안 선택지: 보통 / 고른 것 | **선택지의 상태** | 선택지 한 줄의 모습. 칸이 아니라 선택지가 가짐 ⚑ D·J |
| 목록 안 선택지: 마우스·키보드로 가리킴 | **선택지의 상태** | 시안에 없음 ⚑ D |
| 칸 안 글자가 필터 이름("운행 상태별") | **글자 내용** | 컴포넌트 종류가 아니라 안내 문구에 무엇을 쓰느냐의 문제 ⚑ H |
| 너비 128~164 | 해당 없음(화면 배치) | 화면마다 너비를 정함. 컴포넌트 속성이 아님 |

## 2. Component property 제안

### 2-1. `Dropdown` (칸)

| 속성 | 타입 | 값 | 기본값 | 정하는 것 |
|---|---|---|---|---|
| `Size` ⚑ C | Variant | `Small`(40), `Medium`(48) | `Medium` | 높이·여백·글자 크기 |
| `State` | Variant | `Default`, `Hover`, `Open`, `Disabled` | `Default` | 상호작용 모습. `Open`은 테두리 보라 + 위 화살표 |
| `Value` | Variant | `Empty`, `Filled` | `Empty` | 안내 문구인지 고른 값인지(글자색) |
| `Text` | Text | 글자 | `선택해 주세요` | 안내 문구 또는 고른 값 |

- Variant 수: Size 2 × State 4 × Value 2 = **16개**(모든 조합이 실제로 생길 수 있음. 예: 값 있는 채 비활성, 값 없는 채 열림).
- 마우스 올림과 열림을 한 축(`State`)에 둔 이유: 열린 동안의 마우스 올림 모습은 열림과 같아서 따로 만들 조합이 없습니다.

### 2-2. `Dropdown Option` (목록의 선택지 한 줄) ⚑ J

| 속성 | 타입 | 값 | 기본값 | 정하는 것 |
|---|---|---|---|---|
| `Size` | Variant | `Small`(40), `Medium`(48) | `Medium` | 칸과 같은 높이·여백·글자 |
| `State` | Variant | `Default`, `Hover`, `Selected` | `Default` | 보통 / 가리킴 / 고른 것 |
| `Text` | Text | 글자 | `선택지` | 선택지 글자 |

- Variant 수: 2 × 3 = **6개**.

### 2-3. `Dropdown Menu` (열린 목록 틀) ⚑ J

| 속성 | 타입 | 값 | 기본값 |
|---|---|---|---|
| `Size` | Variant | `Small`, `Medium` | `Medium` |

- 안에 `Dropdown Option` 인스턴스 5개(⚑ I의 최대 개수)를 세로로 쌓은 틀입니다. 화면에서 필요 없는 줄은 숨기고 글자만 바꿉니다.
- 화면에서는 `Dropdown`(`State=Open`) 바로 아래에 붙여 놓습니다.

## 3. 최종 스펙 (제안)

### 3-1. 종류

| 컴포넌트 | 하는 일 | 쓰는 곳 |
|---|---|---|
| `Dropdown` | 닫힌 칸. 지금 값(또는 안내 문구)과 화살표 | 차량관리 필터 3개, 콘텐츠 관리 "내 콘텐츠", 텍스트 업로드 글꼴 |
| `Dropdown Option` | 목록의 선택지 한 줄 | `Dropdown Menu` 안 |
| `Dropdown Menu` | 열린 목록 틀 | 열린 모습을 보여 줄 화면(상호작용 설명 등) |

코드에서는 `Dropdown` 하나로 칸·목록·선택지를 모두 그립니다(선택지는 배열로 받음). Figma만 세 개로 나누는 이유는 5절 J.

### 3-2. 크기 (`Size`)

| 항목 | `Small` | `Medium` | 토큰 |
|---|---|---|---|
| 칸 높이 | 40 | 48 | `Size/Height/ControlSmall` · `ControlMedium` |
| 좌우 여백 | 12 | 16 ⚑ A | `Spacing/Scale/12` · `16` (TextField와 같음) |
| 칸 글자 | `14/Regular` | `15/Regular` ⚑ B | Text Style (TextField와 같음) |
| 화살표 | `Icon/Arrow/Down` 20, 열림은 `Icon/Arrow/Up` 20 | 같음 | `Size/Icon/Small` |
| 글자와 화살표 | 양 끝으로 벌림, 최소 간격 8 | 같음 | `Spacing/Scale/8` (지금 64 → 8) |
| 너비 | 화면에서 정함(Figma 기본 164). 글자가 넘치면 말줄임(…) | 같음 | — |
| 선택지 한 줄 높이 | 40 | 48 | 칸과 같음 |
| 선택지 좌우 여백·글자 | 12, `14/Regular` | 16, `15/Regular` | 칸과 같음 |
| 고른 선택지 체크 ⚑ D | `Icon/Action/Check` 20, 오른쪽 | 같음 | `Size/Icon/Small` |

| 모서리, 테두리 | 0, 1 | 같음 | `Radius/Scale/0`, `Size/Border/Default` |

| 요소 | 색 |

### 3-6. 코드에서만 정하는 것 (Figma 속성 없음)

| 항목 | 내용 |
|---|---|
| 이름(제목) ⚑ G | `label` 필수. 지금 화면처럼 제목을 안 보이게 할 때는 `hideLabel`(스크린리더는 읽음) |
| 선택지 | `options` 배열(값·글자) |
| 값 | `value`/`defaultValue` + `onValueChange`. 값이 없으면 `placeholder`(안내 문구)를 보여 줌 |
| 키보드 | WAI-ARIA "select-only combobox": Enter·Space·아래 화살표로 열기, 위·아래로 이동, Enter로 고르기, Esc로 닫기, 글자로 찾아가기 |
| 열린 목록 위치 | 칸 바로 아래, 다른 내용 위에 겹침. 칸과 같은 너비 |
| 참고 | 브라우저 기본 `<select>`는 열린 목록 모양을 바꿀 수 없어서(운영체제 모양), 시안 모양을 지키려면 목록을 직접 그려야 함. 코드 단계에서 다시 정리 |

## 4. 조사에 나왔지만 지금은 넣지 않는 것

| 항목 | 이유 |
|---|---|
| 오류 상태·아래 오류 문구 | 드롭다운이 쓰이는 곳이 모두 필터·편집 도구라 "꼭 골라야 하는" 경우가 없음. 폼에 필수 드롭다운이 생기면 TextField와 같은 `Status=Error` + 문구로 추가 |

| 글자를 쳐서 찾기(검색·자동 완성, Combobox) | 로컬 프레임의 검색창 메모("추후 고도화")는 검색 기능이고, 지금 드롭다운은 고르기만 함. 차량 수가 많아져 찾기가 필요하면 별도 컴포넌트로 |
| 여러 개 고르기 | 쓰이는 곳 없음 |
| 묶음 제목·구분선·비활성 선택지 | 선택지 목록 자체가 시안에 없음 |
| 선택지 앞 아이콘·설명 글 | 쓰이는 곳 없음 |
| 명령 실행 메뉴(Pull-down, "…" 더보기 메뉴) | 값 고르기와 다른 컴포넌트. 필요하면 따로 |
| 누르는 중(`Pressed`) | 누르면 바로 열림 |
| 목록 그림자 | 시안처럼 칸에 붙은 보라 틀이면 필요 없음(⚑ F) |
