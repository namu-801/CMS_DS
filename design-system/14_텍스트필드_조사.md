# TextField 조사 (결정 전, 조사 결과만)

글자를 직접 입력하는 한 줄 입력창을 조사했습니다. 입력창 안에 들어가는 아이콘 버튼은 `IconButton`(확정, `13_아이콘버튼_계약.md`)이 맡습니다.

- 기준일: 2026-10-16
- 조사 범위: 시안 화면 54개의 인스턴스(외부 라이브러리), 로컬 컴포넌트(`Text input-pw` 프레임, node `53:19243`)
- 조사 방법: 이름(`input`, `textfield`, `search`, `password` 등)으로 찾은 뒤, **모양**으로 한 번 더 훑었습니다. 높이 28~56, 너비 100 이상, 테두리가 있고 글자가 왼쪽에 붙은 요소를 모두 모아 입력창만 남겼습니다. 표의 칸·이벤트 행처럼 모양이 비슷한 것은 확인 후 뺐습니다.

### 1-5. TextField가 아닌 것 (확인 후 제외)

- **드롭다운:** `Component 73~76`(48·40, 오른쪽 아래 화살표), `Select mode`. 틀 모양은 입력창과 같지만 고르는 컨트롤이라 Dropdown 컴포넌트에서 다룹니다.
- **표 칸·이벤트 행:** 높이 48~56에 테두리와 왼쪽 글자가 있어 모양 검색에 걸렸지만 입력창이 아닙니다(`Table.Cell.Text` 등).
- **시간 설정 버튼**(`btn-timesetting-h48`), **파일 가져오기**(`UploadButton_default`): 버튼입니다.
- **텍스트 편집 도구의 글자 크기 숫자 칸(52×40):** 콘텐츠 업로드(텍스트) 화면 `Font Size Controls`(node `1:4973`). −(40) · 숫자 칸(52, 글자 14/Medium `#494949`, 값 `32`) · +(40)이 붙어 있습니다. 지금 글자 크기를 보여 주는 칸이고, 숫자를 직접 쳐서 바꿀 수 있는지는 시안에 없습니다(확인 필요).
- **여러 줄 입력(textarea):** 시안에서 찾지 못했습니다.

### 1-6. 관찰된 특징 (아직 판단하지 않음)

- **크기 네 가지, 이름이 제각각:** 52(M), 48(검색, 컴포넌트 없음), 40(XXS), 30(XXXS). M과 XXS 사이의 S가 비어 있습니다.
- **크기마다 글자 크기와 여백이 다른 것은 자연스럽습니다.** 문제는 크기와 상관없어야 할 것(입력값 색, 굵기, 마우스 올림 표현, 제목·안내 문구 유무, 컴포넌트 구조)까지 크기마다 다르다는 점입니다. 크기별 상세는 1-7절.
- **같은 크기 안에서도 컴포넌트 방식이 다름:** M은 상태마다 단일 컴포넌트 10개, XXS·XXXS는 Variant 세트입니다.
- **입력값 색이 둘:** M `#111111`, XXS·XXXS `#2D2D2D`.
- **마우스 올림 표현이 다름:** M은 테두리가 진해지고(`#A3A3A3`), XXS는 바뀌지 않습니다.
- **포커스 표시는 테두리 색만:** 두께는 그대로 1이고, 버튼의 포커스 링(보라 2px)과 다른 방식입니다.
- **오류·성공을 색과 문구로만 알림:** 아이콘이 없습니다.
- **비활성 배경만 토큰 밖 색**(`#F1F3F6`)이고, 나머지 색은 모두 지금 토큰에 있습니다.
- **모양:** 모두 직각, 테두리 1, 그림자 없음.

## 2. 시중 디자인 시스템의 입력창

| 항목 | Material 3 | Carbon (IBM) | shadcn/ui |
|---|---|---|---|
| 종류 | Filled(배경 채움), Outlined(선, 기본) | Default(제목·안내가 밖), Fluid(칸에 붙은 형태) | 하나(`Input`) |
| 크기 | 문서에 높이 없음. 너비 기본 245dp, 최대 488dp | Extra small 24, Small 32, **Medium 40(기본)**, Large 48 | 36 하나 |
| 제목(label) | 칸 안에 있다가 입력·포커스 때 위로 올라감 | 칸 위, **필수**(접근성 예외 승인 없으면) | 별도 `Label` + `Field` 묶음 |
| 안내 문구(placeholder) | 제목과 함께 씀 | 선택, 기본은 숨김. 제목을 대신하면 안 됨 | 흐린 글자색 |
| 도움말(helper) | 칸 아래, 오류가 생기면 오류 문구로 바뀜 | 칸 아래, 오류·경고 문구로 바뀜 | `Field`의 설명 |
| 오류 | 테두리·글자·아이콘을 오류 색으로, **오류 아이콘** 표시 | 빨간 테두리 + **오류 아이콘** + 문구 | `aria-invalid`일 때 빨간 테두리·빨간 링 |
| 그 밖의 상태 | Enabled, Focused(테두리 색과 **두께** 변경), Error | Enabled, Active(입력 중), Focus, Error, **Warning**, Disabled, **Read-only**, Skeleton | focus-visible(링 3px), aria-invalid, disabled(투명도 50%) |
| 앞·뒤 요소 | 앞뒤 아이콘, 앞뒤 글자(prefix/suffix), 글자 수 | 비밀번호 보기 아이콘(오른쪽 끝) | 없음(조합해서 씀) |
| 끝 아이콘 기능 | 비밀번호 보기, **지우기**(글자가 있을 때), 사용자 정의 | 비밀번호 보기 | — |
| 필수·선택 표시 | — | 대부분 필수면 "선택"만, 대부분 선택이면 "필수"만 표시 | — |
| 접근성 | 제목·도움말 권장, 오류 문구를 스크린리더가 읽게, 누르는 아이콘에는 이름 | 칸 경계 3:1, 제목 필수 | 브라우저 기본 + `aria-invalid` |

**공통점:**
- 포커스는 테두리 색이 바뀌는 것 이상으로 **눈에 띄게** 표시합니다(Material은 두께, shadcn은 링).
- 오류는 **색 + 아이콘 + 문구**로 알립니다(색만으로 알리지 않음, WCAG 1.4.1).
- 안내 문구(placeholder)는 제목을 **대신하지 않습니다**.

## 3. 시중에는 보통 있는데 우리 시안에 없는 것

| 항목 | 시중 | 우리 시안 |

| 제목(label) 규칙 | 항상 보이는 제목 필수(Carbon) | 로그인은 제목 없이 안내 문구만 |
| 눈에 띄는 포커스 | 두께 변경 또는 링 | 테두리 색만 `#494949`로 |
| 오류 아이콘 | Material·Carbon | 없음(색과 문구만) |
| 읽기 전용(read-only) | Carbon | 없음 |
| 경고(warning) | Carbon | 없음 |
| 지우기 버튼 | Material | 없음 |
