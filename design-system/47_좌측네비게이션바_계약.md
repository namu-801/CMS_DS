# 좌측 네비게이션바 계약 (Contract) — + 상단 바 · 화면 제목

모든 관리 화면에 놓이는 좌측 네비게이션바(`Left Navigation Bar`·`Nav Item`)와, 함께 놓이는 상단 바(`Top Bar`·`Top Bar Action`), 화면 제목(`Page Title`)의 사용 규칙입니다.

- 기준일: 2026-10-27
- 근거: Figma `Navigation · Component`, 코드 `src/components/Navigation/`, 조사 `35_좌측네비게이션바_조사.md`, 스펙 `36_좌측네비게이션바_스펙안.md`(4~8절), 아이콘 규칙 `07`(안쪽 구조 통일), 대응표 `39_코드구현_대응표.md`
- 상태: Figma 완료, 코드 구현 완료

**핵심 원칙:** 메뉴 항목은 하나의 컴포넌트(아이콘 + 글자 + 상태)입니다. 메뉴가 늘어도 Variant를 늘리지 않고 아이콘·글자만 바꿉니다. 지금 화면의 메뉴 하나만 `Selected`입니다.

## 3. Figma 속성 ↔ 코드 Prop 대응표

| Figma | 코드 | 대응 |
|---|---|---|
| `Nav Item` `State=Selected` | `selected` 또는 `LeftNavigationBar currentValue` | 1:1 |
| `Nav Item` `State=Hover` | CSS `:hover` | 상태 → 브라우저 |
| `Nav Item` `Icon` · `Label` | `icon`(추천 6개만) · `label` | 1:1 |
| `Left Navigation Bar` 묶음·메뉴 | `groups` 데이터 | 구조 → 데이터 |
| 로고 이미지 | `logo` | 코드에만(이미지 슬롯) |
| `Top Bar Action` `Action` | `action` | 1:1 |
| `Top Bar Action` `State=Hover` | CSS `:hover` | 상태 → 브라우저 |
| `Top Bar` `Greeting` · 프로필 사진 | `greeting` · `avatarSrc` | 1:1 |
| `Page Title` `Title` · `Description`+`Description Text` | `title` · `description?` | 둘 → 하나 |

**일대일이 아닌 이유:** 메뉴 구성은 화면마다 같고 지금 메뉴만 다르므로, 코드는 메뉴를 데이터(`groups`)로 받고 지금 메뉴는 `currentValue` 하나로 정합니다. Figma는 드러낸 인스턴스의 `State`를 바꿉니다. 아이콘 바꿔 끼우기가 색을 지키는 것은 아이콘 세트 안쪽 구조를 통일했기 때문입니다(`07` 색 변경 기록).

## 4. 시안 쓰임별 정답 조합

| 쓰임 | Figma | 코드 |
|---|---|---|
| 관리 화면 왼쪽 | `Left Navigation Bar`, 지금 메뉴 `Selected` | `<LeftNavigationBar groups={MENU} currentValue="content" logo={<img …/>} />` |
| 관리 화면 위 오른쪽 | `Top Bar`(남은 너비 채움) | `<TopBar greeting=… avatarSrc=… onNotificationClick onLogoutClick />` |
| 화면 제목 | `Page Title` | `<PageTitle title="콘텐츠 관리" description="…" />` |
| 새 메뉴 추가 | `Nav Item` 인스턴스 추가 + 아이콘·글자 | `groups`에 항목 추가 |

## 5. 사용 규칙

1. 지금 화면 메뉴만 `Selected`. 두 개 이상 두지 않습니다.
2. 메뉴가 늘면 `Nav Item`을 하나 더 놓고 아이콘·글자를 바꿉니다(Variant 추가 금지).
3. Figma에서 기본 아이콘(Dashboard)을 쓸 때는 바꿔 끼우지 않습니다(같은 아이콘을 다시 지정하면 덧칠이 풀림).
4. 상단 알림·로그아웃은 아이콘 + 글자 `Top Bar Action`(IconButton 아님, 결정 2026-10-27).
5. 화면 제목은 화면마다 하나(h1).

## 6. 제대로 썼는지 확인하는 방법

- Figma: 이전 `Navi`·`Leftside`·`gnb` 이미지가 아닌지, 네비게이션바 안 `Selected`가 하나인지, 메뉴 아이콘이 흰색(선택은 진한 색)인지.

```js
const NAV_KEY = "4fc94c029a27bf9636703a8ca7ae8abda76f6388";
const report = [], old = [];
for (const inst of figma.currentPage.findAllWithCriteria({ types: ["INSTANCE"] })) {
  const main = await inst.getMainComponentAsync(); const set = main?.parent?.type === "COMPONENT_SET" ? main.parent : main;
  if (["Navi", "Leftside", "Title"].includes(set?.name)) { old.push(inst.id); continue; }
  if (main?.key !== NAV_KEY) continue;
  const sel = inst.findAll(n => n.type === "INSTANCE" && n.variantProperties?.State === "Selected");
  if (sel.length !== 1) report.push(`${inst.id}: 선택 ${sel.length}개`);
}
return { report, old };
```

- 코드: `npm run typecheck`(추천 목록 밖 아이콘, 없는 `action`, `title` 누락 컴파일 오류), `npm test`(nav 이름, 묶음 제목, 지금 메뉴 `aria-current`, 링크/버튼, 상단 버튼, h1).
- 손으로: Tab으로 메뉴 순서대로 이동, 포커스 링 보임, 스크린리더가 "주 메뉴 탐색, 콘텐츠 관리 현재 페이지"를 읽음.

## 7. 예시

```tsx
const MENU = [
  { title: "모니터링", items: [
    { value: "dashboard", icon: "navigation_dashboard_filled", label: "대시보드", href: "/dashboard" },
    { value: "vehicle", icon: "navigation_vehicle_filled", label: "차량관리", href: "/vehicle" },
  ]},
  { title: "콘텐츠 설정", items: [
    { value: "content", icon: "navigation_content_filled", label: "콘텐츠 관리", href: "/content" },
  ]},
] as const;

<div className={layout.shell}>
  <LeftNavigationBar groups={MENU} currentValue="content" logo={<img src={logo} alt="M-CMS" />} />
  <div className={layout.main}>
    <TopBar greeting="안녕하세요, 마바산업님" avatarSrc={profile} onNotificationClick={openAlerts} onLogoutClick={logout} />
    <PageTitle title="콘텐츠 관리" description="콘텐츠들을 생성하고 업로드해 주세요." />
  </div>

```

| 반례 | 왜 문제인지 | 바르게 |
|---|---|---|
| Figma: 메뉴마다 새 Variant를 만듦 | 규칙 하나로 만든 의미가 없어짐 | 인스턴스 + 아이콘·글자 |
| Figma: 메뉴 아이콘 색을 덧칠로 맞춤 | 아이콘을 바꾸면 풀릴 수 있음 | 컴포넌트 색 그대로 |
| 코드: 상단 알림을 IconButton으로 | 결정과 다름(글자 있음) | `TopBarAction` |
| 코드: `<h1>`을 화면에 여러 개 | 제목 구조 혼란 | `PageTitle` 하나 |
| 코드: 메뉴를 `<div onClick>`로 | 키보드·현재 페이지 표시 없음 | `NavItem`(링크/버튼) |

## 9·10. 동기화 · 알려진 문제

- 아이콘을 아이콘 세트에 추가할 때는 안쪽 구조("컴포넌트 > VECTOR `Icon` 하나")를 지켜야 메뉴에서 색이 유지됩니다(`07`).
- ⚑ 로고는 이미지 슬롯(`logo`)이며 로고 컴포넌트는 따로 없음.
- ⚑ 메뉴 접기·하위 메뉴·알림 개수 배지는 아직 없음.
- ⚑ 시안 화면에 이전 `Navi`·`Leftside`·`gnb` 이미지가 그대로 — 화면 교체 단계에서 바꿈.
