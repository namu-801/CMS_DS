# Tabs 계약 (Contract)

같은 자리에서 내용을 바꿔 보여 주는 탭(가로·세로) 사용 규칙입니다.

- 기준일: 2026-10-27
- 근거: Figma `Tab`·`Tab List`, 코드 `src/components/Tabs/`, 조사 `27_탭_조사.md`, 스펙 `28_탭_스펙안.md`(5~8절), 대응표 `39_코드구현_대응표.md`
- 상태: Figma 완료(검사 통과), 코드 구현 완료(타입 검사·테스트 통과, 브라우저 확인)

**핵심 원칙:** 한 묶음에서 선택은 하나입니다. 선택된 탭은 연보라 배경 + 보라 막대(가로는 아래, 세로는 왼쪽)로 표시합니다. 탭 안에 라디오를 넣지 않습니다.

## 2. 속성과 넣을 수 있는 값

| 컴포넌트 | 속성 | 타입 | 값 | 기본값 |
|---|---|---|---|---|
| `Tab` | `Orientation` | Variant | `Horizontal`, `Vertical` | `Horizontal` |
| | `State` | Variant | `Default`, `Hover`, `Selected`, `Disabled` | `Default` |
| | `Text` | Text | 글자 | `탭` |
| `Tab List` | `Orientation` | Variant | `Horizontal`(탭 4개, 3·4 숨김, 아래 선) / `Vertical`(탭 6개, 6번째 숨김, 오른쪽 선) | `Horizontal` |

```ts
interface TabItem { value: string; label: string; disabled?: boolean; content?: ReactNode }
interface TabsProps {
  label: string;                               // 필수. 탭 묶음 이름(스크린리더)
  items: readonly TabItem[];
  value?: string; defaultValue?: string;       // 없으면 첫 번째 탭
  onValueChange?: (value: string) => void;
  orientation?: "horizontal" | "vertical";     // 기본 "horizontal"
  className?: string;
}
```

| 항목 | 가로 | 세로 | 토큰 |
|---|---|---|---|
| 탭 높이 | 48 | 56 | `Size/Height/ControlMedium` · `Size/Height/Row` |

## 3. Figma 속성 ↔ 코드 Prop 대응표

| Figma | 코드 | 대응 |
|---|---|---|
| `Orientation` | `orientation` | 1:1 |
| `State=Selected` | `value`·`defaultValue`와 같은 탭 | 상태 → 값 |
| `State=Hover` | CSS `:hover` | 상태 → 브라우저 |
| `State=Disabled` | `items[].disabled` | 1:1 |
| `Text` | `items[].label` | 1:1 |
| `Tab List` | `<Tabs>` 자체 | 1:1(묶음) |
| (없음) | `label`(필수), `items[].content`, `onValueChange` | 코드에만 |

**일대일이 아닌 이유:** 선택은 묶음이 정하는 값이라 `value` 하나로 관리합니다(Figma는 탭마다 Variant). 탭 내용(`content`)과 묶음 이름(`label`)은 화면·스크린리더에 필요해 코드에만 있습니다.

## 4. 시안 쓰임별 정답 조합

| 쓰임 | Figma | 코드 |
|---|---|---|
| GPS 설정 팝업 "위치 설정 / 시간 설정" | `Tab List` `Horizontal`, 첫 탭 `Selected` | `<Tabs label="설정 방식" items={[{value:"location",label:"위치 설정",content:…}, …]} />` |
| 콘텐츠 업로드 팝업 왼쪽 메뉴 | `Tab List` `Vertical`(팝업 본문 높이 채움) | `<Tabs label="콘텐츠 종류" orientation="vertical" items={…} />`, 왼쪽 탭 묶음 너비는 화면에서 240 |

## 5. 사용 규칙

1. 탭은 같은 자리의 내용을 바꿀 때만 씁니다. 다른 화면으로 이동하면 좌측 네비게이션바·링크를 씁니다.
2. 한 묶음에 `Selected`는 하나. 처음에도 하나가 선택된 채로 시작합니다.
3. 탭 안에 라디오·체크박스를 넣지 않습니다(2026-10-27 결정).
4. 탭 글자는 짧게(넘치면 말줄임).
5. `Hover`는 상호작용 설명 프레임에만 씁니다.

## 6. 제대로 썼는지 확인하는 방법

- Figma: 이전 `Component 79`·`Popup_btn`이 아닌 `Tab`·`Tab List` 인스턴스인지, 한 묶음에 `Selected`가 하나인지.

```js
const TAB_KEY = "777ad233381e3c55bc92b3c00f995c55ae535c17", LIST_KEY = "5ced044c7ce20478146ec828909d7d458364c006";
const multi = [], old = [];
for (const inst of figma.currentPage.findAllWithCriteria({ types: ["INSTANCE"] })) {
  const main = await inst.getMainComponentAsync(); const set = main?.parent;
  if (set?.name === "Component 79" || set?.name === "Popup_btn") { old.push(inst.id); continue; }
  if (set?.key === LIST_KEY) {
    const sel = inst.children.filter(c => c.visible && c.variantProperties?.State === "Selected");
    if (sel.length !== 1) multi.push(`${inst.id}: 선택 ${sel.length}개`);
  }
}
return { multi, old };
```

- 코드: `npm run typecheck`(없는 `orientation`·`label` 누락 컴파일 오류), `npm test`(선택·화살표 이동·비활성 건너뜀·세로 위아래·내용 연결), `npm run dev`.
- 손으로: Tab 키로 들어가면 선택된 탭에 포커스, ←→(세로는 ↑↓)로 옮기면 바로 내용이 바뀜, 스크린리더가 "탭, 몇 개 중 몇 번째, 선택됨"을 읽음.

## 9. 동기화 · 10. 알려진 문제

- 막대 두께는 `Spacing/Scale/6`에 연결되어 있어, 간격 6을 바꾸면 막대도 바뀝니다.
- ⚑ 세로 탭 묶음 너비 240은 토큰 없이 화면이 정함(결정).
- ⚑ 시안 화면에 이전 `Component 79`·`Popup_btn`이 그대로 — 화면 교체 단계에서 바꿈.
