# IconButton 계약 (Contract)

이 문서는 디자인(Figma)과 코드가 함께 지켜야 하는 IconButton(아이콘만 있는 버튼) 사용 규칙입니다. 사람과 AI 모두 이 문서를 기준으로 쓰고 검사합니다.

- 기준일: 2026-10-09
- 근거: Figma `IconButton` 세트, 코드 `src/components/IconButton/`, 스펙 결정 `12_아이콘버튼_스펙안.md`, 토큰 `04_이름규칙.md`
- 상태: Figma 180개 Variant 완료, 코드 구현 완료(타입 검사·테스트 통과). 2026-10-09 재검토 반영(`Subtle` 아이콘 색 삭제, 아이콘 이름 정리)
- 글자가 있는 버튼은 `Button`(`10_버튼_계약.md`)을 씁니다.
- ⚑는 확정되지 않았거나 알려진 문제입니다. 10절에 모아 두었습니다.

**핵심 원칙:** 아이콘은 쓰임이 정해져 있습니다. IconButton은 틀(배경·테두리·상태)만 정하고, 아이콘의 크기와 색은 쓰임마다 정해진 값을 그대로 씁니다(4절 표).

## 2. 속성과 넣을 수 있는 값

### 2-1. Figma Component property

| 속성 | 타입 | 넣을 수 있는 값 | 기본값 |
|---|---|---|---|
| `Style` | Variant | `Plain`(틀 없음), `Outline`(선), `Primary`(채움) | `Plain` |
| `Size` | Variant | `20`, `24`, `40`, `48` (정사각 틀 크기) | `40` |
| `State` | Variant | `Default`, `Hover`, `Pressed`, `Selected`, `Disabled` | `Default` |
| `Icon Color` | Variant | `Strong`, `Default`, `Primary` | `Strong` |
| `Icon` | Instance swap | `Icon/*` 세트. 추천 26개: Plus, Minus, Edit, Close, Check, Refresh, Visibility, VisibilityOff, Undo, Arrow Up, Arrow Down, AddLocation, MyLocation, Notification, Logout, Bold, Italic, Underline, AlignLeft, AlignCenter, AlignRight, VerticalAlignTop, VerticalAlignCenter, VerticalAlignBottom, TextColor, BackgroundColor | `Icon/Action/Plus` 20 |
| `Floating` | Boolean | 켬 / 끔 (그림자 `Elevation/Low`) | 끔 |

버튼 이름은 속성이 아니라, 화면에 놓은 **인스턴스의 레이어 이름**에 적습니다(예: `IconButton` → `확대`).

### 2-2. 코드 Prop

```ts
type IconButtonVariant = "plain" | "outline" | "primary";
type IconButtonSize = 20 | 24 | 40 | 48;
type IconButtonIconColor = "strong" | "default" | "primary";
type IconButtonIconSize = 16 | 20 | 24 | 32;
// 틀보다 큰 아이콘은 넣을 수 없음
type IconSizeFor<S> = S extends 20 ? 16 | 20 : S extends 24 ? 16 | 20 | 24 : 16 | 20 | 24 | 32;

interface IconButtonProps<S extends IconButtonSize = 40> /* + 네이티브 <button> 속성(style, children, type, color, aria-label, aria-pressed, title 제외) */ {
  icon: IconName;                       // 필수
  label: string;                        // 필수. 버튼 이름 → aria-label, 툴팁(title)
  variant?: IconButtonVariant;          // 기본 "plain"
  size?: S;                             // 기본 40
  iconSize?: IconSizeFor<S>;            // 기본 20
  iconColor?: IconButtonIconColor;      // 기본 "strong"
  selected?: boolean;                   // 켜고 끄는 버튼만. 주면 aria-pressed
  disabled?: boolean;                   // 기본 false. selected보다 우선
  floating?: boolean;                   // 기본 false
  type?: "button" | "submit" | "reset"; // 기본 "button"
  className?: string;                   // 배치(margin, grid 위치)용만
}
```

| Prop | 넣을 수 있는 값 | 기본값 | 그 밖의 값을 넣으면 |
|---|---|---|---|
| `icon` | 등록된 아이콘 32종(아래) | 없음(필수) | 컴파일 오류 |
| `label` | 버튼 이름 글자 | 없음(필수) | 빠뜨리면 컴파일 오류 |
| `variant` | `"plain"`, `"outline"`, `"primary"` | `"plain"` | 컴파일 오류 |
| `size` | `20`, `24`, `40`, `48` | `40` | 컴파일 오류 |
| `iconSize` | 틀 20 → `16`·`20` / 틀 24 → `16`·`20`·`24` / 틀 40·48 → `16`·`20`·`24`·`32` | `20` | 틀보다 크면 컴파일 오류 |
| `iconColor` | `"strong"`, `"default"`, `"primary"` | `"strong"` | 컴파일 오류(`"subtle"`도 오류) |
| `selected`, `disabled`, `floating` | `true` / `false` | 없음 / `false` / `false` | — |
| `style` | 받지 않음 | — | 컴파일 오류 |

## 3. Figma 속성 ↔ 코드 Prop 대응표

| Figma | 코드 | 대응 | 값 대응 |
|---|---|---|---|
| `Style` | `variant` | 1:1 | `Plain`→`"plain"`, `Outline`→`"outline"`, `Primary`→`"primary"` |
| `Size` | `size` | 1:1 | `"20"`→`20`, `"24"`→`24`, `"40"`→`40`, `"48"`→`48` |
| `Icon Color` | `iconColor` | 1:1 | `Strong`→`"strong"`, `Default`→`"default"`, `Primary`→`"primary"` |
| `Icon` | `icon` | 1:1 | `Icon/Action/Plus` → `"action_plus"` |
| 아이콘 인스턴스의 Size | `iconSize` | 1:1 | 아이콘 `Size=24` → `24` |
| `Floating` | `floating` | 1:1 | 켬 → `true` |
| `State=Default` | (없음) | 상태 → 없음 | 아무것도 안 주면 Default |
| `State=Hover` | CSS `:hover` | 상태 → 브라우저 | Prop 없음 |
| `State=Pressed` | CSS `:active` | 상태 → 브라우저 | Prop 없음 |
| `State=Selected` | `selected` | 상태 → Boolean | `selected={true}` |
| `State=Disabled` | `disabled` | 상태 → Boolean | `disabled={true}` |
| 인스턴스 레이어 이름 | `label` | 레이어 이름 → Prop | 레이어 `확대` → `label="확대"` |
| (없음) | `:focus-visible` | 코드에만(Figma는 안내 프레임) | 포커스 링. 모양은 Figma `Focus Ring · Guide` 프레임(node `173:15758`) |
| (없음) | 클릭 영역 32 | 코드에만 | 20·24 틀 |
| (없음) | `type`, `onClick` 등 | 코드에만 | 동작 정의 |

### 3-1. 일대일이 아닌 이유

1. **Hover·Pressed는 Prop이 아닙니다.** 사용자가 마우스를 올리거나 누를 때 브라우저가 정하는 상태라서 코드에서 켜고 끌 이유가 없습니다. Figma는 화면 설계서에 모양을 보여 주려고 Variant로 둡니다(Button과 같음).
2. **Selected·Disabled는 Boolean입니다.** 화면 로직이 정하는 상태입니다. Figma에는 둘을 함께 켠 조합이 없고, 코드에서는 `disabled`가 우선입니다(비활성 모양, 클릭 안 됨).
3. **`selected`는 켜고 끄는 버튼에만 줍니다.** 값을 주면 `aria-pressed`가 붙어 스크린리더가 "눌림/안 눌림"을 읽습니다. 주지 않으면 일반 버튼입니다. 그래서 `false`와 "안 줌"이 다른 뜻입니다.
4. **버튼 이름은 레이어 이름 → `label`입니다.** Figma에서 숨긴 글자 레이어를 두지 않기로 했습니다(아이콘 버튼에 글자 레이어가 불필요). 대신 코드에서는 이름이 없으면 접근성이 깨지므로 `label`을 필수로 했고, 다른 속성으로 덮어쓸 수 없게 했습니다.
5. **`iconSize`의 허용 값이 `size`에 따라 달라집니다.** "틀보다 큰 아이콘을 넣지 않는다"는 지침을 Figma는 문서로만 지키지만, 코드는 타입으로 막습니다.
6. **포커스 링과 클릭 영역 32는 코드에만 있습니다.** 키보드 사용자와 작은 버튼의 누르기 편의를 위한 것이고, 화면 모양은 Figma와 같습니다. 포커스 링 모양은 Variant 대신 Figma `Focus Ring · Guide` 프레임에 예시로 둡니다.
7. **그림자 구현이 다릅니다.** Figma는 `Floating Shadow` 레이어를 켜고 끄고, 코드는 `box-shadow: var(--elevation-low)`를 씁니다. 결과는 같은 그림자입니다.

## 5. 사용 규칙

1. **틀보다 큰 아이콘을 넣지 않습니다.** 20 틀에는 20 이하, 24 틀에는 24 이하. Figma는 틀 밖을 자르지 않아서 튀어나오고, 코드는 타입 오류가 납니다.
2. 아이콘 크기와 색은 4절 표의 값을 씁니다. 임의로 바꾸지 않습니다.
3. 화면에 놓은 인스턴스의 레이어 이름을 버튼 뜻으로 바꿉니다(예: `확대`). 코드의 `label`이 이 이름입니다.
4. 지도 위치 추가는 켜졌을 때 `Selected` + 되돌리기 아이콘입니다. 다른 버튼의 선택 모양과 다른 것은 모드 전환을 보여 주는 예외입니다.
5. `Floating`은 지도처럼 바탕 위에 떠 있는 컨트롤에만 씁니다.
6. 글자가 필요하면 IconButton이 아니라 Button을 씁니다.
7. 화면 시안에는 `Default`, `Selected`, `Disabled`를 씁니다. `Hover`·`Pressed`는 상호작용 설명용 프레임에만 씁니다.
8. 세트 설명에 **[색 고정]**이 적힌 아이콘(상태·콘텐츠 종류·픽토그램, `07_아이콘_네이밍_규칙.md`)은 IconButton에 넣지 않습니다. 색이 정해져 있어서 `Icon Color`·비활성 색이 적용되지 않습니다. 코드에도 등록하지 않습니다.

## 6. 제대로 썼는지 확인하는 방법

### 6-1. Figma

**눈으로 확인**
- [ ] 레이어 패널에서 버튼이 `IconButton` 인스턴스(◇)입니다. 이전 컴포넌트(1-1의 9개)가 아닙니다.
- [ ] 인스턴스 레이어 이름이 버튼 뜻(`확대`, `알림` 등)으로 바뀌어 있습니다.
- [ ] 4절 표와 Style·Size·아이콘·아이콘 크기·Icon Color가 같습니다.
- [ ] 아이콘이 틀 밖으로 튀어나오지 않습니다.
- [ ] 인스턴스 메뉴의 "Reset all changes"를 눌러도 아이콘 모양 말고는 바뀌지 않습니다.

```js
for (const inst of figma.currentPage.findAllWithCriteria({ types: ["INSTANCE"] })) {
  const main = await inst.getMainComponentAsync();
  if (main?.parent?.type !== "COMPONENT_SET" || main.parent.key !== ICON_BUTTON_SET_KEY) continue;
  for (const o of inst.overrides) {
    const bad = o.overriddenFields.filter(f => !ALLOWED.has(f));
    if (bad.length) problems.push(`${inst.name} (${inst.id}): ${bad.join(", ")}`);
  }
  if (inst.name === "IconButton") unnamed.push(inst.id);                 // 버튼 이름 안 적음
  const icon = inst.findOne(n => n.name === "Icon");
  if (icon && (icon.width > inst.width || icon.height > inst.height)) oversize.push(inst.id); // 틀보다 큰 아이콘
}
return { problems, unnamed, oversize };
```

### 7-2. 시스템을 우회하는 반례

| 반례 | 왜 문제인지 | 바르게 |
|---|---|---|
| Figma: 이전 `Zoom IN` 컴포넌트를 그대로 씀 | 토큰이 연결돼 있지 않고 hover가 잘못 정의됨(아이콘이 옅어짐) | `IconButton` Outline / 40 + Floating |
| Figma: `Size=20`에 24 아이콘을 넣음 | 아이콘이 틀 밖으로 튀어나옴 | 20 아이콘 또는 Size 24 |
| Figma: 아이콘 색을 직접 칠함 | Icon Color 토큰이 끊기고, 상태가 바뀌어도 색이 안 따라감 | `Icon Color` 속성으로 고름 |
| Figma: `Status/Warning` 같은 [색 고정] 아이콘을 넣음 | 노란색 그대로라 `Icon Color`·비활성 색이 안 먹음 | 버튼에는 색이 바뀌는 아이콘만 씀. 경고 표시는 버튼 밖에 둠 |
| Figma: 레이어 이름을 `IconButton` 그대로 둠 | 개발자·AI가 버튼 이름을 알 수 없음 | 레이어 이름을 `확대` 등으로 |
| 코드: `<svg onClick={zoomIn}>…</svg>` | 키보드로 못 누르고 스크린리더가 버튼으로 못 읽음, 클릭 영역도 작음 | `<IconButton … />` |
| 코드: `<button><Icon name="action_plus" /></button>` | 버튼 이름이 없음, 상태 색·포커스가 없음 | `<IconButton icon="action_plus" label="추가" />` |
| 코드: `<IconButton size={20} iconSize={24} …>` | 컴파일 오류. 틀보다 큰 아이콘 | `iconSize={20}` |
| 코드: `<IconButton … className="text-red-500">` | 아이콘 색 덮어쓰기. 상태별 색이 깨짐 | `iconColor`로 고름 |
| 코드: 굵게 버튼을 `selected` 없이 배경색만 바꿔 켜짐 표시 | 스크린리더가 켜짐 상태를 모름 | `selected={isBold}` |
| 코드: 같은 `label`로 아이콘만 바꿔 토글(펼치기 ↔ 접기) | 스크린리더가 지금 상태를 알 수 없음 | 상태에 따라 `label`도 바꿈("펼치기"/"접기") |

## 8. 접근성 요구사항

### 8-1. 필수

| 항목 | 요구사항 | 지금 코드 | 근거 |

| 툴팁 | 마우스를 올리면 이름이 보여야 함 | `title`로 표시 | WCAG 1.1.1 보조 |

| 켜고 끄는 상태 | `aria-pressed`로 알림 | `selected`를 주면 적용 | WCAG 4.1.2 |

### 8-2. 아이콘 대비 (그림 요소 기준 3:1)

아이콘은 글자가 아니라 그림이라 3:1 이상이면 됩니다(WCAG 1.4.11). 비활성은 제외입니다.

| Icon Color | 흰 배경(기본) | hover 배경(`#F1F5FB`) | pressed 배경(`#E5E5E5`) |
|---|---|---|---|
| `Strong` `#2D2D2D` | 13.77 | 12.59 | 10.93 |
| `Default` `#767676` | 4.54 | 4.15 | 3.61 |
| (삭제됨) `Subtle` `#A3A3A3` | 2.52 미달 | 2.31 미달 | 2.00 미달 |
| `Primary` `#111111` | 18.88 | 17.26 | 14.99 |

- `Primary` 스타일: 흰 아이콘 / 보라 배경 4.83 · hover 6.95 · pressed 9.90, 켜짐(보라 아이콘 / 흰 배경) 4.83
- `Selected`: `#2D2D2D` / `#F3F3FF` 12.51

`Subtle`은 모든 배경에서 3:1에 못 미쳐서, 2026-10-09에 이 색을 쓰던 목록 펼치기(65곳), 입력창 수정(20곳), 비밀번호 보기, 편집 세로 정렬을 모두 `Default`(`#767676`)로 바꾸고 IconButton의 `Icon Color`에서 `Subtle` 값을 지웠습니다(Figma Variant 60개 삭제, 코드 `"subtle"`은 타입 오류). 남은 세 색은 모든 배경에서 기준을 넘습니다.
