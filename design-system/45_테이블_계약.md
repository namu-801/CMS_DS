**핵심 원칙:** 칸은 하나의 컴포넌트에 앞 부품·글자·뒤 부품을 켜고 끄며 만듭니다. 행 상태(마우스 올림·선택·비활성)는 **행 전체**에 적용합니다. 칸 안에 넣는 부품은 정해진 목록(아이콘·아바타·배지·버튼)만 씁니다.

## 3. Figma 속성 ↔ 코드 Prop 대응표

| Figma | 코드 | 대응 |
|---|---|---|
| `Table Header Cell` `Text` | `<TableHeaderCell>` 글자, 빈 열은 `hideLabel` | 1:1 |
| `Table Cell` `State` | `<TableRow selected disabled onClick>` | 칸 → 행 |
| `Radio` | `radio={{…}}` | Boolean → 객체 |
| `Indent` · `Chevron` | `indent` · `chevron` | 1:1 |
| `Leading` + `Leading Swap` | `leading` | 둘 → 하나 |
| `Label` + `Text` | `children` | 둘 → 하나 |
| `Trailing` + `Trailing Swap` | `trailing` | 둘 → 하나 |
| (없음) | `caption`, `TableHead`·`TableBody`·`TableRow` | 코드에만 |

### 3-1. 일대일이 아닌 이유

1. **상태가 행 단위입니다.** Figma 시안은 열 단위로 쌓아 칸마다 상태를 바꾸지만, 코드는 `<tr>` 하나에 한 번 줘서 같은 행의 칸이 어긋나지 않습니다.
2. **켜고 끄기 + 바꿔 끼우기 → 객체 하나.** 값이 없으면 꺼진 것이고, 바꿔 끼울 수 있는 부품은 타입으로 제한했습니다.
3. **라디오는 이름이 필요합니다.** 글자 없는 라디오라도 스크린리더가 어느 행을 고르는지 알아야 해서 `label`을 받습니다.
4. **표 이름(`caption`)은 코드에만 있습니다.** 화면에는 화면 제목이 있지만 스크린리더는 표 자체의 이름이 필요합니다.

## 5. 사용 규칙

1. 행 상태는 행 전체가 같게. 한 행 안에서 칸마다 상태를 다르게 두지 않습니다.
2. 라디오 열이 있으면 행 어디를 눌러도 선택되게(`TableRow onClick`에서 선택). 선택된 행은 `selected`.
3. 화살표 열이 있으면 행 전체가 상세로 가는 링크 역할(`onClick`).
4. 칸 안에는 정해진 부품만. 다른 컴포넌트를 넣어야 하면 계약에 추가한 뒤 씁니다.
5. 글자는 한 줄, 넘치면 말줄임. 행 높이 56을 바꾸지 않습니다.
6. 값이 없으면 "-"(결정 G).

## 6. 제대로 썼는지 확인하는 방법

### 6-1. Figma

- [ ] 이전 `Table.Title`·`Table.Cell.Text`·`default`가 아닌 새 컴포넌트입니다.
- [ ] 같은 행의 칸이 모두 같은 `State`입니다.
- [ ] 글자 끈 라디오도 선택 상태(`Selected`)가 행 상태와 맞습니다.

```js
const CELL_KEY = "2c0b2d648b4e3c41f8d2f338236a5fbff1fb87df";
const rows = new Map(), old = [];
for (const inst of figma.currentPage.findAllWithCriteria({ types: ["INSTANCE"] })) {
  const main = await inst.getMainComponentAsync(); const set = main?.parent;
  if (["Table.Title", "Table.Cell.Text", "default"].includes(set?.name ?? main?.name)) { old.push(inst.id); continue; }
  if (set?.key !== CELL_KEY) continue;
  const key = `${inst.parent.id}@${Math.round(inst.absoluteTransform[1][2])}`; // 같은 줄(y)끼리
  (rows.get(key) ?? rows.set(key, new Set()).get(key)).add(inst.variantProperties.State);
}
const mixed = [...rows].filter(([, s]) => s.size > 1).map(([k]) => k);
return { mixed, old: old.length };
```

## 7. 예시

```tsx
<Table caption="콘텐츠 그룹 목록">
  <TableHead>
    <TableHeaderCell>그룹 이름</TableHeaderCell>
    <TableHeaderCell>다운로드</TableHeaderCell>
    <TableHeaderCell hideLabel>할당</TableHeaderCell>
  </TableHead>
  <TableBody>
    {groups.map((g) => (
      <TableRow key={g.id} selected={selected === g.id} onClick={() => setSelected(g.id)}>
        <TableCell
          radio={{ name: "group", checked: selected === g.id, onChange: () => setSelected(g.id), label: `${g.name} 선택` }}
          leading={{ type: "icon", name: "object_group_folder_filled" }}
          trailing={g.gps ? { type: "tag", tagType: "gps", text: "GPS" } : undefined}
        >
          {g.name}
        </TableCell>
        <TableCell trailing={{ type: "statusText", status: g.ok ? "success" : "fail", text: g.ok ? "다운로드 성공" : "다운로드 실패" }} />
        <TableCell trailing={{ type: "button", label: "할당하기", icon: "arrow_right", onClick: () => assign(g.id) }} />
      </TableRow>
    ))}
  </TableBody>
</Table>
```

| 반례 | 왜 문제인지 | 바르게 |
|---|---|---|
| Figma: 선택 행의 칸 일부만 `Selected` | 한 행이 두 색 | 같은 행 모두 같은 State |
| Figma: 칸 안에 일반 프레임으로 배지를 그림 | 토큰·모양 규칙 밖 | `Leading`·`Trailing Swap` |
| 코드: `<TableCell><Tag …/></TableCell>`(children에 부품) | 컴파일 오류(글자만) | `trailing={{ type: "tag", … }}` |
| 코드: `<table>`를 직접 | 행 상태·토큰 없음 | `<Table>` |
| 코드: 라디오 `label` 없이 | 스크린리더가 어느 행인지 모름 | `label: "행 이름 선택"` |
