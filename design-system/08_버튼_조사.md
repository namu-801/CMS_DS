# 버튼 조사 (결정 전, 조사 결과만)

## 1. 우리 시안의 버튼

- 출처: 시안 화면의 버튼 인스턴스(외부 라이브러리)와, 가져오신 로컬 컴포넌트 세트(`Button` 프레임 8세트, `check,radio..` 프레임, `Map` 프레임 등)
- 모서리: 글자 버튼은 **모두 0(직각)**. 지도 컨트롤만 2, 전체보기 버튼만 약 5(재디자인 대상 화면)

### 1-4. 관찰된 특징 (아직 판단하지 않음)
- **크기 이름이 컴포넌트마다 다름**: `xxxs`·`xs`·`s`·`m`·`l`·`xl`, `h40`, `M`·`S`·`L`·`XL`이 섞여 있고, 같은 이름이 다른 높이를 뜻하기도 함(예: xs 42, xxs 40).
- **실제 높이는 8가지**: 20, 24(아이콘만), 32, 40, 42, 48, 52, 56. Foundation의 `Size/Height/Control*`(32·40·48·52)에 없는 42와 56이 많이 쓰임.
- **hover·pressed 색 일부가 토큰에 없음**: 보라 채움 `#5F60CA`·`#4C4DB2`, 네이비 채움 `#142E87`·`#283F89`.
- **상태**: 기본·hover·pressed·비활성 4가지. 포커스(키보드)와 로딩 상태는 없음.
- **여백이 좌우 비대칭**: 아이콘 옵션 때문에 예: 위12 오른14 아래12 왼24.
- **같은 모양이 여러 이름**: 회색 채움 42(`btn-fill-gray-xs` ↔ `btn-line-gray-m/default/default`), 보라 채움 42(`btn-fill-purple` xs ↔ `large/fill/purple/default/xs`).

## 2. 시중 디자인 시스템의 버튼

| 항목 | Material 3 | Apple HIG (SwiftUI) | shadcn/ui |
|---|---|---|---|
| 종류(스타일) | 강조 순서대로 Elevated, Filled, Filled tonal, Outlined, Text | borderedProminent(강조), bordered, borderless, plain, link, glass·glassProminent(새 OS) | default(주요), secondary, outline, ghost, link, destructive |
| 의미(역할) | — | normal, primary(기본 동작, Return 키), cancel, destructive(빨강) | destructive 스타일 |
| 크기 | Extra small, Small(기본), Medium, Large, Extra large | ControlSize: mini, small, regular(기본), large, extraLarge | xs(24px), sm(32px), default(36px), lg(40px) |
| 아이콘만 버튼 | Icon button(별도 컴포넌트), FAB·Extended FAB | 원형·사각 아이콘 버튼(macOS square/image button) | size `icon-xs`(24), `icon-sm`(32), `icon`(36), `icon-lg`(40) |
| 상태 | enabled, hovered, focused, pressed, disabled + 선택형(toggle)은 selected/unselected | (visionOS 기준) Idle, Hover, Selected, Unavailable / pressed 상태 필수 | hover, focus-visible(포커스 링), disabled(투명도 50%), aria-invalid(오류) |
| 모양 | 기본 완전히 둥글게(round), square 옵션, 누르거나 선택하면 모양 변화 | 캡슐·둥근 사각·원형 | 둥근 모서리(rounded-md) |
| 로딩 | — | 오래 걸리는 동작은 버튼 안에 진행 표시, 문구 변경("Checkout"→"Checking out…") | 버튼 안에 Spinner |
| 터치 영역 | — (아이콘 버튼은 48dp 보장) | 최소 44×44pt | — |
| 묶음 | Button group, Split button, Toggle button group | Pop-up 버튼(선택 메뉴), Pull-down 버튼(동작 메뉴) | Button Group |
| 아이콘 위치 | 아이콘 여백 8dp | 기호, 글자, 또는 둘 다 | `data-icon="inline-start"` / `"inline-end"` |

참고: Material 3 크기별 높이(dp)는 공식 문서 페이지를 열 수 없어 확인하지 못했습니다. 이름(XS~XL)과 기본값(Small)만 확인했습니다.

## 3. 시중에는 보통 있는데 우리 시안에 없는 것

| 항목 | 시중 | 우리 시안 |
|---|---|---|
| 포커스(키보드) 상태 | 세 시스템 모두 있음 | 없음 |
| 로딩 상태 | Apple, shadcn | 없음 |
| 위험(destructive) 버튼 | Apple 역할, shadcn 스타일(빨강) | 없음. 삭제도 회색·보라 버튼 사용 |
| 부드러운 채움(tonal·secondary) | Material Filled tonal, shadcn secondary | 없음(채움 아니면 선) |
| 링크 버튼 | Apple link, shadcn link | 없음(약관 링크는 그냥 밑줄 글자) |
| 둥근 모서리 | 세 시스템 모두 기본 | 없음(모두 직각) |
| 크기 이름 체계 | 하나의 체계(XS~XL, mini~extraLarge, xs~lg) | 컴포넌트마다 다름 |
| 아이콘 버튼 크기를 글자 버튼 높이와 맞춤 | shadcn(icon-sm 32 ↔ sm 32 등) | 20, 24, 40, 48로 따로 정해짐 |
| 최소 터치 영역 | Apple 44pt, Material 48dp | 20·24px 아이콘 버튼 있음 |
| 묶음 버튼(Split·Group) | 있음 | 없음(탭·세그먼트는 있음) |
