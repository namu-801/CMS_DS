## 1. 우리 시안의 아이콘 현황

### 1-1. `Icon` 프레임 구성

| 항목 | 개수 | 비고 |
|---|---|---|
| `Icon` 프레임 안의 아이콘 | 96 | |
| └ 로컬 원본 컴포넌트 | 36 | 이 파일에서 직접 수정 가능 |

### 1-5. 관찰된 이름·구조 특징 (아직 판단하지 않음)

| 특징 | 예 |
|---|---|
| 같은 아이콘이 두 벌 | `ic-dashboard-24-w`와 `icon/ic-dashboard-24/w` 둘 다 쓰임(차량·콘텐츠·링크도 동일) |
| 색이 이름에 들어감 | `-w`(흰색), `/b`(검정) |
| 상태가 이름에 들어감 | `-active`, `-deactive`, Variant `Default`/`Pressed` |
| 채움 여부가 이름에 들어감 | `-fill` |
| 크기가 이름에 들어감 | 16, 20, 24, 32, 36, 48, 60, 75 |
| 이름과 실제 크기가 다름 | `ic-baseline-folder-20`이 실제 24×24, `ic_full_screen_36`이 20×20, `ic-plus-20`이 23×23으로도 쓰임 |
| 구분자가 섞임 | `-`, `_`, `/`, 공백 (`ic-double arrow_right-24-active`) |
| 오타 | `ic-delele-36-W`, `ic-tex-bold-24`, `ic-time_locatioon-24` |
| 대소문자 섞임 | `ic-Radius-20`, `ic-Radiuscursor-20` |
| 실제로 쓰인 크기 | 16, 20, 24, 32(주로), 36·48·60·75(삽화에 가까운 큰 아이콘) |

## 2. 시중 디자인 시스템의 아이콘 스펙

shadcn/ui는 아이콘 세트를 직접 만들지 않고 Lucide를 기본으로 씁니다(문서 예시에서 Tabler도 사용). 그래서 표의 shadcn 칸은 Lucide 기준입니다.

| 항목 | Material (Material Symbols) | Apple HIG (SF Symbols) | shadcn/ui (Lucide) |
|---|---|---|---|
| 부르는 이름 | Material Symbols, 컴포넌트는 Icon, Icon button | SF Symbols, symbol | Icon(Lucide 아이콘), 아이콘만 있는 버튼은 Button `size="icon"` |
| 규모 | — | 7,000개 이상 | — |
| 스타일(종류) | Outlined, Rounded, Sharp 3종 | 렌더링 모드 4종: Monochrome, Hierarchical, Palette, Multicolor | 선 아이콘 한 가지 |
| 채움 | Fill 축 0~1, 기본 0(선) | `.fill` 변형 | 채움 축 없음(선 기반) |
| 기타 변형 | Grade 축 -50~200, 기본 0(같은 크기에서 두께 미세 조정) | slash, enclosed(circle·square·rectangle) 변형 | 별도 아이콘으로 제공(이름으로 구분) |
| 굵기 | Weight 100~700, 기본 400 | 9단계(ultralight~black), 글자 굵기와 맞춤 | strokeWidth 기본 2, `absoluteStrokeWidth`로 크기와 무관하게 고정 가능 |
| 크기 | Optical size 20~48, 기본 24 | 3단계 scale(small, medium, large), 글자 크기에 맞춰 커짐 | 기본 24px(viewBox 24) |
| 색 | 색 역할(color role)로 지정 | 렌더링 모드 + 컨테이너의 tint | `currentColor`(부모 글자색을 그대로 씀) |
| 상태 | 아이콘 자체에는 상태 없음. 상태 레이어를 위에 덮음: hover 8%, focus·pressed 10~12%, dragged 16%. disabled는 38% 불투명도. 선택/비선택은 채운 아이콘과 선 아이콘으로 구분 | 아이콘이 컨테이너 상태를 따름: disabled면 자동으로 흐려지고, 선택·강조 시 tint가 바뀜 | 아이콘에는 상태 없음. 상태는 감싼 버튼이 처리 |
| 터치 영역 | 48dp 권장 | (HIG 일반 기준 44pt) | Button `size`: `icon`, `icon-xs`, `icon-sm`, `icon-lg` |
| 움직임 | — | Bounce, Pulse, Wiggle, Rotate, Breathe, Replace, Draw On/Off, Variable Color | — (CSS로 처리) |
| 이름 규칙 | snake_case: `arrow_forward` | 소문자 점 구분: `square.and.arrow.up`, `heart.fill`, `bell.slash` | 아이콘 이름 kebab-case `arrow-right`, 컴포넌트 PascalCase `ArrowRight` |

### 세 시스템의 공통점 (사실 정리)
- 아이콘 이름에 **색이나 상태를 넣지 않습니다.** 색은 부모나 색 역할에서 받고, 상태는 아이콘을 감싼 버튼·컨트롤이 처리합니다.
- 채움 여부와 굵기, 크기는 이름이 아니라 **축이나 속성**(Fill, Weight, size, strokeWidth)으로 바꿉니다. Apple만 채움을 `.fill` 이름 변형으로 둡니다.
- 기본 크기는 모두 **24**입니다.
