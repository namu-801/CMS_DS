# Checkbox 스펙안 (제안, 피그마 작업 전)

근거: `20_체크박스_조사.md`. Radio(`19_라디오_계약.md`)에서 정한 규칙(꺼짐 테두리, 비활성 모양, 글자색 고정, 포커스 링, 클릭 영역)을 그대로 이어 씁니다. ⚑는 정해 주셔야 하는 항목이고 5절에 이유와 선택지를 적었습니다.

- 기준일: 2026-10-19

## 1. 종류와 상태 나누기

| 조사에서 나온 차이 | 종류인가 상태인가 | 이유 |
|---|---|---|
| 글자 있음(`checkbox`) / 상자만(`btn-check`) | **종류 → 켜고 끄기** | 같은 컨트롤에 글자만 붙은 것. Radio와 같은 방식 |
| 켜짐 전용 컴포넌트(`Checkbox_on_text`) | **상태로 합침** | 켜짐/꺼짐은 같은 컴포넌트의 상태여야 함. 지금은 켜면 컴포넌트가 바뀌어 글자 굵기까지 달라짐 |
| 켜짐 / 꺼짐 | **상태(값)** | 사용자가 누르면 바뀌는 값 |
| 기본 / 마우스 올림 / 비활성 | **상태(상호작용)** | 사용 중에 바뀌는 모습 |
| 포커스 | 상태, 코드에만 | Button·Radio와 같은 포커스 링 |
| 굵은 글씨가 섞인 글자(약관 동의) | **글자 내용** | 체크박스 종류가 아니라 글자 안의 꾸밈. 5절 I |
| 크기 | 해당 없음 | 시안에 20 하나뿐 |

## 2. Component property 제안

| 속성 | 타입 | 값 | 기본값 | 정하는 것 |
|---|---|---|---|---|
| `Checked` ⚑ | Variant | `Off`, `On` | `Off` | 켜짐 여부 |
| `State` | Variant | `Default`, `Hover`, `Disabled` | `Default` | 상호작용 모습 |
| `Label` | Boolean | 켬 / 끔 | 켬 ⚑ | 옆 글자 |
| `Label Text` | Text | 글자 | `선택 항목` | |
| `Message` ⚑ | Boolean | 켬 / 끔 | 끔 | 아래 오류 문구(5절 J를 (2)로 정할 때만) |
| `Message Text` ⚑ | Text | 글자 | `오류 문구` | |

- Variant 수: Checked 2 × State 3 = **6개**(모든 조합. 지금 없는 "켜짐 + 비활성", "켜짐 + 마우스 올림"도 만듦).
- 코드에서는 체크박스 하나(`Checkbox`)만 만듭니다. 체크박스는 하나씩 따로 켜고 끄므로 Radio처럼 묶음 컴포넌트가 꼭 필요하지 않습니다.

## 12. 글자 굵기 변경 (2026-10-20)

- 문제: 글자 `15/Medium`은 이전 `checkbox` 세트 기본값과 Radio에 맞춘 것이었고, 시안 화면 실사용을 세지 않았습니다. 시안 화면 체크박스 글자는 6곳 중 5곳이 `15/Regular`(로그인 "이메일 기억하기" 켜짐 2, 회원가입 약관 3), Medium은 로그인 꺼짐 1곳뿐입니다.
