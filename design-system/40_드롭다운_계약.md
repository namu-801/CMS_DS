# Dropdown 계약 (Contract)

이 문서는 디자인(Figma)과 코드가 함께 지켜야 하는 Dropdown(목록에서 값 하나 고르기) 사용 규칙입니다. 사람과 AI 모두 이 문서를 기준으로 쓰고 검사합니다.

- 기준일: 2026-10-27
- 근거: Figma `Dropdown` 세트들, 코드 `src/components/Dropdown/`, 조사 `23_드롭다운_조사.md`, 스펙 `24_드롭다운_스펙안.md`(7~11절 결정), 대응표 `39_코드구현_대응표.md`
- 상태: Figma 완료(검사 통과), 코드 구현 완료(타입 검사·테스트 통과, 브라우저 확인)
- 선택지가 2~5개면 Radio(`19_라디오_계약.md`), 켜고 끄기면 Checkbox(`22_체크박스_계약.md`), 글자를 쳐서 찾기는 이 컴포넌트가 아닙니다.
- ⚑는 확정되지 않았거나 알려진 문제입니다. 10절에 모았습니다.

**핵심 원칙:** 드롭다운은 **하나만** 고릅니다. 닫힌 칸은 TextField와 같은 모양이고, 열린 목록에서 "가리킨 줄"은 연보라, "고른 값"은 오른쪽 체크로 따로 보입니다. 화면에 제목이 없어도 코드에는 이름(`label`)을 줍니다.

## 2. 속성과 넣을 수 있는 값

### 2-1. Figma Component property

| 컴포넌트 | 속성 | 타입 | 값 | 기본값 |
|---|---|---|---|---|
| `Dropdown` | `Size` | Variant | `Small`(40), `Medium`(48) | `Medium` |
| | `State` | Variant | `Default`, `Hover`, `Open`, `Disabled` | `Default` |
| | `Value` | Variant | `Empty`(안내 문구), `Filled`(값) | `Empty` |
| | `Text` | Text | 안내 문구 또는 고른 값 | `선택해 주세요` |
| `Dropdown Option` | `Size` | Variant | `Small`, `Medium` | `Medium` |
| | `Selected` | Variant | `Off`, `On`(오른쪽 체크) | `Off` |
| | `State` | Variant | `Default`, `Hover`(연보라) | `Default` |
| | `Text` | Text | 선택지 글자 | `선택지` |
| `Dropdown Menu` | `Size` | Variant | `Small`, `Medium` (안에 선택지 5개, 필요 없는 줄은 숨김) | `Medium` |
| `Dropdown Open` | `Size` | Variant | `Small`, `Medium` (안의 칸·목록은 밖으로 드러남) | `Medium` |

### 2-2. 코드 Prop

```ts
type DropdownSize = "small" | "medium";
interface DropdownOption { value: string; label: string }

interface DropdownProps {
  label: string;                         // 필수. 무엇을 고르는 칸인지(스크린리더)
  hideLabel?: boolean;                   // 기본 false. 지금 시안은 제목이 없으므로 true
  options: readonly DropdownOption[];    // 선택지
  value?: string;                        // 고른 값(제어 방식). 없으면 안내 문구
  defaultValue?: string;                 // 처음 값(비제어 방식)
  onValueChange?: (value: string) => void;
  placeholder?: string;                  // 기본 "선택해 주세요"
  size?: DropdownSize;                   // 기본 "medium"
  disabled?: boolean;                    // 기본 false
  name?: string;                         // 폼 제출 이름(숨은 input)
  id?: string;
  className?: string;                    // 배치·너비용만
}
```

| Prop | 넣을 수 있는 값 | 기본값 | 그 밖의 값을 넣으면 |
|---|---|---|---|
| `label` | 글자 | 없음(필수) | 빠뜨리면 컴파일 오류 |
| `size` | `"small"`, `"medium"` | `"medium"` | 컴파일 오류 |
| `options[].label` | 글자 | — | 글자가 아니면 컴파일 오류 |
| `style` | 받지 않음 | — | 컴파일 오류 |

## 3. Figma 속성 ↔ 코드 Prop 대응표

| Figma | 코드 | 대응 | 값 대응 |
|---|---|---|---|
| `Size` | `size` | 1:1 | `Small`→`"small"`, `Medium`→`"medium"` |
| `State=Default` | (없음) | 상태 → 없음 | |
| `State=Hover` | CSS `:hover` | 상태 → 브라우저 | |
| `State=Open` | 누르기·키보드로 열림(내부 상태) | 상태 → 동작 | |
| `State=Disabled` | `disabled` | 1:1 | |
| `Value=Empty` / `Filled` | `value`(또는 `defaultValue`) 유무 | 상태 → 값 | 값이 없으면 Empty |
| `Text` | `placeholder` / 고른 선택지의 `label` | 하나 → 둘 | |
| `Dropdown Option` `Text` | `options[].label` | 1:1 | |
| `Dropdown Option` `Selected` | 지금 값과 같은 선택지 | 상태 → 값 | |
| `Dropdown Option` `State=Hover` | 마우스·키보드로 가리킨 줄 | 상태 → 동작 | |
| `Dropdown Menu`, `Dropdown Open` | 컴포넌트 안에서 그림 | Figma 전용 | |
| (없음) | `label`·`hideLabel`, `onValueChange`, `name`, `id` | 코드에만 | |

### 3-1. 일대일이 아닌 이유

1. **열림·가리킴·고름은 Prop이 아닙니다.** 사용자가 누르고 움직이면서 바뀌는 상태라 컴포넌트가 직접 관리합니다. Figma는 설계서에 모양을 보여 주려고 Variant로 둡니다.
2. **Figma `Text` 하나가 코드에서는 둘입니다.** 값이 없을 때의 안내 문구(`placeholder`)와 고른 값의 글자(`options[].label`)는 출처가 다릅니다.
3. **목록·선택지 컴포넌트는 Figma에만 있습니다.** Figma는 열린 모습을 화면에 그려야 해서 부품으로 나눴고, 코드는 `options` 배열로 한 번에 그립니다.
4. **`label`은 코드에서 필수입니다.** 시안에 제목이 없어도 스크린리더는 무엇을 고르는 칸인지 알아야 합니다(Figma에 제목 속성은 만들지 않기로 결정, 스펙 ⚑ G).

## 5. 사용 규칙

1. 고르기만 합니다. 여러 개 고르기, 글자 쳐서 찾기, 명령 실행 메뉴에 쓰지 않습니다.
2. 선택지가 2~5개이고 모두 보여도 되면 Radio를 먼저 고려합니다.
3. 칸 너비는 화면에서 정합니다. 긴 글은 말줄임(…)됩니다.
4. 목록은 선택지 5개까지 보이고 넘으면 스크롤됩니다. 개수 제한을 위해 선택지를 줄이지 않습니다.
5. 필터처럼 "아무것도 안 고름"이 의미 있으면 안내 문구(Empty)로 두고, 선택지에 "전체"를 넣어 되돌릴 수 있게 합니다.
6. Figma에서 열린 모습은 `Dropdown Open`으로 그립니다. 칸과 목록을 따로 놓으면 너비가 어긋납니다.
7. 칸 색·체크 색을 덮어쓰지 않습니다.

## 6. 제대로 썼는지 확인하는 방법

### 6-1. Figma

**눈으로 확인**
- [ ] 드롭다운이 `Dropdown` 또는 `Dropdown Open` 인스턴스입니다(이전 `Component 73` 아님).
- [ ] 값이 들어간 칸은 `Value=Filled`, 안내 문구만 있는 칸은 `Value=Empty`입니다.
- [ ] 열린 목록에서 `Selected=On`은 하나뿐입니다.
- [ ] 너비를 바꾼 열린 드롭다운의 칸과 목록 너비가 같습니다.

**스크립트로 확인(Figma 플러그인 API)**

```js
const KEYS = { dropdown: "094771c2b31824249b95fbf7c064cd35aa098efe", option: "55813003a69d67b51c361e0be166da0532236615", open: "854bc1e107922b3581310fa3408191eb5feba43b" };
const ALLOWED = new Set(["characters", "visible", "name", "componentProperties", "width", "height"]);
const problems = [], old = [], multiSelected = [];
for (const inst of figma.currentPage.findAllWithCriteria({ types: ["INSTANCE"] })) {
  const main = await inst.getMainComponentAsync();
  const set = main?.parent?.type === "COMPONENT_SET" ? main.parent : null;
  if (set?.name === "Component 73") { old.push(inst.id); continue; }            // 이전 드롭다운
  if (!set || !Object.values(KEYS).includes(set.key)) continue;
  for (const o of inst.overrides) { const bad = o.overriddenFields.filter(f => !ALLOWED.has(f)); if (bad.length) problems.push(`${inst.id}: ${bad}`); }
  if (set.key === KEYS.open) {
    const on = inst.findAll(n => n.type === "INSTANCE" && n.variantProperties?.Selected === "On");
    if (on.length > 1) multiSelected.push(inst.id);
  }
}
return { problems, old, multiSelected };
```

## 7. 예시

### 7-1. 정상 사용

```tsx
import { Dropdown } from "@/components/Dropdown";

const STATUS = [
  { value: "all", label: "전체" },
  { value: "driving", label: "운행 중" },
  { value: "idle", label: "대기" },
];

// 필터: 안 고르면 안내 문구, "전체"를 고르면 다시 비움
const [status, setStatus] = useState<string>();
<Dropdown
  label="운행 상태"
  hideLabel
  placeholder="운행 상태별"
  options={STATUS}
  value={status}
  onValueChange={(v) => setStatus(v === "all" ? undefined : v)}
/>

// 편집 도구: 작은 크기
<Dropdown label="글꼴" hideLabel size="small" options={fonts} defaultValue="pretendard" />

// 폼: 제목 보이기 + 제출 이름
<Dropdown label="차량 그룹" options={groups} name="group" />
```

### 7-2. 시스템을 우회하는 반례

| 반례 | 왜 문제인지 | 바르게 |
|---|---|---|
| Figma: 이전 `Component 73`을 그대로 씀 | 테두리·안내 문구 대비 미달, 토큰 없음 | `Dropdown` |
| Figma: 칸과 목록을 따로 놓고 너비를 각각 맞춤 | 너비가 어긋나기 쉬움 | `Dropdown Open` |
| Figma: 고른 줄을 연보라로 칠함(체크 없음) | "가리킴"과 "고름"이 구분되지 않음 | `Selected=On`(체크), 가리킴만 `State=Hover` |
| 코드: `<select>`를 직접 씀 | 열린 목록 모양이 운영체제 모양 | `<Dropdown>` |

| 코드: `className="border-red"`로 오류 표시 | 오류 상태는 아직 없음(⚑ 1) | 화면 문구로 알림 |

| 이름 | 무엇을 고르는지 | `aria-labelledby`(제목, `hideLabel`이어도 유지) | WCAG 1.3.1, 4.1.2 |
| 열림 상태 | 펼침/접힘 | `aria-expanded`, `aria-controls` | WCAG 4.1.2 |
| 가리킨 선택지 | 포커스는 칸에 두고 가리킨 줄을 알림 | `aria-activedescendant` | WAI-ARIA |
| 고른 값 | 선택됨을 알림 | `aria-selected="true"` + 체크(모양) | WCAG 1.4.1 |
| 키보드 | 열기·이동·고르기·닫기 | Enter·Space·↓ 열기, ↑↓·Home·End·PageUp/Down 이동, Enter·Space 고르기, Esc 닫기, Tab 고르고 이동, 글자로 찾기 | WCAG 2.1.1 |
| 포커스 표시 | 보임 | 테두리 `Border/Brand/Primary` | WCAG 2.4.7 |
| 비활성 | 열리지 않음 | 네이티브 `disabled` | WCAG 4.1.2 |
