## 2. Scrollbar

### 2-1. 시안

| 항목 | 값 |
|---|---|
| 컴포넌트 | 외부 `Scrollbar`(`Orientation=Vertical, Scroller size=50%`) |
| 모양 | 세로 막대만(트랙 없음), 두께 4(인스턴스 틀 6), 모서리 둥글게, 색 `#757780`(토큰 없음, `Neutral500` `#767676`과 거의 같음) |
| 쓰는 곳 | 팝업 안 표·목록, GPS 위치 목록, 대시보드 카드 |

### 2-2. 스펙

| 속성 | 값 |
|---|---|
| 컴포넌트 | `Scrollbar` (속성 없음, 세로만) |
| 크기 | 너비 4(토큰 없음, 그림 크기), 높이는 화면에서 늘림. 막대 길이는 틀 높이의 절반(화면에서 조절) |
| 색 | 막대 `Border/Neutral/Tertiary` `#767676`(지금 `#757780`), 트랙 없음 |
| 모서리 | `Radius/Scale/Full` |
| 코드 | 컴포넌트 아님. 전역 CSS로 브라우저 스크롤바를 얇게(4) + 같은 색. 키보드·휠 스크롤은 브라우저 기본 |

넣지 않는 것: 가로 스크롤바, 트랙 색, 마우스 올림 굵어짐(시안에 없음).

## 3. List Item (GPS 위치 목록) — 만들지 않음

| 항목 | 시안 |
|---|---|
| 기본 행 `list` | 298 × 48, 흰색, 아래 선 `#E5E5E5`, 안에 이전 `gps_textfield`(위치 이름 13 · `#2D2D2D`) + 펼침 화살표 20(`#A3A3A3`) |
| 펼친 행 `selected_unfold` | 배경 `#F3F3FF`, 이름 + 수정 버튼(연필 20), 아래 주소·좌표 |

판단 근거와 나중에 할 일:
- 이름 칸은 TextField 계약에서 이미 `gps_textfield`를 다시 만든 부분(274×32)이고, 수정 버튼은 IconButton `Plain` 20 정답 조합이 있습니다(`14_텍스트필드_조사.md` 1-4절).
- 행 배경(선택 `#F3F3FF`)과 아래 선은 Table 본문 칸과 같은 토큰(`Surface/Brand/Tertiary`, `Border/Neutral/Primary`)으로 맞추면 됩니다.
- GPS 설정 화면을 새로 그릴 때 "위치 목록 항목" 화면 패턴으로 문서화합니다.

## 4. Map Marker (지도 반경 표시) — 규칙만

| 상태(시안 이름) | 원 채움 | 원 테두리 | 가운데 점 | 이름표 |
|---|---|---|---|---|
| 저장됨(`Save default mode`) | `Surface/Location/Saved`(`#5D5FEF` 8%) | `#5D5FEF` 1 → `Border/Brand/Strong` | 흰 원 24 + 같은 테두리 | 흰 상자(모서리 3, 그림자 흐림 1), "위치"·"반경 500m" `10/Medium` `#494949`, 숫자 `10/Bold` 보라 |
| 선택됨(`Select mode`) | `Surface/Location/Selected`(`#9747FF` 20%) | `#9747FF` 2 → `Foreground/Location/Selected` 색 | 같음(보라) | 같음, 숫자 `#9747FF` |
| 편집 중(`Edit mode`) | 선택됨과 같음 | 같음 | 같음 | 이름표 아래 "지우기" 버튼(이전 `btn-outline-gray`) |

나중에 할 일(GPS 화면 교체 때):
- 원 테두리 색에 맞는 Border 토큰이 보라(`Border/Brand/Strong`)만 있고 바이올렛 테두리 토큰은 없음 → 토큰 필요 여부 판단.
- 이름표 글자 10은 우리 글자 크기 중 가장 작음. 지도 위 가독성 검토.
- "지우기"는 `Button` `Outline` `XSmall` + 아이콘으로 바꿈.
- 지도 위 컨트롤(위치 추가·현재 위치·확대·축소)은 이미 IconButton 정답 조합이 있음(`13_아이콘버튼_계약.md`).
