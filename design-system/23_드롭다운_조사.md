# Dropdown 조사 (결정 전, 조사 결과만)

닫혀 있을 때는 지금 고른 값 하나를 보여 주고, 누르면 아래로 선택지 목록이 열리는 컨트롤(드롭다운)을 조사했습니다. 선택지를 모두 펼쳐 놓는 컨트롤은 Radio(`19_라디오_계약.md`), 직접 글자를 쓰는 칸은 TextField(`16_텍스트필드_계약.md`)가 맡습니다.

- 기준일: 2026-10-25
- 조사 범위: 시안 화면의 인스턴스(외부 라이브러리 `Component 73` 세트), 로컬 프레임 `Combo box (Dropdown)`(node `53:19845`)과 로컬 세트 `Component 73`(node `53:19865`). 새로 만든 로그인 v2 화면은 제외
- 조사 방법: 이름(`Component 73~76`, `drop`, `select`)으로 찾은 뒤, TextField 조사 때 모양으로 걸러 둔 드롭다운 후보(`14_텍스트필드_조사.md` 1-5절)와 맞춰 봤습니다.
- 화면에 보이는 것만 셌습니다(숨긴 레이어 0개).

### 1-7. 관찰된 특징 (아직 판단하지 않음)

- **세트 하나로 통일되어 있음:** 시안 화면 10개가 모두 같은 `Component 73`입니다. 다른 방식으로 만든 드롭다운은 없습니다.
- **열린 목록이 화면에 없음:** 선택지가 실제로 무엇인지(필터의 선택지, 글꼴 목록) 시안에 없습니다. 글꼴 고르기의 "항목2"도 자리 채움 글자로 보입니다.
- **제목 없이 칸 안 글자로 뜻을 알림:** 필터 "운행 상태별"처럼 칸 글자가 제목 역할을 합니다. 값을 고르면 이 글자가 사라지는지, "운행 상태: 운행 중"처럼 바뀌는지 알 수 없습니다.
- **같은 상태 안에서 글자 굵기가 섞임:** 안내 문구가 닫힌 칸은 Medium, 열린 칸은 Regular. 비활성은 S만 Regular, XXS는 Medium.
- **기본 테두리가 TextField보다 연함:** `#D6D6D6`(1.45)는 그림 요소 기준 3:1에 못 미칩니다. TextField는 같은 문제로 `#767676`으로 바꿨습니다.
- **안내 문구 대비 부족:** `#A3A3A3` 2.52(글자 기준 4.5:1 미달). TextField 안내 문구는 시안부터 `#767676`(4.54)이었습니다.
- **비활성 글자가 거의 안 보임:** `#D6D6D6` 글자(TextField 비활성 글자는 `#A3A3A3`). 비활성은 대비 기준 대상은 아닙니다.
- **칸과 목록이 하나의 틀:** 열리면 칸 아래 테두리가 없어지고 목록과 이어져 보라 틀 하나가 됩니다. 그림자가 없어 아래 화면과 겹칠 때 구분은 테두리만 맡습니다.
- **고른 선택지 표시가 마우스 올림 색:** 고른 선택지의 배경 `#F3F3FF`는 다른 컴포넌트에서 "마우스 올림" 배경으로 쓰는 색입니다. 마우스를 올린 선택지 모양은 따로 없습니다.
- **선택지 개수가 많을 때(스크롤) 모양이 없음:** 목록은 4개짜리만 있습니다.
- **화살표 아이콘은 아이콘 세트에 있음:** `ic-arrow-down-20`·`ic-arrow-up-20`은 이미 `Icon/Arrow/Down`·`Up` 20으로 옮겨져 있습니다(코드 `arrow_down`, `arrow_up`). 새로 그릴 것은 없습니다.
- **너비가 화면마다 다름:** 128, 132, 139, 156, 164. 글자 길이에 맞춘 것이 아니라 고정 너비입니다(128 칸의 "이벤트 상태별"은 화살표와 간격이 64보다 좁아짐).

## 2. 시중 디자인 시스템의 드롭다운

| 항목 | Material 3 | Apple HIG | shadcn/ui |
|---|---|---|---|
| 부르는 이름 | Exposed dropdown menu(글자 칸 + 메뉴) | Pop-up button(값 고르기) / Pull-down button(명령 실행) | Select(Radix 기반) |
| 구성 | 칸(테두리형·채움형), 제목, 고른 값, 뒤 아이콘, 메뉴 | 지금 값을 보여 주는 버튼 + 메뉴 | 칸(Trigger) + 값(Value) + 아래 화살표, 떠 있는 목록(Content), 선택지(Item) |
| 크기 | 기본·조밀(dense) 두 가지 | 문서에 없음 | `default` 36, `sm` 32 |
| 칸 모양 | 글자 칸(TextField)과 같은 모양 | 시스템 버튼 | 입력칸과 같은 테두리·모서리 6, 아래 화살표 16(투명도 50%) |
| 목록 모양 | 떠 있는 메뉴, 높이(elevation) 3 | 시스템 메뉴 | 떠 있는 상자, 테두리 + 그림자, 모서리 6, 칸과 4 떨어짐(popper 방식) |
| 고른 선택지 표시 | 배경색(`surfaceContainerHighest`) | 체크 표시 | 오른쪽 체크 아이콘 16 |
| 마우스 올림·키보드로 가리킨 선택지 | 물결(ripple) 색 | 시스템 강조 | 배경 `accent` |
| 선택지가 많을 때 | — | 묶고 구분선 | 화면 높이에 맞춰 스크롤, 위·아래 스크롤 버튼 |
| 묶음 제목·구분선·비활성 선택지 | 메뉴에 구분선 | 구분선 | 모두 있음(`SelectLabel`, `SelectSeparator`, `data-disabled`) |
| 제목(라벨) | 선택이지만 **강하게 권장** | 무엇을 고르는지 미리 알 수 있게 **앞 글자나 버튼 글자**를 둠 | 별도 `Label`과 연결 |
| 오류 | TextField와 같은 오류 모양·문구 | — | `aria-invalid`면 빨간 테두리·링 |
| 직접 글자 쓰기 | 일부 변형은 가능(자동 완성) | 불가 | 불가(글자 쓰기는 Combobox로 따로) |
| 기본값 | 값을 보여 준 채로 시작 가능 | **대부분이 원할 값을 기본으로** | 안내 문구(placeholder) 또는 기본값 |
| 언제 쓰는지 | 선택 컨트롤(라디오)보다 자리를 적게 차지할 때 | 서로 배타적인 평평한 목록, 자리가 부족할 때. 명령 목록·여러 개 고르기·하위 메뉴는 Pull-down | — |

**키보드·스크린리더 (WAI-ARIA "select-only combobox" 패턴):**
- 칸은 `combobox`, 목록은 `listbox`, 선택지는 `option`. 열림 여부는 `aria-expanded`, 고른 선택지는 `aria-selected`. 제목은 `aria-labelledby`로 연결.
- 닫힌 칸: Enter·Space·아래 화살표로 열기, 글자를 치면 그 글자로 시작하는 선택지로 이동.
- 열린 목록: 위·아래 화살표로 이동, Home·End로 처음·끝, Enter·Space로 고르고 닫기, Esc로 바꾸지 않고 닫기, Tab으로 고르고 다음 칸으로.
- 브라우저 기본 `<select>`도 같은 동작을 하지만, 열린 목록의 모양은 바꿀 수 없습니다(운영체제 모양).

**공통점:**
- 닫힌 칸은 **입력칸(TextField)과 같은 모양**이고, 뒤에 아래 화살표가 붙습니다.
- 목록은 칸 위에 **떠 있는 상자**(그림자 또는 높이)로 그립니다.
- 고른 선택지는 **체크 표시나 배경색**으로, 키보드·마우스로 가리킨 선택지는 **다른 배경색**으로 구분합니다.
- **제목(라벨)** 을 두거나, 없으면 무엇을 고르는지 미리 알 수 있는 글자를 둡니다.
- 값 고르기(Select)와 명령 실행(메뉴), 글자 쓰기(Combobox)를 **다른 컴포넌트**로 나눕니다.

## 3. 시중에는 보통 있는데 우리 시안에 없는 것

| 항목 | 시중 | 우리 시안 |
|---|---|---|
| 제목(라벨) | Material 권장, Apple은 앞 글자, shadcn `Label` | 없음. 칸 안 글자가 대신함 |
| 오류 상태·문구 | Material, shadcn | 없음 |
| 닫힌 칸의 키보드 포커스 | 세 시스템 모두 | 없음(열린 모양만 보라) |
| 마우스 올린(가리킨) 선택지 | 세 시스템 모두 | 없음. 고른 선택지 색이 마우스 올림 색 |
| 고른 선택지의 체크 표시 | Apple, shadcn | 없음(배경색만) |
| 떠 있는 목록(그림자·간격) | 세 시스템 모두 | 칸에 붙은 보라 틀, 그림자 없음 |
| 긴 목록 스크롤 | shadcn | 없음(4개짜리만) |
| 비활성 선택지, 묶음 제목, 구분선 | shadcn(모두), Apple·Material(구분선) | 없음 |
| 입력칸과 같은 칸 모양 | 세 시스템 모두 | 테두리·안내 문구 색·여백·글자 굵기가 TextField와 다름(1-6절) |
| 진한 기본 테두리 | Material·shadcn은 입력칸 테두리 색 | `#D6D6D6` 1.45 |
