# Radio 조사 (결정 전, 조사 결과만)

여러 선택지 중 **하나만** 고르는 컨트롤을 조사했습니다. 여러 개를 고르는 컨트롤은 Checkbox(다음 차례)에서 다룹니다.

- 기준일: 2026-10-17
- 조사 범위: 시안 화면 54개의 인스턴스(외부 라이브러리), 로컬 세트 `btn-radio`(node `53:19455`), `radiobutton`(node `53:19508`)
- 조사 방법: 이름(`radio`)으로 찾은 뒤, 모양(14~26 크기의 테두리 있는 원)으로 한 번 더 훑었습니다. 컴포넌트가 아닌 원은 1개(빨간 원, 라디오 아님)뿐이었습니다.
- **화면에 보이는 것만 셌습니다.** 숨긴 레이어(`visible=false`)에 들어 있는 라디오 52개는 뺐습니다(1-5절).

## 1. 우리 시안의 라디오

### 1-1. 쓰이는 곳

| 묶음 | 지금 만든 방식 | 모양 | 한 묶음 선택지 | 선택 표시 | 사용 |
|---|---|---|---|---|---|
| 표·목록 행 선택(콘텐츠, 콘텐츠 그룹) | `btn-radio`(라벨 없음) | 원 20, 행 맨 앞 | 9~10개(행 수) | 원 + 행 배경 `#F3F3FF` | 418 · 7화면 |
| 할당 화면 콘텐츠 그룹 목록 | `btn-radio`(라벨 없음) | 원 20, 목록 행(405×86) 맨 앞 | 3~10개 | 원 + 행 배경 `#F3F3FF` | 50 · 4화면 |
| 콘텐츠 업로드 팝업 왼쪽 메뉴(콘텐츠 종류) | `radiobutton`(라벨 포함)을 메뉴 행(239×56) 안에 넣음 | 원 20 + 글자 | 5~6개, 세로 | 원 + 행 배경 `#F3F3FF` + 왼쪽 보라 막대 | 65 · 11화면 |
| "반복 재생" 선택(팝업) | `radiobutton`(라벨 포함) | 원 20 + 글자, 가로 | 2개(안함/함) | 원만 | 2 · 1화면 |
| "반복재생" 선택(할당 화면) | **`btn-radio` + 일반 글자**(같은 모양을 다르게 만듦) | 위와 같음 | 2개 | 원만 | 2 · 1화면 |

- 합계: 화면에 보이는 라디오 537개(`btn-radio` 470, `radiobutton` 67). 모든 묶음에서 선택된 것은 항상 1개입니다(라디오 규칙대로).
- 가로 묶음("반복 재생"): 묶음 제목 `15/SemiBold` `#2D2D2D`를 왼쪽에 두고, 선택지 사이 간격 20.

### 1-2. 상태별 모양 (로컬 세트 기준)

| 상태 | Figma 이름 | 원 테두리 | 원 안 | 글자 | 시안 화면에 쓰임 |
|---|---|---|---|---|---|
| 기본(선택 안 됨) | `defualt`(오타), `default_text` | `#A3A3A3` 1 (`Border/Neutral/Disabled`) | 없음 | `15/Medium` `#494949` (`Foreground/Neutral/Tertiary`) | ✓ |
| 마우스 올림 | `hover`, `hover_text` | `#7778FD` 1 (`Border/Brand/Primary`) | 배경 `#F3F3FF` (`Surface/Brand/Tertiary`) | 기본과 같음 | 세트만 |
| 선택됨 | `pressed`, `pressed_text` | `#7778FD` 1 | 점 11 `#7778FD` (`Surface/Brand/Primary`) | `15/Medium` **`#2D2D2D`**(기본보다 진해짐) | ✓ |
| 비활성 | `disabled`, `disabled_text` | `#A3A3A3` 1 | 배경 **`#F1F3F6`(토큰 없음)** | **`15/Regular`** `#A3A3A3` | 세트만 |
| 포커스 | 없음 | — | — | — | — |

- 선택됨 + 비활성 조합은 세트에 없습니다.
- `pressed`라는 이름이 "누르는 중"이 아니라 "선택됨"을 뜻합니다.

### 1-3. 크기

| 항목 | 값 |
|---|---|
| 원 | 20 × 20, 테두리 1 |
| 선택 점 | 11 × 11 (원 가운데에서 위치 5, 5) |
| 라벨 포함 높이 | 24 (원은 위아래 가운데) |
| 원과 글자 간격 | 8 |
| 글자 | 15 (Medium, 비활성만 Regular) |
| 크기 종류 | 하나뿐(작게·크게 없음) |

### 1-4. 행 전체가 선택되는 곳

라디오가 쓰인 곳 대부분(표·목록 행, 팝업 왼쪽 메뉴)은 **행 전체**가 선택 대상처럼 보입니다. 행 배경이 `#F3F3FF`로 바뀌고, 팝업 메뉴는 왼쪽에 보라 막대도 생깁니다. 이 행 배경과 막대는 라디오가 아니라 표·목록·메뉴 쪽 모양입니다.

### 1-5. 라디오가 아닌 것 (확인 후 제외)

- **차량관리 리스트뷰의 숨긴 라디오 52개:** 표 행 안에 `visible=false`로 들어 있고 모두 "선택됨"입니다. 화면에 보이지 않아 제외했습니다(이전 후보 조사의 700개에는 포함돼 있었음).
- **모양 검색에 걸린 빨간 원 1개**(14, `#EE293A` 테두리): 라디오가 아닙니다.
- 체크박스(`btn-check`, `checkbox`): Checkbox 조사에서 다룹니다.

### 1-6. 관찰된 특징 (아직 판단하지 않음)

- **같은 컨트롤이 컴포넌트 두 개:** 원만 있는 `btn-radio`와 글자가 붙은 `radiobutton`. `radiobutton` 안에 `btn-radio`가 들어 있습니다.
- **같은 화면 요소를 두 방식으로 만듦:** "반복 재생"이 한 화면은 `radiobutton`, 다른 화면은 `btn-radio` + 일반 글자입니다.
- **선택하면 글자색이 바뀜:** `#494949` → `#2D2D2D`. 비활성은 굵기까지 바뀝니다(Medium → Regular).
- **기본 원 테두리 색의 토큰 이름이 `Border/Neutral/Disabled`:** 비활성이 아닌 기본 상태에 쓰이고 있습니다(IconButton 때 "Radio 만들 때 정리"로 미룬 항목, 567곳).
- **선택 점 11:** 홀수라 20 원 안에서 정확히 가운데에 놓이지 않습니다(위치 5, 5).
- **포커스 표시 없음**, 오류 상태 없음.
- **비활성·마우스 올림은 세트에만 있고 시안 화면에는 없습니다.**
- **이름 오타:** `defualt`.
- **팝업 왼쪽 메뉴의 글자가 모두 "비디오 + 오디오":** 6개 선택지 글자가 같아 실제 문구를 알 수 없습니다(시안 미완성으로 보임).

### 1-7. 색 대비 (흰 배경 기준, 그림 요소 3:1)

## 2. 시중 디자인 시스템의 라디오

| 항목 | Material 3 | Apple HIG | shadcn/ui |
|---|---|---|---|
| 부르는 이름 | Radio button. 묶음은 `RadioGroup` | Radio button(macOS). iOS에는 라디오가 없음 | Radio Group(`RadioGroup` + `RadioGroupItem`, Radix 기반) |
| 언제 쓰는지 | 여러 선택지 중 하나, 모든 선택지를 펼쳐 보여야 할 때. 접어도 되면 드롭다운 | 서로 배타적인 선택지 2~5개. 그보다 많으면 팝업 버튼 | 하나만 고르는 선택지 |
| 구성 | 선택 아이콘, 선택 안 됨 아이콘, 옆 글자 | 작은 원 + 글자. 선택지마다 자기 글자 | 원(테두리) + 가운데 점, 글자는 별도 `Label` |
| 크기 | 문서에 원 크기 없음. 최소 터치 영역은 테마의 최소 터치 크기 | 문서에 크기 없음 | 원 16, 점 8, 묶음 간격 12 |
| 색 | 선택 안 됨 `onSurface`(진한 회색), 선택 `primary` | 시스템 색 | 테두리 `input` 색, 점 `primary` |
| 상태 | Enabled, Disabled, Hover, Focused, Pressed × 선택/선택 안 됨 | 선택(채운 원), 선택 안 됨(빈 원). 혼합 상태(대시)는 가능하지만 드묾 → 체크박스 권장 | 선택, 키보드 포커스(링 3px), 오류(`aria-invalid`, 빨간 테두리·링), 비활성(투명도 50%) |
| 묶음 배치 | `RadioGroup`이 선택을 하나로 유지 | 가로 배치 때 가장 긴 글자 폭에 맞춰 같은 간격 | 세로 그리드, 간격 12 |
| 하나짜리 켜고 끄기 | — | 켜고 끄는 설정 하나는 체크박스. 반대 두 상태가 체크박스로 분명하지 않을 때만 라디오 두 개 | — |
| iOS 대안 | — | 목록에서 하나 고르기는 체크 표시 목록, 몇 개는 세그먼트, 많으면 팝업·피커(일반적 관행) | — |
| 접근성 | 글자가 자동으로 스크린리더 이름이 됨 | — | Radix가 선택 상태, 키보드 이동, ARIA 속성 처리 |

**공통점:**
- 선택은 **묶음 단위**입니다. 하나를 고르면 나머지는 자동으로 풀립니다.
- 선택된 원은 브랜드(primary) 색, 선택 안 된 원은 **진한** 회색 테두리입니다.
- 선택지가 많으면(5개 넘게) 드롭다운·팝업으로 바꾸라고 권합니다.
- 켜고 끄는 설정 하나에는 라디오가 아니라 체크박스나 스위치를 씁니다.

## 3. 시중에는 보통 있는데 우리 시안에 없는 것

| 항목 | 시중 | 우리 시안 |
|---|---|---|
| 묶음 제목 | Apple·Material 모두 묶음에 제목을 둠(코드에서는 `fieldset`/`legend` 또는 `role="radiogroup"` 이름) | "반복 재생"만 제목이 있음. 표·메뉴의 라디오는 묶음 제목 없음 |
| 포커스 상태 | 세 시스템 모두 | 없음 |
| 오류 상태 | shadcn(`aria-invalid`) | 없음 |
| 선택 안 된 원의 충분한 대비 | Material `onSurface`(진한 색) | `#A3A3A3` 2.52로 미달 |
| 선택됨 + 비활성 | Material(선택/선택 안 됨 × 비활성) | 없음 |
| 키보드 이동(묶음 안 화살표) | shadcn(Radix) 기본 | 정의 없음 |
| 가로 배치 간격 규칙 | Apple: 가장 긴 글자 폭에 맞춘 같은 간격 | 선택지 사이 20 고정 |
| 크기 종류 | 시스템마다 하나 또는 소수 | 하나(20) |
| 글자를 눌러도 선택 | 세 시스템 모두(글자가 라디오의 이름이자 누르는 영역) | 정의 없음 |
