# Table 조사 (결정 전, 조사 결과만)

목록 화면의 표(머리 칸·본문 칸·행 상태)를 조사했습니다.

- 기준일: 2026-10-26
- 조사 범위: 시안 화면의 외부 라이브러리 `Table.Title`(머리 칸), `Table.Cell.Text`(글자 칸), `default`(여러 부품이 들어가는 칸, 상태 3개)와 그 안의 부품.

## 1. 우리 시안의 표

### 1-1. 쓰이는 곳

| 화면 | 표 | 칸 안에 들어가는 것 |
|---|---|---|
| 차량관리 리스트뷰(2화면) | 차량 목록 10행 × 9열 | 글자, 아바타 + 운전자 이름, 위험·경고·주의 라벨 + 글자 + "+N", 예약 시간 + "+N", 행 끝 화살표(상세로 이동), **운행종료 차량은 행 전체 회색 글자** |
| 콘텐츠 관리 | 콘텐츠 목록 9행 | 라디오 + 콘텐츠 종류 아이콘 24 + 이름, 종류, 재생 시간, 용량, 성공·실패 상태 글자 |
| 콘텐츠 그룹 관리 | 그룹 목록 | 라디오 + 폴더 아이콘 + 그룹 이름 + GPS 태그, 숫자·날짜 |
| 콘텐츠 그룹 관리 · 타임라인·GPS 설정 팝업(약 20화면) | 콘텐츠 목록(좁은 표, 열 3개) | 라디오 + 종류 아이콘 + 이름(말줄임 …), 종류("비디오 + 오디오"는 두 줄), 시간·반경 |
| 할당 및 실행(5화면) | 콘텐츠 그룹·차량 목록 | 라디오 + 이름 + 태그, 차량 카드 |

- 칸 사용: `default` 약 830개, `Table.Cell.Text` 약 740개, `Table.Title` 47개 · 15화면(`05_컴포넌트_후보.md`의 1,619개).
- **표가 열(세로 줄) 단위로 만들어져 있습니다.** 열마다 세로 프레임(`ContentsType`, `Contentsname` 등) 안에 칸을 10개씩 쌓았습니다. 그래서 "행 상태"(마우스 올림·선택)를 칸마다 따로 바꿔야 합니다.
- 선택된 행: 연보라 배경 + 라디오 선택. 이 모양은 Radio 계약의 알려진 문제 2번("선택된 행 모양은 Table에서 정함")입니다.

### 1-2. 칸 모양

| 칸 | 높이 | 좌우 여백 | 배경 | 아래 선 | 글자 |
|---|---|---|---|---|---|
| 머리 칸 `Table.Title` | 56 | 24 | `#F9F9F9` | `#767676` 1 | `#494949` `15/Medium` |
| 글자 칸 `Table.Cell.Text` | 56 | **20** | 흰색 | `#E5E5E5` 1 | `#494949`(51)·`#767676`(4)·`#2D2D2D`(8) `15/Medium` |
| 부품 칸 `default` | 56 | 24 | 흰색 | `#E5E5E5` 1 | `#2D2D2D` `15/Medium`(약 800), 비활성 행 `#A3A3A3` |

### 1-3. 행 상태 (`default` 세트)

| 상태 | 배경 | 시안 화면 |
|---|---|---|
| `Default` | 흰색 | ✓ |
| `hover` | `#F1F5FB` (`Navy0`) | 세트만 |
| `selected` | `#F3F3FF` (`Purple0`) | ✓ |
| 비활성(운행종료 차량) | 흰색, 글자만 `#A3A3A3` | ✓(상태가 아니라 글자색 덮어쓰기) |

### 1-4. 칸 안 부품 배치 (`default`)

라디오 20 → (간격 16) → [종류 아이콘 24 · 아바타 32 · 글자 · 버튼] (간격 8) → (간격 20) → 태그. 쓰지 않는 부품은 숨김.

| 조합 | 개수 |
|---|---|
| 글자만 | 241 |
| 라디오 + 종류 아이콘 + 글자 | 약 530 |
| 라디오 + 폴더 + 글자 (+ GPS 태그) | 약 45 |
| 성공·실패 상태 글자만 | 18 |
| 디스플레이 아이콘 + 글자 | 10 |
| 버튼만(`Component 77`, 이전 Plain 버튼) | 9 |

### 1-5. 관찰된 특징 (아직 판단하지 않음)

- **열 단위로 쌓은 표**라 행 상태를 바꾸려면 열마다 칸을 바꿔야 합니다.
- **글자 칸 좌우 여백이 둘**(20·24), **본문 글자색이 셋**(`#2D2D2D`·`#494949`·`#767676`).
- **본문 글자는 모두 `15/Medium`**입니다(시안 약 800곳).
- **비활성 행은 상태가 아니라 글자색 덮어쓰기**입니다.
- **넘치는 글자:** 팝업 표는 이름을 말줄임(…)하고, 종류 칸은 두 줄로 넘깁니다.
- **행 끝 화살표**(차량관리)는 행을 누르면 상세로 간다는 표시입니다.
- **아바타**(운전자)는 외부 UI 키트 `Avatar`이고, 우리 후보 목록에 없습니다.
- 정렬(머리 칸 누르기), 체크박스 열(여러 행 선택), 빈 표 모양은 이 컴포넌트들에 없습니다(빈 목록은 화면이 따로 그림: 콘텐츠 없음 화면).

## 2. 시중 디자인 시스템

| 항목 | Material 3 | Apple HIG | shadcn/ui |
|---|---|---|---|
| 이름 | Data table(M2 문서, M3는 정식 컴포넌트 없음) | Tables(macOS: 열·정렬) | Table(+ 예시 Data Table) |
| 행 높이 | 52 기본, 조밀 36 | 시스템 | 칸 여백 8, 높이 40 |
| 머리 | 정렬 화살표, 체크박스 | 열 머리 누르면 정렬 | `TableHead` 글자 Medium |
| 행 상태 | 마우스 올림, 선택(체크박스) 배경 | 선택 강조 | 마우스 올림 `muted/50`, 선택 `data-state=selected` 배경 `muted` |
| 선 | 행 사이 선 | 줄무늬 선택 가능 | 행 아래 선 |
| 넘치는 글자 | 말줄임 | 말줄임 | 줄바꿈 안 함(`whitespace-nowrap`) |

**공통점:** 표는 행 단위(머리 행 + 본문 행)로 만들고, 행 상태(마우스 올림·선택)는 행 전체에 한 번에 적용합니다. 글자는 한 줄에 말줄임이 기본입니다.

## 3. 시중에는 있는데 우리 시안에 없는 것

| 항목 | 우리 시안 |
|---|---|
| 정렬 | 없음 |
| 체크박스 열(여러 행 선택, 전체 선택) | 없음 |
| 행 단위 구조 | 열 단위 |
| 빈 표·불러오는 중 모양 | 화면에 따로(빈 표) / 없음(불러오는 중) |
