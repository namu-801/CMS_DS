# Checkbox 조사 (결정 전, 조사 결과만)

여러 선택지를 각각 켜고 끄는 컨트롤(체크박스)을 조사했습니다. 하나만 고르는 컨트롤은 Radio(`19_라디오_계약.md`)가 맡습니다.

- 기준일: 2026-10-19
- 조사 범위: 시안 화면 54개의 인스턴스(외부 라이브러리), 로컬 세트 `btn-check`(node `53:19465`), `checkbox`(node `53:19495`). 새로 만든 로그인 v2 화면은 제외
- 조사 방법: 이름(`check`)으로 찾은 뒤, 모양(14~24 크기의 테두리 있는 사각형)으로 한 번 더 훑었습니다. 컴포넌트가 아닌 사각형은 0개였습니다.
- 화면에 보이는 것만 셌습니다(숨긴 레이어 0개).

## 1. 우리 시안의 체크박스

### 1-1. 쓰이는 곳

| 쓰이는 곳 | 지금 만든 방식 | 글자 | 상태 | 사용 |
|---|---|---|---|---|
| 로그인 "이메일 기억하기" | 꺼짐은 `checkbox`(글자 포함), 켜짐은 **다른 컴포넌트** `Checkbox_on_text` | `15/Medium`(꺼짐) / **`15/Regular`**(켜짐), 둘 다 `#111111`로 덮어씀 | 꺼짐(입력 전), 켜짐(입력 중·오류) | 3 · 3화면 |
| 회원가입 약관 동의 | `btn-check`(상자만 있는 쪽) + **일반 글자 여러 개**(`Checkbox_off_text` 프레임) | `15/Regular` `#2D2D2D`, "이용약관"·"개인정보처리방침"만 `15/Bold` | 꺼짐(입력 전·잘못된 정보), 켜짐(정확한 정보) | 3 · 3화면 |

- 합계 6개, 화면 6개. 표(목록)에는 체크박스가 없습니다(이전 후보 조사의 "표"는 확인 결과 없음).
- 회원가입은 약관에 동의(켜짐)해야 아래 "가입" 버튼이 활성으로 바뀝니다.
- 모든 곳이 글자와 함께 쓰이고, 체크박스만 홀로 쓰인 곳은 없습니다.

### 1-2. 상태별 모양 (로컬 세트 기준)

| 상태 | Figma 이름 | 상자 테두리 | 상자 배경 | 체크 표시 | 글자 | 시안 화면 |
|---|---|---|---|---|---|---|
| 꺼짐(기본) | `default`, `default_text` | `#A3A3A3` 1 | 없음 | 없음 | `15/Medium` `#494949` | ✓ |
| 마우스 올림 | `hover`, `hover_text` | `#7778FD` 1 (`Border/Brand/Primary`) | `#F3F3FF` (`Interaction/Brand/SubtleHover`) | 없음 | 기본과 같음 | 세트만 |
| 켜짐 | `pressed`, `pressed_text` | 없음 | `#7778FD` (`Surface/Brand/Primary`) | 흰색 선 2(`Foreground/Neutral/Inverse`), 직접 그린 선(7×4) | `15/Medium` **`#2D2D2D`**(기본보다 진해짐) | ✓ |
| 비활성 | `disabled`, `disabled_text` | `#A3A3A3` 1 | **`#F1F3F6`(토큰 없음)** | 없음 | **`15/Regular`** `#A3A3A3` | 세트만 |
| 포커스, 혼합(일부만 선택), 오류 | 없음 | — | — | — | — | — |

- 켜짐 + 비활성 조합은 세트에 없습니다.
- `pressed`라는 이름이 "켜짐"을 뜻합니다(Radio와 같은 문제).
- `#A3A3A3` 테두리는 지난번에 삭제한 `Border/Neutral/Disabled`와 같은 색입니다.

| 항목 | 값 |

| 체크 표시 | 선 2, 7 × 4 크기(상자 안 6, 10 위치). 아이콘 세트의 `Icon/Action/Check`(20 하나만 있음)가 아니라 직접 그린 선 |
| 글자 포함 높이 | 24 (상자는 위아래 가운데) |
| 상자와 글자 간격 | 8 |

### 1-5. 관찰된 특징 (아직 판단하지 않음)

- **같은 체크박스가 켜짐/꺼짐에 따라 다른 컴포넌트:** 로그인 "이메일 기억하기"는 꺼짐은 `checkbox`, 켜짐은 `Checkbox_on_text`입니다. 그래서 켜면 글자 굵기도 Medium → Regular로 바뀝니다.
- **같은 컨트롤이 세 가지 방식:** 상자만(`btn-check`), 글자 포함(`checkbox`), 켜짐 전용(`Checkbox_on_text`). 회원가입은 상자만 쓰고 글자를 따로 놓았습니다.
- **글자 안에 굵은 부분:** 약관 동의 글자는 "이용약관", "개인정보처리방침"만 굵습니다. 눌러서 약관을 여는 링크 모양은 아니고 굵기만 다릅니다.
- **기본 테두리 대비 부족:** `#A3A3A3` 2.52(기준 3:1 미달). Radio와 같은 문제입니다.
- **체크 표시를 직접 그린 선:** 아이콘 세트에 `Icon/Action/Check`(20 하나, 안쪽 그림 14×10)가 있지만 쓰지 않았습니다. 선 굵기 2를 선 그대로 둔 것(outline 변환 안 함)이라 크기를 바꾸면 굵기가 그대로입니다.
- **포커스·혼합·오류 상태 없음**, 비활성·마우스 올림은 세트에만 있습니다.
- **시안 글자색 덮어쓰기:** 로그인은 세트 기본 글자색(`#494949`)을 `#111111`로 바꿔 썼습니다.
- **비활성 배경만 토큰 밖 색**(`#F1F3F6`).

### 1-6. 색 대비 (흰 배경 기준, 그림 요소 3:1)

| 요소 | 색 | 대비 | 결과 |
|---|---|---|---|
| 꺼짐 상자 테두리 | `#A3A3A3` | 2.52 | **미달** |
| 켜짐 상자(보라 채움) | `#7778FD` | 3.57 | 통과 |

| 글자 | `#2D2D2D` / `#111111` | 13.77 / 18.88 | 통과 |

## 2. 시중 디자인 시스템의 체크박스

| 항목 | Material 3 | Apple HIG | shadcn/ui |
|---|---|---|---|
| 부르는 이름 | Checkbox | Checkbox(macOS) | Checkbox(Radix 기반) |
| 구성 | 상자(container) + 체크 아이콘 | 작은 사각형 + 오른쪽 글자 | 상자 + 체크 아이콘(14), 글자는 별도 `Label` |
| 크기 | 문서에 상자 크기 없음. 최소 터치 영역은 테마 최소 터치 크기 | 문서에 없음 | 상자 16, 모서리 4 |
| 모양 | 항상 둥근 사각형(모양 바꾸기 미지원) | 사각형 | 모서리 4 |
| 값 | 체크됨, 체크 안 됨, **혼합(indeterminate)** | 꺼짐(빈 상자), 켜짐(체크), **혼합(대시)** | 체크됨, 체크 안 됨(Radix는 혼합 지원, shadcn 기본 모양에는 없음) |
| 상호작용 상태 | Enabled, Disabled, Hover, Focused, Pressed | — | 키보드 포커스(링 3px), 비활성(투명도 50%) |
| 오류 | 있음(체크됨·안 됨·혼합 모두 오류 모양 가능) | — | 있음(`aria-invalid`, 빨간 테두리·링) |
| 색 | 상자 `onSurface`(진한 회색), 체크 `onPrimary`, 켜짐 `primary` | 시스템 색 | 테두리 입력칸 색, 켜짐은 배경·테두리 `primary` + 체크 `primary-foreground` |
| 부모·자식 | 자식이 모두 켜지면 부모 켜짐, 일부면 혼합, 부모를 바꾸면 자식 모두 바뀜 | 하위 체크박스는 들여쓰기, 일부만 켜지면 부모는 혼합 | — |
| 글자 | 옆 글자, 스크린리더 이름이 됨 | 오른쪽에 글자. 편집 체크리스트에서는 글자 없이도 가능. 묶음 관계가 불분명하면 묶음 제목 | 별도 `Label`과 연결 |
| 언제 쓰는지 | — | 켜고 끄는 설정 하나, 여러 개 고르기. 서로 배타적이면 라디오, 5개 넘으면 팝업 | — |

**공통점:**
- 켜짐은 브랜드(primary) 색으로 **상자를 채우고** 그 위에 대비되는 체크를 올립니다.
- 꺼짐 상자는 **진한** 회색 테두리입니다.
- **혼합(일부만 선택) 상태**를 정식 값으로 둡니다(전체 선택 같은 부모 체크박스용).
- 글자가 체크박스의 이름이자 누르는 영역입니다.

## 3. 시중에는 보통 있는데 우리 시안에 없는 것

| 항목 | 시중 | 우리 시안 |
|---|---|---|
| 혼합(일부만 선택) 상태 | 세 시스템 모두(Material·Apple 정식, Radix 지원) | 없음. 전체 선택이 있는 표도 시안에 없음 |
| 포커스 상태 | 세 시스템 모두 | 없음 |
| 오류 상태 | Material, shadcn | 없음. 회원가입 약관은 동의 안 하면 버튼만 비활성 |
| 켜짐 + 비활성 | Material | 없음 |
| 진한 꺼짐 테두리 | Material `onSurface` | `#A3A3A3` 2.52 |
| 둥근 모서리 | Material·shadcn | 직각(모서리 0) |
| 체크 아이콘을 아이콘 세트에서 | shadcn은 아이콘 컴포넌트 사용 | 직접 그린 선 |
| 부모·자식(들여쓰기) 규칙 | Material·Apple | 없음 |
| 묶음 제목 | Apple(관계가 불분명할 때) | 체크박스 묶음이 없음(모두 하나짜리) |
