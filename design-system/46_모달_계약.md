# Modal 계약 (Contract) — Dialog(입력 팝업) · AlertDialog(확인 모달)

화면 위에 떠서 입력을 받거나 결과를 알리는 팝업의 사용 규칙입니다.

- 기준일: 2026-10-27
- 근거: Figma `Modal Header`·`Modal Footer`·`Alert Dialog`, 코드 `src/components/Modal/`, 조사 `33_모달_조사.md`, 스펙 `34_모달_스펙안.md`(5~9절), 대응표 `39_코드구현_대응표.md`
- 상태: Figma 완료, 코드 구현 완료(포커스 가두기·되돌리기 확인)

**핵심 원칙:** 입력 팝업은 "보라 머리 + 본문 + 취소·저장", 확인 모달은 "상태 그림 + 제목 + 설명 + 가운데 버튼". 크기·버튼 너비는 토큰으로 정해져 있습니다. 삭제를 최종 확인하는 버튼만 빨강입니다.

### 2-2. 코드

```ts
interface DialogProps {
  open: boolean; onClose: () => void;           // 취소·Esc
  title: string;
  size?: "small" | "medium" | "large";          // 기본 "small"
  children: ReactNode;                           // 본문
  confirmLabel?: string;                         // 기본 "저장"
  onConfirm: () => void; confirmDisabled?: boolean;
  cancelLabel?: string;                          // 기본 "취소"
}
interface AlertDialogProps {
  open: boolean;
  type: "warning" | "success" | "error";
  title: string; description?: string;
  confirmLabel: string; onConfirm: () => void;
  cancelLabel?: string; onCancel?: () => void;   // 주면 버튼 2개
  destructive?: boolean;                         // 기본: warning + 버튼 2개면 true
}
```

## 3. Figma 속성 ↔ 코드 Prop 대응표

| Figma | 코드 | 대응 |
|---|---|---|
| `Modal Header` `Title` | `title` | 1:1 |
| 팝업 크기 규칙 | `size` | 규칙 → Prop |
| 본문 | `children` | 1:1 |
| `Modal Footer` 버튼 글자 | `cancelLabel`·`confirmLabel` | 1:1 |
| `Alert Dialog` `Type` | `type` | 1:1 |
| `Buttons` Two / One | `cancelLabel` 유무 | Variant → 유무 |
| `Title` · `Description`+`Description Text` | `title` · `description?` | 둘 → 하나 |
| 경고 + 2개의 Destructive 버튼 | `destructive`(기본 규칙 자동) | 규칙 → Prop |
| (없음) | `open`, `onClose`·`onCancel`, 포커스 가두기, Esc | 코드에만 |

**일대일이 아닌 이유:** 입력 팝업은 본문이 팝업마다 달라 Figma에서는 머리·하단만 컴포넌트로 두고 틀은 크기 규칙으로 정했습니다. 코드는 틀 전체를 `Dialog` 하나로 그립니다. 버튼 개수는 취소 버튼이 있는지로 정해지므로 별도 값이 필요 없습니다.

## 5. 사용 규칙

1. 입력을 받으면 `Dialog`, 알리거나 확인을 받으면 `AlertDialog`.
2. 팝업 크기는 소·중·대 세 가지만.
3. 삭제를 최종 확인하는 버튼만 빨강(`destructive`). 다른 확인은 보라.
4. 입력 팝업은 덮개를 눌러도 닫히지 않습니다(입력 보호). 취소·Esc로 닫습니다.
5. 확인 모달은 버튼으로만 닫습니다(취소가 있으면 Esc = 취소).
6. 입력 팝업에 닫기(×)는 두지 않습니다(결정 D).

## 6. 제대로 썼는지 확인하는 방법

- Figma: 이전 `Modal-topbar`·`Modal/Btn`이 아닌지, 확인 모달 버튼 너비가 100/216인지(직접 바꾸지 않았는지), 삭제 확인이 `Destructive`인지.

```js
const KEYS = ["716ec663c586b7d4b4aff32674d34f40099a2656", "e000d15de0ae13cc55b445161035fdf87ebe0690", "7039632c6f6076184124e0a837d6142d6e3eee30"];
const old = [], resized = [];
for (const inst of figma.currentPage.findAllWithCriteria({ types: ["INSTANCE"] })) {
  const main = await inst.getMainComponentAsync(); const set = main?.parent?.type === "COMPONENT_SET" ? main.parent : main;
  if (["Modal-topbar", "Modal/Btn"].includes(set?.name)) { old.push(inst.id); continue; }
  if (!KEYS.includes(set?.key)) continue;
  for (const b of inst.findAll(n => n.type === "INSTANCE" && n.mainComponent?.parent?.name === "Button")) if (!b.boundVariables?.width) resized.push(`${inst.id}: 버튼 너비 직접값`);
}
return { old, resized };
```

- 코드: `npm run typecheck`(없는 `size`·`type`, `title` 누락 컴파일 오류), `npm test`(닫힘이면 안 그림, 이름·`aria-modal`, 포커스 안으로, 취소·Esc·저장, alertdialog 설명 연결, 버튼 1·2개, Destructive 기본 규칙, Esc 규칙).
- 손으로: 열면 포커스가 팝업 안, Tab이 팝업 밖으로 나가지 않음, 닫으면 연 버튼으로 돌아감, 스크린리더가 "대화상자, 제목"을 읽음.


| 반례 | 왜 문제인지 | 바르게 |

## 9·10. 동기화 · 알려진 문제

- 팝업 크기·버튼 너비를 바꾸면 Foundation `Size/Width/Dialog*`·`Size/Height/Dialog*`를 고치고 `npm run tokens`.
- ⚑ 화면 높이가 팝업보다 낮으면 팝업이 줄어들고 본문이 스크롤됩니다(의도).
- ⚑ 시안 화면에 이전 `Modal-topbar`·직접 그린 확인 모달이 그대로 — 화면 교체 단계에서 바꿈.
