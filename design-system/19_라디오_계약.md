# Radio 계약 (Contract)

이 문서는 디자인(Figma)과 코드가 함께 지켜야 하는 Radio(여러 선택지 중 하나 고르기) 사용 규칙입니다. 사람과 AI 모두 이 문서를 기준으로 쓰고 검사합니다.

- 기준일: 2026-10-17
- 근거: Figma `Radio` 세트, 코드 `src/components/Radio/`, 조사 `17_라디오_조사.md`, 스펙 결정 `18_라디오_스펙안.md`, 토큰 `04_이름규칙.md`
- 상태: Figma 6개 Variant 완료, 코드 구현 완료(타입 검사·테스트 통과, 브라우저에서 상태·키보드 확인)
- 여러 개를 고르는 것은 Checkbox(제작 예정), 선택지가 많으면(6개 이상) Dropdown(제작 예정)을 씁니다.
- ⚑는 확정되지 않았거나 알려진 문제입니다. 10절에 모아 두었습니다.

**핵심 원칙:** 라디오는 항상 **묶음**으로 씁니다. 한 묶음에서 선택은 하나뿐이고, 묶음과 선택지 모두 이름(글자)이 있어야 합니다. 화면에 글자를 숨겨도 이름은 남깁니다.

### 2-2. 코드 Prop

```ts
type RadioGroupOrientation = "horizontal" | "vertical";

interface RadioGroupProps {
  label: string;                          // 필수. 묶음 이름
  hideLabel?: boolean;                    // 기본 false. 화면에서만 숨김
  value?: string;                         // 선택 값(제어 방식)
  defaultValue?: string;                  // 처음 선택 값(내부에서 관리)
  onValueChange?: (value: string) => void;
  orientation?: RadioGroupOrientation;    // 기본 "horizontal"
  disabled?: boolean;                     // 기본 false. 묶음 전체
  name?: string;                          // 폼 제출 이름. 없으면 자동
  children: ReactNode;                    // Radio들
  className?: string;                     // 배치용만
}

interface RadioProps {
  value: string;                          // 필수. 이 선택지의 값
  label: string;                          // 필수. 선택지 글자 = 이름
  hideLabel?: boolean;                    // 기본 false. 화면에서만 숨김, 클릭 영역 32
  disabled?: boolean;                     // 기본 false. 이 선택지만
  className?: string;                     // 배치용만
}
```

| Prop | 넣을 수 있는 값 | 기본값 | 그 밖의 값을 넣으면 |
|---|---|---|---|
| `RadioGroup` `label` | 묶음 이름 글자 | 없음(필수) | 빠뜨리면 컴파일 오류 |
| `orientation` | `"horizontal"`, `"vertical"` | `"horizontal"` | 컴파일 오류 |
| `Radio` `value` | 글자 | 없음(필수) | 빠뜨리면 컴파일 오류 |
| `Radio` `label` | 선택지 글자 | 없음(필수) | 빠뜨리면 컴파일 오류 |
| `hideLabel`, `disabled` | `true` / `false` | `false` | — |
| `size`, `style` | 받지 않음 | — | 컴파일 오류 |
| `RadioGroup` 밖의 `Radio` | — | — | 실행할 때 오류("Radio는 RadioGroup 안에서만 쓸 수 있습니다.") |

## 3. Figma 속성 ↔ 코드 Prop 대응표

| Figma | 코드 | 대응 | 값 대응 |
|---|---|---|---|
| `Selected=Off` / `On` | `RadioGroup` `value`·`defaultValue` + `Radio` `value` | 상태 → 묶음 값 | 묶음 값과 같은 `value`의 라디오가 On |
| `State=Default` | (없음) | 상태 → 없음 | 아무것도 안 주면 Default |
| `State=Hover` | CSS `:hover` | 상태 → 브라우저 | Prop 없음 |
| `State=Disabled` | `Radio` `disabled` 또는 `RadioGroup` `disabled` | 상태 → Boolean(두 곳) | 선택지 하나 또는 묶음 전체 |
| `Label` | `hideLabel` | 뜻이 반대 | `Label` 켬 → `hideLabel` 안 줌, 끔 → `hideLabel` |
| `Label Text` | `label` | 1:1(코드는 필수) | `반복 재생 함` → `label="반복 재생 함"` |
| (없음) | `RadioGroup` `label`, `hideLabel` | 코드에만 | 묶음 이름 |
| (없음) | `orientation` | 코드에만(Figma는 화면 배치) | 가로 간격 20, 세로 간격 12 |
| (없음) | `onValueChange`, `name` | 코드에만 | 동작·폼 |
| (없음) | 포커스 링, 글자 끈 라디오의 클릭 영역 32 | 코드에만 | |

### 3-1. 일대일이 아닌 이유

1. **선택 여부는 라디오가 아니라 묶음이 정합니다.** 하나를 고르면 나머지가 자동으로 풀려야 하므로, 선택 값은 `RadioGroup` 하나가 들고 있습니다. 각 라디오는 자기 `value`가 묶음 값과 같으면 On으로 보입니다. Figma는 화면 설계서에 두 모양을 보여 주려고 Variant로 둡니다.
2. **`RadioGroup`은 코드에만 있습니다.** Figma에서는 묶음 컴포넌트를 만들지 않고 화면에서 나란히 놓기로 했습니다(2026-10-17). 코드에서는 묶음 이름, 하나만 선택, 키보드 화살표 이동을 맡을 묶음이 반드시 필요합니다. 브라우저 기본 라디오를 같은 `name`으로 묶어서 화살표 이동과 스크린리더 읽기가 기본으로 됩니다.
3. **Hover는 Prop이 아닙니다.** 브라우저가 정하는 상태입니다(Button·TextField와 같음).
4. **Disabled는 두 곳에 있습니다.** 선택지 하나만 막을 때와 묶음 전체를 막을 때가 다르기 때문입니다. 묶음이 막히면 모든 라디오가 막힙니다.
5. **글자는 코드에서 항상 필요합니다.** 표 행처럼 글자를 숨겨도 스크린리더가 무엇을 고르는지 읽어야 합니다. 그래서 `label`은 필수이고 숨길 때만 `hideLabel`을 씁니다. Figma `Label`과 `hideLabel`은 뜻이 반대입니다(TextField와 같은 방식).
6. **포커스 링과 클릭 영역 32는 코드에만 있습니다.** 키보드 사용자와 작은 원의 누르기 편의를 위한 것이고, 화면 모양은 Figma와 같습니다.

## 4. 시안 쓰임별 정답 조합

새 화면도 이 표의 조합을 그대로 씁니다. 표에 없는 쓰임이 생기면 가장 가까운 줄을 따르고, 스펙 문서에 줄을 추가합니다.

| 쓰임 | Figma | 코드 |
|---|---|---|
| "반복 재생" 안함/함(팝업, 할당 화면) | `Label` 켬, 가로로 나란히(간격 20). 묶음 제목 "반복 재생"은 화면 글자로 왼쪽에 배치 | `<RadioGroup label="반복 재생" hideLabel>` + `<Radio value="off" label="반복 재생 안함" />` … (화면 제목 글자는 `aria-hidden`) |
| 표·목록 행 선택(콘텐츠, 콘텐츠 그룹, 할당 목록) | `Label` 끔, `Label Text`에 그 행의 이름 | `<RadioGroup label="콘텐츠 선택" hideLabel>` + 행마다 `<Radio value={id} label={행 이름} hideLabel />` |
| 콘텐츠 업로드 팝업 왼쪽 메뉴(콘텐츠 종류) | `Label` 켬, 세로로 메뉴 행 안에. 선택된 행 배경·보라 막대는 메뉴 쪽 모양 ⚑ | `<RadioGroup label="콘텐츠 종류" hideLabel orientation="vertical">` |

## 5. 사용 규칙

1. 라디오는 2개 이상을 한 묶음으로 씁니다. 하나만 놓고 켜고 끄는 용도로 쓰지 않습니다(그때는 Checkbox).
2. 한 묶음에서 `Selected=On`은 하나만 둡니다. 처음부터 하나가 선택된 채로 시작합니다.
3. 선택지는 2~5개. 6개 이상이면 Dropdown을 씁니다.
4. 선택지 글자는 짧게, 서로 분명히 구별되게 씁니다(예: "반복 재생 안함" / "반복 재생 함"). 너비는 글자에 맞춰 자동이며 인스턴스 너비를 직접 줄이지 않습니다.
5. 가로 묶음은 선택지 사이 `Spacing/Scale/20`, 세로 묶음은 `Spacing/Scale/12`로 놓습니다.
6. 묶음 제목은 화면에 두는 것이 좋습니다. 화면에 제목이 없어도 코드에는 `RadioGroup label`을 줍니다.
7. 글자를 끈 라디오(표 행)도 `Label Text`에 그 행을 가리키는 글자를 적습니다. 코드에서 이 글자가 이름이 됩니다.
8. 화면 시안에는 `Default`와 `Disabled`를 씁니다. `Hover`는 상호작용 설명용 프레임에만 씁니다.
9. 선택된 행의 배경색·막대는 라디오가 아니라 표·목록·메뉴가 정합니다. 라디오 인스턴스의 색을 바꿔 행 모양을 흉내 내지 않습니다.

## 6. 제대로 썼는지 확인하는 방법

### 6-1. Figma

**눈으로 확인**
- [ ] 레이어 패널에서 라디오가 `Radio` 인스턴스(◇)입니다. 이전 `btn-radio`, `radiobutton`이 아닙니다.
- [ ] 한 묶음에서 선택(점)이 하나만 있습니다.
- [ ] 글자를 끈 라디오의 `Label Text`가 기본값 "선택지"가 아니라 행의 이름입니다.
- [ ] 인스턴스 너비를 직접 줄여 글자가 넘친 곳이 없습니다.
- [ ] 인스턴스 메뉴의 "Reset all changes"를 눌러도 글자·켜고 끄기 말고는 바뀌지 않습니다.

**스크립트로 확인(Figma 플러그인 API)**

```js
const RADIO_SET_KEY = "561050770ae7a49159623c81995d79360f8f5aec";
// 허용: 글자(속성), 켜고 끄기, 레이어 이름. 너비·색 덮어쓰기는 문제
const ALLOWED = new Set(["characters", "visible", "name", "componentProperties"]);
const problems = [], defaultText = [], multiSelected = [];
const onByParent = new Map();
for (const inst of figma.currentPage.findAllWithCriteria({ types: ["INSTANCE"] })) {
  const main = await inst.getMainComponentAsync();
  if (main?.parent?.type !== "COMPONENT_SET" || main.parent.key !== RADIO_SET_KEY) continue;
  for (const o of inst.overrides) {
    const bad = o.overriddenFields.filter(f => !ALLOWED.has(f));
    if (bad.length) problems.push(`${inst.name} (${inst.id}): ${bad.join(", ")}`);
  }
  const p = inst.componentProperties;
  const textKey = Object.keys(p).find(k => k.startsWith("Label Text#"));
  if (p[textKey].value === "선택지") defaultText.push(inst.id); // 이름을 안 적음
  if (inst.variantProperties.Selected === "On") onByParent.set(inst.parent.id, (onByParent.get(inst.parent.id) ?? 0) + 1);
}
for (const [parentId, n] of onByParent) if (n > 1) multiSelected.push(`${parentId}: ${n}개 선택`); // 한 묶음에 선택이 여러 개
return { problems, defaultText, multiSelected };
```

`multiSelected`는 같은 부모 프레임 안의 라디오를 한 묶음으로 봅니다. 표 행처럼 행마다 부모가 다르면 행들의 공통 부모를 기준으로 눈으로 확인합니다.

| 라디오 모양을 클래스로 덮어씀 | `grep -rnE "<Radio[^>]*className=\"[^\"]*(border|bg-|color|w-|h-)" src` | 0건 |
| 묶음 밖 Radio | 실행할 때 오류로 막힘 | — |

**손으로 확인(새 화면마다)**
- [ ] Tab 키로 묶음에 들어가면 선택된 라디오로 가고, 포커스 링이 보입니다.
- [ ] 화살표 키로 다른 선택지로 옮기면 선택도 같이 바뀝니다.
- [ ] 선택지 글자를 눌러도 선택됩니다(글자 있는 라디오).
- [ ] 스크린리더(맥 VoiceOver: Cmd+F5)가 묶음 이름, 선택지 이름, "선택됨", "몇 개 중 몇 번째"를 읽습니다.

## 7. 예시

### 7-1. 정상 사용

**Figma**
- 반복 재생: 화면 글자 "반복 재생"(`15/SemiBold`) 오른쪽에 `Radio` 두 개를 간격 20으로. 첫 번째 `On / Default` `반복 재생 안함`, 두 번째 `Off / Default` `반복 재생 함`
- 콘텐츠 표: 각 행 맨 앞에 `Radio` `Label` 끔, `Label Text`에 콘텐츠 이름. 선택된 행만 `Selected=On`

**코드**

```tsx
import { Radio, RadioGroup } from "@/components/Radio";

<RadioGroup label="반복 재생" defaultValue="off">
  <Radio value="off" label="반복 재생 안함" />
  <Radio value="on" label="반복 재생 함" />
</RadioGroup>

// 표 행 선택: 화면에 글자는 없지만 이름은 행 내용으로
<RadioGroup label="콘텐츠 선택" hideLabel value={selectedId} onValueChange={setSelectedId}>
  {contents.map((c) => (
    <Radio key={c.id} value={c.id} label={c.name} hideLabel />
  ))}
</RadioGroup>

// 세로 배치
<RadioGroup label="콘텐츠 종류" orientation="vertical" defaultValue="video">
  <Radio value="video" label="비디오" />
  <Radio value="audio" label="오디오" />
  <Radio value="image" label="이미지" disabled />
</RadioGroup>
```

### 7-2. 시스템을 우회하는 반례

| 반례 | 왜 문제인지 | 바르게 |
|---|---|---|
| Figma: 이전 `btn-radio`를 그대로 씀 | 토큰이 연결돼 있지 않고 테두리 대비가 2.52로 부족함 | `Radio` |
| Figma: 한 묶음에 `Selected=On`을 둘 이상 | 라디오 규칙에 맞지 않음. 개발자가 체크박스로 오해 | 하나만 On. 여러 개 고르기는 Checkbox |
| Figma: 원 테두리·점 색을 직접 칠해 선택된 행처럼 보이게 함 | 토큰이 끊기고 상태와 맞지 않음 | `Selected` 속성으로. 행 배경은 표·목록이 정함 |
| Figma: 글자 끈 라디오의 `Label Text`를 "선택지"로 둠 | 개발자·AI가 이름을 알 수 없음 | 행 이름을 적음 |
| Figma: 인스턴스 너비를 줄여 글자가 넘침 | 글자가 칸 밖으로 나감 | 너비를 자동으로 두고 글자를 짧게 |
| 코드: `<input type="radio" />`를 직접 씀 | 모양·포커스·이름 연결이 없음 | `<Radio>` |
| 코드: `RadioGroup` 없이 `Radio`만 씀 | 실행 오류. 묶음 이름과 하나만 선택이 없음 | `<RadioGroup label=…>`로 감쌈 |
| 코드: `<Radio value="1" label="" hideLabel />` | 이름이 빈 칸이라 스크린리더가 무엇인지 모름 | `label={행 이름}` |
| 코드: 켜고 끄는 설정 하나에 라디오 하나 | 한 번 고르면 끌 수 없음 | Checkbox |
| 코드: 선택지 7개를 라디오로 나열 | 화면이 길어지고 고르기 어려움 | Dropdown |
| 코드: `<Radio className="text-red-500" …>` | 상태별 색이 깨짐 | 색은 바꾸지 않음 |

## 8. 접근성 요구사항

### 8-1. 필수

| 항목 | 요구사항 | 지금 코드 | 근거 |
|---|---|---|---|
| 묶음 이름 | 묶음 전체에 이름 | `role="radiogroup"` + `aria-labelledby`(묶음 제목). `label` 필수 | WCAG 1.3.1, 4.1.2 |
| 선택지 이름 | 각 라디오에 이름 | 네이티브 라디오를 `<label>`로 감싸 글자가 이름이 됨. `hideLabel`이어도 유지 | WCAG 1.3.1, 4.1.2 |
| 선택 상태 | 선택 여부를 기계가 알 수 있음 | 네이티브 `checked` | WCAG 4.1.2 |
| 키보드 | Tab으로 묶음에 들어가고, 화살표로 이동·선택, Space로 선택 | 같은 `name`의 네이티브 라디오(브라우저 기본) | WCAG 2.1.1 |
| 포커스 표시 | 키보드 포커스가 보임 | 2px `Border/Brand/Primary`, 2px 띄움 | WCAG 2.4.7 |
| 클릭 영역 | 최소 24 | 글자 있음: 원 + 글자 전체를 누름. 글자 없음: 원 20을 32로 넓힘 | WCAG 2.5.8 |
| 색만으로 알리지 않음 | 선택이 색 말고도 전달됨 | 점(모양)이 생김 | WCAG 1.4.1 |
| 비활성 | 고를 수 없음 | 네이티브 `disabled`, 클릭해도 값이 바뀌지 않음 | WCAG 4.1.2 |
| 고대비 모드 | 원과 점이 보임 | `forced-colors`에서 시스템 테두리·강조색 | WCAG 1.4.11 |
