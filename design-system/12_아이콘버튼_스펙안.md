# IconButton 스펙안 (제안, 피그마 작업 전)

근거: `11_아이콘버튼_조사.md`. Button 스펙(`09`, `10`)과 같은 규칙·토큰을 이어 씁니다.
⚑는 확인이 필요한 항목입니다.

## 1. 종류와 상태 나누기

| 구분 | 기준 | 해당 항목 |
|---|---|---|
| **종류** | 화면을 설계할 때 고르고, 쓰는 동안 바뀌지 않음 | 스타일(채움·선·틀 없음), 크기, 아이콘, 떠 있는지(지도 위 그림자), 버튼 이름(접근성) |
| **상태** | 사용자 동작이나 화면 로직에 따라 바뀜 | 기본, hover, pressed, 선택(켜짐), 비활성 |
| 화면 로직(아이콘 교체) | 상태에 따라 **아이콘 모양**이 바뀌는 것 | 목록 펼침 ↓ / 접힘 ↑, 비밀번호 보기 / 숨기기, 지도 위치 추가 / 되돌리기 → `Icon`을 바꿔서 표현 |
| 별도 컴포넌트 | 여러 버튼을 묶어 함께 동작 | 하나만 고르는 정렬 묶음(Toggle Group), 숫자 −/값/+ (Number Stepper) → IconButton을 조합해 나중에 만듦 |

헷갈리기 쉬운 것:
- **선택(켜짐)은 상태입니다.** 굵게·정렬처럼 누르면 켜지고 다시 누르면 꺼집니다. 누르는 순간(Pressed)과는 다릅니다.
- **떠 있음(그림자)은 종류입니다.** 지도처럼 바탕 위에 떠 있는 곳에 쓸 때 고르고, 쓰는 동안 바뀌지 않습니다.
- **목록 펼침 화살표는 선택 상태가 아니라 아이콘 교체입니다.** 배경 모양은 그대로 두고 아이콘만 ↓ ↔ ↑로 바뀝니다.

## 2. Component property 제안

컴포넌트 이름은 `IconButton`입니다. 속성 이름은 Button과 맞춥니다.

| 속성 | 타입 | 값 | 기본값 | 다루는 차이 |
|---|---|---|---|---|
| `Style` | Variant | `Primary`, `Outline`, `Ghost` | `Ghost` | 채움 / 선 / 틀 없음 |
| `Size` | Variant | `XSmall`, `Small`, `Medium` | `Small` | 정사각 틀 크기, 아이콘 크기 |
| `State` | Variant | `Default`, `Hover`, `Pressed`, `Selected`, `Disabled` | `Default` | 상호작용 상태 |
| `Icon` | Instance swap | `Icon/*` 세트 | `Icon/Action/Plus` ⚑ | 아이콘 모양 |
| `Floating` | Boolean | 켬 / 끔 | 끔 | 지도 위처럼 떠 있는 곳의 그림자 |
| `Label` | Text(화면에 안 보임) | 버튼 이름. 예: "확대", "알림" | `버튼 이름` | 스크린리더 이름, 툴팁 문구 |

속성으로 만들지 않는 것:
- 모서리: 모든 IconButton이 `Radius/Scale/0`입니다(⚑ 지금 지도 컨트롤은 2).
- 포커스: Button처럼 코드에만 둡니다.
- 아이콘 크기: `Size`가 정합니다.

Variant 수는 3 × 3 × 5 = 45개입니다(Button에서 정한 대로 모든 조합을 만듭니다).

## 3. 최종 스펙

### 3-1. 종류 (`Style`)

| 값 | 지금 시안의 버튼 | 사용 | Default 배경 | 테두리 | 아이콘 |
|---|---|---|---|---|---|
| `Primary` | 지도 위치 추가(Pin) | 23 | `Surface/Brand/Strong` | 없음 | `Foreground/Neutral/Inverse` |
| `Outline` | 텍스트 편집 도구 13종, 순서 이동, 지도 현재 위치·확대·축소, 입력창 안 확인·취소 | 약 150 | `Surface/Neutral/Primary` | `Border/Neutral/Secondary` | `Foreground/Neutral/Secondary` ⚑ |
| **`Ghost`** (기본값) | 상단 바 알림·로그아웃, 목록 펼침, 입력창 안 수정, 파일 지우기, 비밀번호 보기, 새로고침, 닫기 | 약 180 | 없음 | 없음 | `Foreground/Neutral/Quaternary` ⚑ |

- 색은 Button의 같은 Style과 같습니다(Primary는 대비 개선 후 색).
- ⚑ **Outline 아이콘 색:** 지금 시안은 `#767676`(지도·편집 도구)과 `#2D2D2D`(순서 이동·확인·취소)가 섞여 있습니다. Button Outline과 같은 `Foreground/Neutral/Secondary`(`#2D2D2D`)로 맞추는 안입니다.
- ⚑ **Ghost 아이콘 색:** Button Ghost와 같은 `Foreground/Neutral/Quaternary`(`#767676`)입니다. 지금 입력창 안 수정 아이콘(`#A3A3A3`)은 이보다 진해집니다.

### 3-2. 크기 (`Size`)

| 값 | 틀(정사각) | 아이콘 | 지금 시안에서 합쳐지는 크기 |
|---|---|---|---|
| `XSmall` | `Size/Hit/Small` 32 | `Size/Icon/Small` 20 | 20(입력창 안 수정), 24(확인·취소), 틀 없는 20 아이콘(목록 펼침, 파일 지우기) |
| **`Small`** (기본값) | `Size/Hit/Medium` 40 | `Size/Icon/Medium` 24 | 40(지도, 편집 도구), 틀 없는 24 아이콘(상단 바, 비밀번호 보기) |
| `Medium` | `Size/Hit/Large` 48 | `Size/Icon/Medium` 24 | 48(순서 이동) |

- 틀 크기는 이미 있는 `Size/Hit/*` 토큰 3개와 그대로 맞습니다. Button 높이(32·40·48)와도 같아서 나란히 놓으면 높이가 맞습니다.
- **20·24 버튼과 틀 없는 아이콘은 32 틀로 커집니다.** Ghost는 평소에 틀이 안 보이기 때문에 겉모습은 거의 같고, 클릭 영역만 최소 기준(32)을 맞춥니다.
- ⚑ 순서 이동 아이콘은 지금 29(24를 늘림)인데 24로 돌아옵니다. 편집 도구의 −/+ 아이콘은 20에서 24가 됩니다.

### 3-3. 상태 (`State`)

| 값 | 언제 | `Primary` | `Outline` | `Ghost` |
|---|---|---|---|---|
| **`Default`** (기본값) | 평소 | 3-1 표 | 3-1 표 | 3-1 표 |
| `Hover` | 마우스를 올림 | 배경 `Interaction/Brand/PrimaryHover` | 배경 `Interaction/Neutral/Fill` | 배경 `Interaction/Neutral/Fill` |
| `Pressed` | 누르는 중 | 배경 `Interaction/Brand/PrimaryPressed` | 배경 `Interaction/Neutral/FillStrong`, 테두리 `Interaction/Neutral/ActiveBorder` | 같음 |
| `Selected` | 켜져 있음(굵게, 정렬, 위치 추가 모드) | 세 Style 모두 같은 모양: 배경 `Surface/Brand/Tertiary`, 테두리 `Border/Brand/Primary`, 아이콘 `Foreground/Brand/Primary` ⚑ | ← | ← |
| `Disabled` | 지금 쓸 수 없음 | 배경 `Surface/Neutral/Disabled`, 아이콘 `Foreground/Neutral/Inverse` | 배경 `Surface/Neutral/Secondary`, 테두리 `Border/Neutral/Secondary`, 아이콘 `Foreground/Neutral/Subtle` | 아이콘 `Foreground/Neutral/Subtle` |

- hover는 세 가지가 섞여 있던 것을 **배경이 바뀌는 방식 하나**로 맞춥니다. 지금 지도처럼 아이콘이 옅어지는 방식은 없어집니다.
- ⚑ **Selected 모양:** 텍스트 편집 도구의 선택 모양(연보라 배경 + 보라 선)에 아이콘만 보라로 바꿔 더 잘 구분되게 하는 안입니다. 지금 편집 도구는 아이콘이 `#2D2D2D`, 로컬 정렬 세트는 `#5D5FEF`입니다.
- 지도 위치 추가가 켜지면 `State=Selected`로 바꾸고, 아이콘은 화면 로직에서 되돌리기로 바꿉니다.

### 3-4. 떠 있음 (`Floating`)

| 값 | 모양 | 쓰는 곳 |
|---|---|---|
| 끔(기본값) | 그림자 없음 | 일반 화면 |
| 켬 | 그림자(지도 컨트롤의 지금 값: 흐림 2, 아래 1, 검정 15%) | 지도 위 컨트롤 |

- ⚑ 그림자 토큰(Effect Style)이 아직 없습니다. 값 정리 때 정한 그림자 3종 중 첫 번째(흐림 2, 아래 1, 퍼짐 1.16, 15%)와 같아서, 이것을 `Elevation/Low` 같은 이름으로 등록해야 합니다.
- ⚑ 지도 컨트롤의 모서리 2를 다른 버튼처럼 0으로 맞출지 정해 주세요.

### 3-5. 접근성 (제안)

| 항목 | 내용 |
|---|---|
| 이름 | 글자가 없으므로 `Label`이 반드시 필요합니다. 코드에서 `aria-label`이 되고, 마우스를 올렸을 때 툴팁으로도 보입니다. |
| 클릭 영역 | 모든 크기가 32 이상입니다(`Size/Hit/*`). |
| 아이콘 대비 | 아이콘은 그림이라 3:1 이상이면 됩니다(WCAG 1.4.11). Ghost hover(3.61), pressed(3.13), Selected(4.39) 모두 통과합니다. |
| 선택 상태 | 코드에서 `aria-pressed`로 알립니다. |

## 5. 확인이 필요한 항목 (⚑)

1. 기본 Style을 `Ghost`로 할지(가장 많이 쓰임, Material도 Standard가 기본)
2. Outline 아이콘 색을 `#2D2D2D`(Button Outline과 같음)로 맞출지
3. Ghost 아이콘 색을 `#767676`(Button Ghost와 같음)으로 맞출지
4. Selected 아이콘을 보라(`Foreground/Brand/Primary`)로 할지
5. 그림자 토큰 `Elevation/Low` 새로 등록
6. 지도 컨트롤 모서리 2 → 0
7. `Icon` 기본값(`Plus`)
8. 20·24 아이콘 버튼을 32 틀로 키우는 것(겉모습은 거의 같고 클릭 영역만 커짐)

## 7. 결정이 필요한 항목과 이유

### A. Style 이름
- 지금: 틀 없는 스타일을 `Ghost`라고 불렀습니다(shadcn 용어). Button에도 같은 이름이 있습니다.
- 왜 정해야 하나: 이름은 디자이너·개발자·AI가 모두 부르는 말이라, 한 번 정하면 Figma·코드·문서에 같이 들어갑니다. Button과 이름이 다르면 같은 모양을 두 이름으로 부르게 됩니다.
- 후보: `Plain`(기존 컴포넌트 `btn-plain-gray`에서 쓰던 말), `Borderless`, `Standard`(Material)
- 추천: `Plain`. 이미 팀에서 쓰던 말이고 "틀 없음"이 바로 떠오릅니다. Button의 `Ghost`도 같이 `Plain`으로 바꾸면 일관됩니다(Figma·코드·문서 이름만 바꿈).

### B. 아이콘 색을 지키는 방법
- 지금: 기본 상태 아이콘 색이 6가지입니다(`#2D2D2D`, `#767676`, `#A3A3A3`, `#111111`, `#2D3748`, 흰색).
- 왜 정해야 하나: Figma Variant 하나는 색을 하나만 가집니다. 같은 Outline이라도 순서 이동(`#2D2D2D`)과 지도 확대(`#767676`)는 색이 달라서, 이 차이를 담을 속성이 따로 필요합니다.
- 방법: `Icon Color` 속성을 추가해 색을 고르게 합니다(값마다 토큰 연결). Variant 수가 늘지 않도록 아이콘 색만 바꾸는 속성으로 둡니다.
- 함께 정할 것:
  - `#A3A3A3`은 토큰 이름이 `Foreground/Neutral/Disabled`(비활성)였는데 눌리는 아이콘에 많이 쓰여서, 2026-10-09에 `Foreground/Neutral/Subtle`로 이름을 바꿨습니다(9절).
  - `#2D3748`(상단 바 알림·로그아웃 64곳)은 토큰에 없는 색입니다. 그대로 쓰려면 Atomic에 추가해야 하고, 아니면 가장 가까운 `#2D2D2D`로 바꿔야 합니다.

### C. 상태가 바뀔 때 아이콘 색
- 지금: hover에서 진해짐(입력창 수정), 옅어짐(지도), 선택되면 진해짐(편집 도구), 켜지면 보라로 뒤집힘(지도 위치 추가) — 네 가지가 섞여 있습니다.
- 왜 정해야 하나: B에서 아이콘 색을 쓰임마다 고르게 하면, 상태마다 "그 색에서 어떻게 바뀌는지"를 하나의 규칙으로 정해야 컴포넌트를 만들 수 있습니다. 쓰임마다 규칙이 다르면 Variant가 수백 개로 늘어납니다.
- 추천 규칙: hover·pressed에서는 **배경만** 바뀌고 아이콘 색은 그대로. 선택되면 편집 도구처럼 연보라 배경 + 보라 선 + 아이콘 `#2D2D2D`. 비활성은 아이콘 `#D6D6D6`.
- 이 규칙으로 바뀌는 곳: 입력창 수정 hover(아이콘이 진해지지 않음), 지도 hover(아이콘이 옅어지지 않음, 대신 배경이 회색), 지도 위치 추가 켜짐(흰 배경+보라 → 연보라 배경+보라 선+짙은 회색 아이콘).

### D. 늘려 쓴 아이콘 크기
- 지금: 순서 이동 아이콘은 24를 29로, 지도 확대·축소는 20을 23으로 늘려 썼고, 지도 현재 위치는 21입니다.
- 왜 정해야 하나: 아이콘 세트에는 16·20·24·32·36만 있습니다. 29·23·21은 세트에 없는 크기라, 그대로 두면 컴포넌트 안에서 아이콘을 늘려야 하고 선 두께도 같이 굵어집니다.
- 선택지: (1) 지금처럼 늘린 크기 유지 (2) 가장 가까운 세트 크기로(29→24, 23→24, 21→20 또는 24)
- 추천: (2). 다만 순서 이동은 29→24로 눈에 띄게 작아지므로, 원하시면 순서 이동만 32 아이콘을 쓰는 방법도 있습니다.

### E. Icon 기본값
- 뜻: 새 IconButton을 처음 끌어다 놓았을 때 들어 있는 아이콘입니다. 기존 화면에는 영향이 없고, 놓은 뒤 바로 원하는 아이콘으로 바꿉니다.
- 왜 정해야 하나: Instance swap 속성은 기본 아이콘이 반드시 하나 있어야 합니다.

### 사용 지침 (추가)

1. **틀보다 큰 아이콘을 넣지 않습니다.** 20 틀에는 20 이하, 24 틀에는 24 이하 아이콘을 씁니다. 틀 밖을 잘라내지 않으므로 큰 아이콘을 넣으면 밖으로 튀어나옵니다.
2. 아이콘 크기와 색은 쓰임마다 정해진 값을 씁니다(10-3, 10-4 표). 임의로 바꾸지 않습니다.
3. 화면에 놓은 IconButton 인스턴스의 레이어 이름은 버튼의 뜻으로 바꿉니다(예: `IconButton` → `확대`). 개발자와 AI가 이 이름으로 버튼 이름(`aria-label`)을 정합니다.
4. 지도 위치 추가는 `Primary`이고, 켜졌을 때는 `State=Selected`로 바꾼 뒤 아이콘을 `Icon/Action/Undo`로 바꿉니다.
