# 토큰 이름 규칙

## 층 구조

| Collection | 모드 | 그룹 | 이름 형식 | 예 |
|---|---|---|---|---|
| `Atomic` | Value | Neutral, Purple, Red, Green, Blue, Navy, Violet, Yellow, Orange | `{색}{단계}` | `Neutral900`, `Purple500` |
| `Semantic` | Light | Foreground, Surface, Border, Chart | `{용도}/{역할}/{변형}` | `Foreground/Neutral/Primary` |
| `Foundation` | Value | Spacing, Radius, Size, Font | `{분류}/{그룹}/{이름}` | `Spacing/Scale/8`, `Size/Icon/Medium`, `Font/Size/15` |

색만 Atomic과 Semantic 두 층이고, 모드가 필요 없는 한 층짜리 값(간격, 모서리, 크기, 글꼴)은 `Foundation` 하나에 모았습니다. Atomic 색 값은 `03_컬러_스케일_설계안.md`에 있습니다.

## Size (Foundation)

여러 컴포넌트가 함께 맞춰 쓰는 크기만 토큰으로 둡니다. 특정 컴포넌트 하나에만 쓰는 치수(좌측 메뉴 너비 220, 모달 너비 1100 같은 값)는 토큰이 아니라 컴포넌트 명세에 둡니다.

| 토큰 | 값 | 쓰인 곳 |
|---|---|---|
| `Size/Icon/XSmall` | 16 | 16px 아이콘(재생·정지·지우개 등) |
| `Size/Icon/Small` | 20 | 화살표·위치 아이콘, 라디오 버튼 |
| `Size/Icon/Medium` | 24 | 콘텐츠 타입 아이콘, 알림·로그아웃 아이콘 |
| `Size/Icon/Large` | 32 | 그룹 폴더 아이콘 |
| `Size/Icon/XLarge` | 36 | 닫기(36px) |
| `Size/Hit/Small` | 32 | 최소 클릭 영역. 아이콘만 있는 버튼도 버튼 틀은 32 이상 |
| `Size/Hit/Medium` | 40 | 지도 버튼(Pin, 현재 위치, 확대·축소), 텍스트 버튼 |
| `Size/Hit/Large` | 48 | 순서 이동 버튼(위·아래) |
| `Size/Height/Badge` | 24 | 태그, 성공·실패 배지 |
| `Size/Height/ControlXSmall` | 32 | 아웃라인 버튼(87×32) |
| `Size/Height/ControlSmall` | 40 | h40 버튼(추가·삭제), 입력창 XXS |
| `Size/Height/ControlMedium` | 48 | 회색 라인 S 버튼, 시간 설정 버튼 |
| `Size/Height/ControlLarge` | 52 | 입력창 M, M·L 버튼(240×52) |
| `Size/Height/ControlXLarge` | 56 | XLarge 버튼(로그인·회원가입 같은 대표 동작) |
| `Size/Height/Row` | 56 | 테이블 행·헤더 |
| `Size/Height/Bar` | 56 | 상단 바, 모달 상단바 |
| `Size/Border/Default` | 1 | 테이블 하단선, 버튼, 컨테이너 |
| `Size/Border/Thick` | 2 | 저장된 위치 반경 테두리 |

레퍼런스는 버튼 높이가 `Control` 하나였지만, 이 제품은 버튼·입력창 높이가 32, 40, 48, 52로 실제 네 가지가 쓰여서 네 단계로 나눴습니다.

제외한 값과 이유:
- 컴포넌트 고유 치수: 너비 Menu 220, Sidebar 260, Field 480, Modal 1100 / 높이 Status 28, Field 30, MenuGroup 38, Menu 40, ListTitle 48
- 10회 미만(Radius와 같은 기준): 선 두께 0.5(1회), 3(1회)

## Spacing (Foundation)

형식: `Spacing/Scale/{px}`. 색 Semantic과 섞지 않고 `Foundation` Collection에 둡니다. 모드는 Collection 단위로 걸리기 때문에, Semantic에 넣으면 간격 값이 Light/Dark마다 중복됩니다.

| 토큰 | 값 |
|---|---|
| `Spacing/Scale/0` | 0 (없음을 명시할 때) |
| `Spacing/Scale/2` ~ `Spacing/Scale/16` | 2, 4, 6, 8, 10, 12, 14, 16 (2px씩, 이전 sm) |
| `Spacing/Scale/20` ~ `Spacing/Scale/48` | 20, 24, 28, 32, 36, 40, 44, 48 (4px씩, 이전 md) |
| `Spacing/Scale/56`, `Spacing/Scale/64` | 56, 64 (8px씩, 이전 lg) |

sm, md, lg는 값을 만드는 규칙으로만 쓰고 이름에는 넣지 않습니다. 그룹 기준이 바뀌어도 이름이 유지됩니다.

## 확인이 필요한 항목 (⚑)

1. **`#F1F5FB`, `#EAEDF2`를 Navy로 옮김**: 푸른 기가 있어서 순수 회색인 Neutral 대신 `Navy0`, `Navy100`에 넣었습니다. 시맨틱에서는 그대로 `Surface/Neutral/Tertiary`, `Quaternary`가 참조하니 화면 색은 바뀌지 않습니다.
2. **`#FF6730`(실패)을 `Red400`에**: 빨간 계열로 두라고 하셨고, 400 자리와 밝기가 같아서 넣었습니다. 다만 다른 Red 단계보다 주황 쪽이라 단계 사이 색감이 살짝 튑니다.
3. **`#202020`(`Neutral800`, 프로필 인사말·알림 99건)의 시맨틱**: `Foreground/Neutral/Primary`(`Neutral900`)와 `Secondary`(`Neutral700`) 사이라 아직 토큰을 붙이지 않았습니다. 둘 중 하나에 합칠지, 별도 토큰을 둘지 정해 주세요.
4. ~~Spacing, Radius 이름 형식~~ → `Spacing/Scale/{px}`, `Radius/Scale/{px}`로 확정했습니다.
5. **차트 토큰 이름** `Chart/{차트}/{Series번호}`: 이 형식으로 괜찮은지 봐 주세요.
