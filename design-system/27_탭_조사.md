# Tab 조사 (결정 전, 조사 결과만)

같은 자리에서 내용을 바꿔 보여 주는 탭을 조사했습니다.

- 기준일: 2026-10-26
- 조사 범위: 시안 화면의 외부 라이브러리 `Component 79` 세트. `05_컴포넌트_후보.md`에서 Tab에 함께 들어 있던 `Component 73`은 드롭다운이라 뺐습니다(`23_드롭다운_조사.md`).

## 1. 우리 시안의 탭

### 1-1. 쓰이는 곳

| 쓰이는 곳 | 탭 | 놓인 곳 | 사용 |
|---|---|---|---|
| 콘텐츠 그룹 관리 · GPS 설정 팝업(1·2·3), 위치 선택·삭제 화면, 타임라인 설정 후 | "위치 설정"(선택됨) / "시간 설정" | 팝업 본문 맨 위, 탭 묶음 아래 전체 너비 회색 선 | 23묶음(탭 46개) · 6화면 |

- 탭은 모두 **2개짜리 한 묶음**, 선택된 탭은 항상 "위치 설정"입니다. "시간 설정"을 고른 화면은 없습니다.
- 탭 묶음(`Tab`, 244×48)은 일반 프레임이고, 그 바깥 `Tab Area`(1020×48)에 아래 테두리 `#D6D6D6` 1이 있습니다.

### 1-2. 세트 구성 (`Component 79`, Variant 4개)

| 상태 | Figma 이름 | 배경 | 글자 | 아래 막대(두께 6) | 시안 화면 |
|---|---|---|---|---|---|
| 기본 | `default` | 없음 | `#767676` `14/SemiBold` | 없음 | ✓ |
| 마우스 올림 | `hover` | `#F3F3FF` | `#494949` | `#BDBEFF`(토큰 없음) | 세트만 |
| 선택됨 | `pressed` | `#F3F3FF` | `#2D2D2D` | `#7778FD` | ✓ |
| 비활성 | `disabled` | `#F9F9F9` | `#A3A3A3` | 없음 | 세트만 |

### 1-3. 크기

| 항목 | 값 |
|---|---|
| 탭 하나 | 122 × 48 (너비 고정) |
| 글자와 막대 | 아래로 붙여 놓음(글자 22 + 간격 9 + 막대 6), 위 여백 11 |
| 막대 | 두께 6, 탭 너비 전체, 모서리 0 |
| 탭 사이 간격 | 0 |

### 1-4. 관찰된 특징 (아직 판단하지 않음)

- `pressed`라는 이름이 "선택됨"을 뜻합니다(Radio·Checkbox와 같은 문제).
- 선택된 탭은 **배경 + 막대** 두 가지로 표시합니다.
- 마우스 올림 막대 색 `#BDBEFF`는 토큰에 없습니다(가까운 `Purple200` `#C0C2FF`).
- 막대 두께 6은 크기 토큰에 없습니다(`Size/Border/Thick` 2).
- 탭 너비가 글자 길이와 상관없이 122로 고정입니다.
- 탭 묶음 아래 회색 선은 탭이 아니라 바깥 프레임 테두리입니다.

### 1-5. 색 대비

| 요소 | 색 | 대비 | 기준 | 결과 |

## 2. 시중 디자인 시스템

| 항목 | Material 3 | Apple HIG | shadcn/ui |
|---|---|---|---|
| 이름 | Tabs(Primary·Secondary) | Segmented control(같은 화면 안 보기 전환), Tab bar(앱 화면 전환) | Tabs |
| 선택 표시 | 아래 막대(indicator) + 글자색 | 선택 칸 배경 | 회색 묶음 안에서 선택 탭만 흰 배경(알약 모양) |
| 높이 | 48(글자만) | — | 36 |
| 너비 | 고정 또는 글자에 맞춤(스크롤 탭) | 칸 너비 같게 | 글자에 맞춤 |
| 아이콘 | 가능 | 가능 | 가능 |
| 키보드(WAI-ARIA Tabs) | 탭 묶음 `tablist`, 탭 `tab`, 내용 `tabpanel`. 좌·우 화살표로 탭 이동, Home·End, 선택은 `aria-selected` | | |

**공통점:** 탭 묶음은 하나만 선택되고, 선택된 탭과 연결된 내용만 보입니다. 막대나 배경 하나로 선택을 표시합니다.
