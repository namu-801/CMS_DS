## 1. 종류와 상태 나누기

| 조사에서 나온 차이 | 종류인가 상태인가 | 이유 |
|---|---|---|
| 입력 팝업 / 확인 모달 | **종류 → 컴포넌트 따로** | 구성(머리·하단 vs 그림·가운데 버튼)과 닫는 방법이 다름 |
| 입력 팝업 대·중·소 | **종류 → 크기** | 본문 양에 따라 고름 |
| 확인 모달 경고·성공·실패 | **종류 → 상태 그림** | 알리는 내용에 따라 |
| 확인 모달 버튼 1개·2개 | **종류 → 버튼 수** | 확인만 / 취소 + 동작 |
| 마우스 올림 등 | 해당 없음 | 버튼이 맡음 |

## 2. Component property

### 2-1. `Modal Header` (입력 팝업 머리)

| 속성 | 타입 | 값 | 기본값 |
|---|---|---|---|
| `Title` | Text | 제목 | `팝업 제목` |

### 2-2. `Modal Footer` (입력 팝업 하단)

| 속성 | 타입 | 값 | 기본값 |
|---|---|---|---|
| (없음) | — | 안에 `Button` 2개(Neutral "취소", Primary "저장"). 글자·Style은 인스턴스에서 바꿈 | — |

### 2-3. 입력 팝업 틀 ⚑ C

본문이 팝업마다 달라 하나의 컴포넌트로 만들지 않고, **크기 규칙 + 예시 프레임**으로 둡니다: 화면에서 `Modal Header` + 본문 프레임 + `Modal Footer`를 세로로 쌓습니다.

| 크기 | 너비 × 높이 |
|---|---|
| `Small` | 400 × 480 |
| `Medium` | 680 × 480 |
| `Large` | 1100 × 700 |

### 2-4. `Alert Dialog` (확인 모달)

| 속성 | 타입 | 값 | 기본값 |
|---|---|---|---|
| `Type` | Variant | `Warning`, `Success`, `Error` | `Warning` |
| `Buttons` | Variant | `One`, `Two` | `Two` |
| `Title` | Text | 제목 | `제목을 입력하세요` |
| `Description` | Boolean | 설명 켬/끔 | 켬 |
| `Description Text` | Text | 설명 | `설명을 입력하세요.` |

- 6개(3 × 2). 버튼 글자·Style(Primary·Destructive)은 안의 `Button` 인스턴스에서 바꿈.
