# 버튼 스펙안 (제안, 피그마 작업 전)

근거: `08_버튼_조사.md`.
사용자가 추가하기로 한 것(2026-10-08): 로딩 상태, 위험(destructive) 버튼, 통일된 크기 이름, 최소 터치 영역.
토큰 이름은 지금 이름을 그대로 씁니다(Positive·Success 이름 변경 없음).
⚑는 확인이 필요한 항목입니다.

## 1. 종류와 상태 나누기

| 구분 | 기준 | 해당 항목 |
|---|---|---|
| **종류** | 화면을 설계할 때 고르고, 쓰는 동안 바뀌지 않음 | 스타일(강조 정도, 위험 여부), 크기, 아이콘 유무·위치, 라벨 |
| **상태** | 사용자 동작이나 시스템 처리에 따라 바뀜 | 기본, 마우스 올림(hover), 누름(pressed), 비활성(disabled), 로딩(loading) |
| 별도 컴포넌트 | 생김새나 구조가 달라 속성 하나로 다루기 어려움 | 아이콘만 있는 버튼 → `IconButton`, 탭·세그먼트·페이지 번호 → 각자 컴포넌트 |

헷갈리기 쉬운 것:
- **위험 버튼은 종류**입니다. Apple은 역할(role), shadcn은 variant로 둡니다. 눌러서 위험해지는 게 아니라 처음부터 위험한 동작이라서 그렇습니다.
- **로딩은 상태**입니다. 같은 버튼이 누른 뒤 처리 중으로 바뀝니다.
- **선택(selected)은 상태**지만 토글 버튼에만 필요합니다. 우리는 탭·세그먼트가 따로 있어서 `Button`에는 두지 않습니다.

## 2. Component property 제안

컴포넌트 이름은 `Button`입니다. 속성 이름은 아이콘과 같은 규칙(`Style`, `Size`)을 따릅니다.

| 속성 | 타입 | 값 | 기본값 | 다루는 차이 |
|---|---|---|---|---|
| `Style` | Variant | `Primary`, `Secondary`, `Neutral`, `Outline`, `OutlineBrand`, `Plain`, `Destructive` | `Primary` | 색과 강조 정도, 위험 여부 |
| `Size` | Variant | `XSmall`, `Small`, `Medium`, `Large`, `XLarge` | `Small` | 높이, 글자, 좌우 여백, 아이콘 크기 |
| `State` | Variant | `Default`, `Hover`, `Pressed`, `Disabled`, `Loading` | `Default` | 상호작용 상태 |
| `Label` | Text | 버튼 문구 | `버튼` | 문구 |
| `Icon Left` | Boolean | 켬/끔 | 끔 | 왼쪽 아이콘 표시 |
| `Icon Left Swap` | Instance swap | `Icon/*` 세트(크기는 버튼 Size가 정함) | `Icon/Action/Plus` ⚑ | 왼쪽 아이콘 모양 |
| `Icon Right` | Boolean | 켬/끔 | 끔 | 오른쪽 아이콘 표시 |
| `Icon Right Swap` | Instance swap | `Icon/*` 세트 | `Icon/Arrow/Right` ⚑ | 오른쪽 아이콘 모양 |

속성으로 만들지 않는 것:
- **모서리**: 모든 버튼이 `Radius/Scale/0`으로 고정입니다.
- **너비**: 기본은 내용에 맞춤(Hug)입니다. 화면에서 고정 너비(100, 240 등)나 채움(Fill)으로 바꿉니다. 오토 레이아웃 설정이라 속성이 아닙니다.
- **최소 터치 영역**: 크기 규칙에 넣어 두고, 따로 끄고 켜지 않습니다.

Variant 수는 7 × 5 × 5 = 175개입니다(Style과 Size는 서로 독립, 모든 조합이 있음).

## 3. 최종 스펙

### 3-1. 종류 (`Style`)

| 값 | 지금 시안의 버튼 | 사용 | 배경 | 선 | 글자·아이콘 |
|---|---|---|---|---|---|
| **`Primary`** (기본값) | 보라 채움 | 약 100 | `Surface/Brand/Strong`(Purple500, 2026-10-08 대비 개선) | 없음 | `Foreground/Neutral/Inverse` |
| `Secondary` | 네이비 채움(할당하기) | 10 | `Surface/Brand/Secondary` | 없음 | `Foreground/Neutral/Inverse` |
| `Neutral` | 회색 채움(취소 등) | 48 | `Surface/Neutral/Inverse` | 없음 | `Foreground/Neutral/Inverse` |
| `Outline` | 회색 선(추가·삭제·수정) | 약 120 | `Surface/Neutral/Primary` | `Border/Neutral/Secondary` | `Foreground/Neutral/Secondary` |
| `OutlineBrand` | 보라 선(중복확인 등) | 18 | `Surface/Neutral/Primary` | `Border/Brand/Primary` | `Foreground/Brand/Primary` |
| `Plain` | 회색 글자(이전·다음) | 19 | 없음 | 없음 | `Foreground/Neutral/Quaternary` |
| `Destructive` 🆕 | 없음(새로 추가) | — | `Surface/Negative/Primary` | 없음 | `Foreground/Neutral/Inverse` |

- `Secondary`라는 이름은 토큰 `Surface/Brand/Secondary`(네이비)와 맞췄습니다.
- `Destructive` 값 이름은 시중 용어를 썼고, 색은 기존 `Negative` 토큰을 씁니다.
- 위험 버튼을 쓸 곳(확정): 삭제를 **최종 확인하는 모달 버튼**에만 씁니다. 목록 위의 "삭제" 버튼(`btn-delete-h40`, 29곳)은 지금처럼 `Outline` + 아이콘으로 둡니다.

### 3-2. 크기 (`Size`)

높이는 이미 등록된 Foundation `Size/Height/Control*` 4단계에 맞춥니다.

| 값 | 높이 토큰 | 글자 | 좌우 여백 | 아이콘 | 아이콘–글자 간격 | 지금 시안에서 합쳐지는 높이 |
|---|---|---|---|---|---|---|
| `XSmall` | `ControlXSmall` 32 | `13/Medium` | `Spacing/Scale/12` | `Size/Icon/XSmall` 16 | `Spacing/Scale/4` | 32 |
| **`Small`** (기본값) | `ControlSmall` 40 | `15/SemiBold` | `Spacing/Scale/16` | `Size/Icon/Small` 20 | `Spacing/Scale/4` | 40, 42 |
| `Medium` | `ControlMedium` 48 | `18/SemiBold` | `Spacing/Scale/20` | `Size/Icon/Small` 20 | `Spacing/Scale/6` | 48 |
| `Large` | `ControlLarge` 52 | `20/SemiBold` | `Spacing/Scale/24` | `Size/Icon/Medium` 24 | `Spacing/Scale/8` | 52 |
| `XLarge` | `ControlXLarge` 56 | `20/SemiBold` | `Spacing/Scale/28` | `Size/Icon/Medium` 24 | `Spacing/Scale/8` | 56 |

- **42 → 40, 56 → 52로 통일**(확정, 2026-10-08).
- **Small 글자는 `15/SemiBold`로 확정**(2026-10-08). 지금 42 버튼(저장·취소)의 15 Medium과 40 버튼의 14 SemiBold가 이 값으로 바뀝니다.
- **아이콘 쪽 여백은 글자 쪽보다 4px 좁습니다**(확정, 기존 방식). 위 표의 좌우 여백은 글자 쪽 값입니다.
  - 구현: 버튼 바깥 여백 = 글자 쪽 − 4(XSmall 8, Small 12, Medium 16, Large 20), 라벨을 감싼 `Label Wrap` 좌우 여백 4.
  - 아이콘이 없으면 바깥 + 4 = 글자 쪽 여백이 되고, 아이콘이 있으면 그쪽만 바깥 여백(4 좁음)이 됩니다. Boolean으로 아이콘을 켜고 꺼도 여백이 자동으로 맞습니다.
  - 아이콘–글자 간격 = 버튼 간격(itemSpacing) + 4. 그래서 itemSpacing은 XSmall 0, Small 0, Medium 2, Large 4입니다.

### 3-3. 상태 (`State`)

| 값 | 언제 | 채움 스타일(`Primary`·`Secondary`·`Neutral`·`Destructive`) | 선·글자 스타일(`Outline`·`OutlineBrand`·`Plain`) | 클릭 |
|---|---|---|---|---|
| **`Default`** (기본값) | 평소 | 3-1 표의 색 | 3-1 표의 색 | 됨 |
| `Hover` | 마우스를 올림 | 배경 `Interaction/{역할}/{변형}Hover`(아래 표) | 배경 `Outline`·`Plain` → `Interaction/Neutral/Fill`, `OutlineBrand` → `Interaction/Brand/SubtleHover` | 됨 |
| `Pressed` | 누르는 중 | 배경 `Interaction/{역할}/{변형}Pressed`(아래 표) | 배경 `Outline`·`Plain` → `Interaction/Neutral/FillStrong` + 선 `Interaction/Neutral/ActiveBorder`, `OutlineBrand` → `Interaction/Brand/SubtlePressed` | 됨 |
| `Disabled` | 지금 쓸 수 없음 | 배경 `Surface/Neutral/Disabled`, 글자 `Foreground/Neutral/Inverse` | 배경 `Surface/Neutral/Secondary`(Ghost는 없음), 선 `Border/Neutral/Secondary`, 글자 `Foreground/Neutral/Subtle` | 안 됨 |
| `Loading` 🆕 | 누른 뒤 처리 중 | `Default` 색 그대로 + 라벨 왼쪽에 회전 아이콘 | 같음 | 안 됨 |

- 비활성 글자색이 지금은 `#D6D6D6`과 `#A3A3A3`으로 섞여 있습니다. `Foreground/Neutral/Subtle`(`#A3A3A3`) 하나로 맞춥니다.
- **로딩**: shadcn 방식입니다. 라벨은 그대로 두고, 왼쪽 아이콘 자리에 회전 아이콘을 둡니다. 왼쪽 아이콘이 있으면 회전 아이콘으로 바뀝니다. 문구를 "저장 중…"으로 바꾸는 것(Apple 방식)은 화면에서 라벨을 바꿔 처리합니다.
- 회전 아이콘 `Icon/Status/Loading`(16·20·24, 기본 24)을 그렸습니다(2026-10-08). 회전 애니메이션은 코드에서 적용합니다.
- hover·pressed 색은 Semantic `Interaction` 그룹에 13개로 추가했습니다(2026-10-08). 새 Atomic 색은 만들지 않고 기존 단계에 연결했습니다.

| 토큰 | 참조 | 버튼 | 이전 시안 색 |
|---|---|---|---|
| `Interaction/Brand/PrimaryHover` | `Purple600` | Primary hover | `#5F60CA` ⚑ 달라짐 |
| `Interaction/Brand/PrimaryPressed` | `Purple700` | Primary pressed | `#4C4DB2` ⚑ 달라짐 |
| `Interaction/Brand/SecondaryHover` | `Navy800` | Secondary hover | `#142E87` ⚑ 달라짐 |

| `Interaction/Brand/SubtlePressed` | `Purple100` | OutlineBrand pressed | 같음 |
| `Interaction/Neutral/InverseHover` | `Neutral700` | Neutral hover | 같음 |
| `Interaction/Neutral/InversePressed` | `Neutral900` | Neutral pressed | 같음 |
| `Interaction/Neutral/Fill` | `Neutral200` | Outline·Plain hover | 같음 |
| `Interaction/Neutral/FillStrong` | `Neutral300` | Outline·Plain pressed | 같음 |
| `Interaction/Neutral/ActiveBorder` | `Neutral400` | Outline·Plain pressed 테두리 | 같음 |

### 3-4. 최소 터치(클릭) 영역

| 항목 | 제안 |
|---|---|
| 기준 | **32×32px 이상** |
| 근거 | 웹 접근성 기준 WCAG 2.2(2.5.8, AA)은 24×24 이상입니다. Apple 44pt, Material 48dp는 손가락 터치 기준이고, 이 제품은 마우스로 쓰는 관제 화면이라 그 사이 값을 골랐습니다. 가장 작은 버튼 높이(`XSmall` 32)와도 같습니다. |
| `Button` | 4가지 크기 모두 높이가 32 이상이라 그대로 충족합니다. |
| `IconButton`(다음 컴포넌트) | 아이콘이 20·24px이어도 버튼 틀은 32 이상으로 둡니다. 지금 20(입력창 지우기 등 16곳)과 24 버튼이 해당합니다. |
| 토큰 | `Size/Hit/Small` = 32 추가 완료(2026-10-08). |

## 4. 조사에 나왔지만 지금은 넣지 않는 것

| 항목 | 출처 | 넣지 않는 이유 |
|---|---|---|
| 포커스(키보드) 상태 | 세 시스템 모두 | 이번에 추가할 목록에 없습니다. 나중에 `State=Focus`로 추가할 수 있게 자리만 비워 둡니다. |
| 선택(selected)·토글 버튼 | Material | 탭·세그먼트 컴포넌트가 따로 맡습니다. |
| 부드러운 채움(Filled tonal, secondary) | Material, shadcn | 시안에 없고, 강조 단계가 이미 7개입니다. |
| 그림자 버튼(Elevated) | Material | 시안의 버튼은 모두 평면입니다(지도 컨트롤만 그림자 → `IconButton`에서 다룸). |
| 링크 버튼 | Apple, shadcn | 약관 링크는 밑줄 글자로 충분합니다. 버튼이 아니라 글자 스타일입니다. |
| 둥근 모서리·눌렀을 때 모양 변화 | Material, Apple | 이 제품은 직각으로 통일돼 있습니다. |
| 묶음·분할 버튼(Button group, Split) | 세 시스템 | 시안에 없습니다. 모달 하단 버튼 묶음은 `Modal`에서 다룹니다. |
| Pop-up·Pull-down 버튼 | Apple | 드롭다운 컴포넌트가 따로 있습니다(`Component 73`). |
| FAB, Glass 스타일 | Material, Apple | 모바일·새 OS 전용입니다. |
| 입력 오류 표시(aria-invalid) | shadcn | 입력창에서 다룹니다. |
| `Cancel` 역할 | Apple | 우리는 `Neutral` 스타일로 충분합니다. |

## 7. Figma 제작 현황 (2026-10-08)

- 프레임 `Button · Component`(96:15595) 안 세트 `Button`(96:15603), **Variant 140개**(Style 7 × Size 4 × State 5). 기본값 `Primary / Small / Default`.
- 배치: 열 = State(Default, Hover, Pressed, Disabled, Loading), 행 = Style별 4줄(Small, XSmall, Medium, Large). 기본 Variant가 왼쪽 위에 와야 기본값이 되기 때문에 Small을 각 스타일의 첫 줄에 뒀습니다.
- 구조: `Button`(가로 Auto Layout, 높이 고정, 너비 Hug) > `Icon Left`(Loading은 `Spinner`) · `Label Wrap` > `Label` · `Icon Right`
- 토큰: 배경·선·글자·아이콘 색 Semantic, 높이 `Size/Height/Control*`, 최소 너비 `Size/Hit/Small`, 아이콘 크기 `Size/Icon/*`, 여백·간격 `Spacing/Scale/*`, 선 두께 `Size/Border/Default`, 모서리 `Radius/Scale/0`. 글자는 Font 변수(크기·줄 높이·굵기·글꼴·자간)도 연결.
- 속성: `Label`, `Icon Left`·`Icon Right`(Boolean), `Icon Left Swap`·`Icon Right Swap`(Instance swap, 추천 8개)
- Loading: 왼쪽 아이콘 대신 `Icon/Status/Loading`, 색은 글자색과 같음
- 아이콘 Swap 색 유지: 한 색 아이콘(Outline·Filled)의 안쪽 레이어 이름을 모두 `Icon`으로 통일(107개 레이어). 레이어가 하나인 아이콘은 Swap해도 버튼 색이 유지됨을 확인.
- 남은 일
  1. 글자 스타일: base만 우리 `15/SemiBold`, 나머지 139개는 라이브러리 `15_Semibold`(작업 환경에 Pretendard 없음). 데스크톱에서 XSmall 줄 → `13/Medium`, Small·Medium 줄 → `15/SemiBold`, Large 줄 → `18/SemiBold` 적용 필요.
  2. 레이어가 2개 이상인 한 색 아이콘(Edit 20, Close 24·36 등 23개 Variant)은 Swap하면 첫 레이어만 버튼 색이 됨 → 레이어를 하나로 합치는(flatten) 정리 제안.

### 검사 후 정리 (2026-10-08)
- 글자: Label에 보이던 글꼴 변수 연결은 Text Style이 가진 변수가 보이는 것이라 중복이 아님(직접 연결 없음).
- 아이콘 크기: Swap 속성 하나를 모든 크기가 같이 쓰기 때문에 크기마다 다른 아이콘 Variant를 넣을 수 없음(인스턴스에서 마지막 값으로 통일됨). 그래서 20px 아이콘을 `Size/Icon/*` 크기로 늘리거나 줄여 씀. 20→16은 선 1.3→약 1.0, 20→24는 약 1.6으로 그리기 기준표(16→1, 24→1.5)와 거의 같음.
- Size 옵션 순서: 이 작업 환경에서는 Variant 순서를 바꿀 수 없어 데스크톱에서 정리 필요.

### 크기 재검토 (2026-10-08)
- 글자를 크기마다 한 단계씩: XSmall 13/Medium, Small 15/SemiBold, Medium 18/SemiBold, Large 20/SemiBold(Small·Medium이 같고 Large가 기존 XL보다 작던 문제 수정).
- 56 크기를 `XLarge`로 다시 살림. 기존 시안처럼 로그인(Primary)·회원가입(OutlineBrand)에만 쓰므로 이 두 스타일에만 둠. 글자는 Large와 같은 20/SemiBold, 높이 `Size/Height/ControlXLarge`(56, 새 토큰).
- 다른 Style에서 XLarge로 바꾸면 조합이 없어 피그마가 가까운 Variant로 옮김 → 세트 설명에 "XLarge는 Primary·OutlineBrand 전용" 명시.
- (갱신) XLarge를 모든 Style에 둠(175개). 두 스타일에만 두면 다른 Style에서 XLarge를 누를 때 피그마가 Style을 말없이 Primary로 바꾸고, 코드(스타일·크기 독립)와 규칙이 어긋나기 때문. "XLarge는 로그인·회원가입 같은 화면의 대표 동작용"은 사용 가이드로 둠.

### Primary 색 대비 개선 (2026-10-08, A안)
- 흰 글자와의 대비가 일반 글자 기준(4.5)에 못 미쳐(3.57) 한 단계씩 진하게 바꿈: Default Purple400→Purple500(4.83), Hover Purple500→Purple600(6.95), Pressed Purple600→Purple700(9.90).
- Default는 `Surface/Brand/Primary`를 바꾸지 않고(탭 등 다른 곳에 영향) 기존 `Surface/Brand/Strong`(Purple500)을 씀. Hover·Pressed는 버튼 전용 `Interaction/Brand/PrimaryHover`·`PrimaryPressed`의 연결을 바꿈.
