## 2. 속성과 넣을 수 있는 값

| Figma | 타입 | 값 | 기본값 |
|---|---|---|---|
| `Size` | Variant | `Small`(20), `Large`(36) | `Small` |
| 사진 | 이미지 칠 | 인스턴스에서 사진을 바꿈 | 시안 사진 |

```ts
interface AvatarProps {
  src: string;               // 사진 주소
  alt: string;               // 필수. 옆에 이름이 있으면 ""
  size?: "small" | "large";  // 기본 "small"
  className?: string;
}
```

| 항목 | `small` | `large` | 토큰 |
|---|---|---|---|
| 크기 | 20 | 36 | `Size/Icon/Small` · `Size/Icon/XLarge` |
| 모양 | 원 | 원 | `Radius/Scale/Full` |
| 테두리 | 1 | 1 | `Size/Border/Default`, `Border/Neutral/Primary` |
| 사진이 없을 때 배경 | | | `Surface/Neutral/Tertiary` |

## 3. Figma 속성 ↔ 코드 Prop 대응표

| Figma | 코드 | 대응 |
|---|---|---|
| `Size` Small / Large | `size: "small" \| "large"` | 1:1 |
| 사진(이미지 칠) | `src` | 1:1 |
| (없음) | `alt`(필수) | 코드에만 — 스크린리더용 설명 |

## 4. 시안 쓰임별 정답 조합

| 쓰임 | Figma | 코드 |
|---|---|---|
| 차량관리 표 운전자 | `Table Cell` `Leading Swap` = `Avatar` Small + 이름 글자 | `leading={{ type: "avatar", src }}`(alt는 자동으로 "") |
| 상단 바 프로필 | `Top Bar` 안 `Avatar` Large | `<TopBar avatarSrc=… />` |

## 5. 사용 규칙

1. 크기는 `Small`·`Large`만. 다른 크기로 늘리거나 줄이지 않습니다.
2. 옆에 이름이 있으면 `alt=""`, 사진만 있으면 사람 이름을 `alt`로.
3. 사진을 네모로 자르거나 테두리 색을 바꾸지 않습니다.

## 6. 제대로 썼는지 확인하는 방법

- Figma: 인스턴스 크기를 직접 바꾼 곳이 없는지(`width`·`height` 덮어쓰기 0).
- 코드: `npm run typecheck`(없는 크기·`alt` 누락은 컴파일 오류), `npm test`(스타일 토큰 검사).
- 찾아보기: `grep -rn "<img" src --include="*.tsx" | grep -v components/` → 프로필 사진을 직접 그린 곳 0건.

## 7. 예시

```tsx
<span><Avatar src={driver.photo} alt="" /> {driver.name}</span>   // 이름 옆: 장식
<Avatar src={company.logo} alt="마바산업" size="large" />           // 사진만: 이름
```

| 반례 | 왜 문제인지 | 바르게 |
|---|---|---|
| `<img className="rounded-full w-6">` 직접 | 크기·테두리 규칙 깨짐 | `<Avatar>` |
| `<Avatar alt="프로필 사진" … />` + 옆 이름 | 스크린리더가 같은 사람을 두 번 읽음 | `alt=""` |
| Figma에서 Avatar를 28로 늘림 | 정해진 크기 아님 | `Small`·`Large` 중 고름 |

## 9. 동기화 · 10. 알려진 문제

- 크기 추가가 필요하면 Figma `Size` → 이 문서 → `AVATAR_SIZES`·CSS 순서로.
- ⚑ 사진이 없을 때 이니셜 등 대체 모양은 아직 없음(회색 원). 필요해지면 추가.
