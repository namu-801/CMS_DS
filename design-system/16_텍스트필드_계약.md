# TextField 계약 (Contract)

이 문서는 디자인(Figma)과 코드가 함께 지켜야 하는 TextField(한 줄 입력창) 사용 규칙입니다. 사람과 AI 모두 이 문서를 기준으로 쓰고 검사합니다.

- 기준일: 2026-10-17
- 근거: Figma `TextField` 세트, 코드 `src/components/TextField/`, 조사 `14_텍스트필드_조사.md`, 스펙 결정 `15_텍스트필드_스펙안.md`, 토큰 `04_이름규칙.md`
- 상태: Figma 48개 Variant 완료, 코드 구현 완료(타입 검사·테스트 통과, 브라우저에서 상태 색 확인)
- 입력칸 안 버튼은 `IconButton`(`13_아이콘버튼_계약.md`), 입력칸 옆 글자 버튼은 `Button`(`10_버튼_계약.md`)이 맡습니다.
- ⚑는 확정되지 않았거나 알려진 문제입니다. 10절에 모아 두었습니다.

**핵심 원칙:** 크기에 따라 바뀌는 것(높이·여백·칸 안 글자)과 크기와 상관없이 같은 것(색·상태 표현·제목·문구·아이콘 24)을 나눕니다. 입력칸은 항상 제목(이름)을 가집니다. 화면에 안 보여도 코드에는 있습니다.

## 2. 속성과 넣을 수 있는 값

### 2-1. Figma Component property

| 속성 | 타입 | 넣을 수 있는 값 | 기본값 |
|---|---|---|---|
| `Size` | Variant | `XSmall`(32), `Small`(40), `Medium`(48), `Large`(52) | `Small` |
| `State` | Variant | `Default`, `Hover`, `Focus`, `Error`, `Success`, `Disabled` | `Default` |
| `Value` | Variant | `Empty`(안내 문구), `Filled`(입력값) | `Empty` |
| `Text` | Text | 칸 안 글자(안내 문구 또는 입력값) | `안내 문구` |
| `Label` | Boolean | 켬 / 끔 (칸 위 제목) | 끔 |
| `Label Text` | Text | 제목 글자 | `제목` |
| `Required` | Boolean | 켬 / 끔 (제목 옆 `(필수)`) | 끔 |
| `Message` | Boolean | 켬 / 끔 (칸 아래 문구) | 끔 |
| `Message Text` | Text | 문구 글자. 색은 `State`를 따름 | `안내 문구` |
| `Leading Icon` | Boolean | 켬 / 끔 (칸 앞 아이콘, 누르지 않음) | 끔 |
| `Leading Icon Swap` | Instance swap | `Icon/*` 24. 추천 `Search` | `Icon/Action/Search` |
| `Trailing Icon` | Boolean | 켬 / 끔 (칸 뒤 누르는 아이콘) | 끔 |
| `Trailing Icon Swap` | Instance swap | `Icon/*` 24. 추천 `VisibilityOff`, `Visibility` | `Icon/Action/VisibilityOff` |

- `Text` 기본 글자는 세트 전체가 공유합니다. `Value=Filled`로 바꾸면 글자색만 진해지므로 입력값 글자를 직접 적어 넣습니다.

### 2-2. 코드 Prop

```ts
type TextFieldSize = "xsmall" | "small" | "medium" | "large";
type TextFieldStatus = "error" | "success";
type TextFieldType = "text" | "email" | "password" | "search" | "tel" | "url";

interface TextFieldTrailingAction {
  icon: IconName;          // 등록된 아이콘 이름
  label: string;           // 버튼 이름(필수)
  onClick: () => void;
}

interface TextFieldProps /* + 네이티브 <input> 속성(size, style, children, type, disabled, required, aria-invalid, aria-describedby, aria-required 제외) */ {
  label: string;                         // 필수. 제목 = 입력칸 이름
  hideLabel?: boolean;                   // 기본 false. 화면에서만 숨김
  required?: boolean;                    // 기본 false
  size?: TextFieldSize;                  // 기본 "small"
  status?: TextFieldStatus;              // 없음 = 기본
  message?: string;                      // 칸 아래 문구
  disabled?: boolean;                    // 기본 false
  leadingIcon?: IconName;                // 칸 앞 아이콘(24)
  trailingAction?: TextFieldTrailingAction; // 칸 뒤 IconButton(Plain 24)
  type?: TextFieldType;                  // 기본 "text"
  className?: string;                    // 배치(margin, grid 위치, 너비)용만
  // value, defaultValue, onChange, placeholder, name, autoComplete 등은 네이티브 그대로
}
```

`ref`는 안쪽 `<input>`으로 전달됩니다. `id`를 주지 않으면 자동으로 만들어 제목과 연결합니다.

| Prop | 넣을 수 있는 값 | 기본값 | 그 밖의 값을 넣으면 |
|---|---|---|---|
| `label` | 제목 글자 | 없음(필수) | 빠뜨리면 컴파일 오류 |
| `size` | `"xsmall"`, `"small"`, `"medium"`, `"large"` | `"small"` | 컴파일 오류(네이티브 `size={20}` 같은 숫자도 오류) |
| `status` | `"error"`, `"success"` | 없음 | 컴파일 오류(`"warning"` 등) |
| `type` | `"text"`, `"email"`, `"password"`, `"search"`, `"tel"`, `"url"` | `"text"` | 컴파일 오류(`"number"`, `"date"` 등) |
| `leadingIcon` | 등록된 아이콘 32종(`13_아이콘버튼_계약.md` 2-2) | 없음 | 컴파일 오류 |
| `trailingAction` | `{ icon, label, onClick }` 셋 다 필요 | 없음 | 하나라도 빠지면 컴파일 오류 |
| `hideLabel`, `required`, `disabled` | `true` / `false` | `false` | — |
| `style` | 받지 않음 | — | 컴파일 오류 |

## 3. Figma 속성 ↔ 코드 Prop 대응표

| Figma | 코드 | 대응 | 값 대응 |
|---|---|---|---|
| `Size` | `size` | 1:1 | `XSmall`→`"xsmall"`, `Small`→`"small"`, `Medium`→`"medium"`, `Large`→`"large"` |
| `State=Default` | (없음) | 상태 → 없음 | 아무것도 안 주면 Default |
| `State=Hover` | CSS `:hover` | 상태 → 브라우저 | Prop 없음 |
| `State=Focus` | CSS `:focus-within` | 상태 → 브라우저 | Prop 없음 |
| `State=Error` | `status` | 상태 → Prop | `status="error"` |
| `State=Success` | `status` | 상태 → Prop | `status="success"` |
| `State=Disabled` | `disabled` | 상태 → Boolean | `disabled` |
| `Value=Empty` / `Filled` | (없음) | 내용 → 자동 | 칸에 글자가 있으면 Filled 모양 |
| `Text` | `placeholder` 또는 `value`·`defaultValue` | 1 → 2 | Empty일 때 글자 → `placeholder`, Filled일 때 글자 → `value` |
| `Label` | `hideLabel` | 뜻이 반대 | `Label` 켬 → `hideLabel` 안 줌, `Label` 끔 → `hideLabel` |
| `Label Text` | `label` | 1:1(코드는 필수) | `제목` → `label="제목"` |
| `Required` | `required` | 1:1 | 켬 → `required` |
| `Message` + `Message Text` | `message` | 2 → 1 | 켬 + 글자 → `message="글자"`, 끔 → 안 줌 |
| `Leading Icon` + `Leading Icon Swap` | `leadingIcon` | 2 → 1 | 켬 + `Icon/Action/Search` → `leadingIcon="action_search"` |
| `Trailing Icon` + `Trailing Icon Swap` | `trailingAction` | 2 → 1(코드는 이름·동작 추가) | 켬 + `Icon/Action/VisibilityOff` → `trailingAction={{ icon: "action_visibility_off", label: "비밀번호 보기", onClick }}` |
| (없음) | `type` | 코드에만 | 입력 종류 |
| (없음) | `id`, `name`, `autoComplete`, `onChange` 등 | 코드에만 | 동작 정의 |

### 3-1. 일대일이 아닌 이유

1. **Hover·Focus는 Prop이 아닙니다.** 사용자가 마우스를 올리거나 입력칸을 누를 때 브라우저가 정하는 상태입니다. Figma는 화면 설계서에 모양을 보여 주려고 Variant로 둡니다(Button·IconButton과 같음).
2. **Error·Success는 `status` 하나로 묶었습니다.** 오류이면서 성공일 수는 없으므로, Boolean 두 개가 아니라 값 하나로 받아야 잘못된 조합이 생기지 않습니다. Disabled는 다른 상태와 겹칠 수 있어(예: 오류 칸을 잠시 막음) 따로 둡니다.
3. **Value(비어 있음/입력됨)는 Prop이 없습니다.** 코드에서는 칸에 실제로 글자가 있는지로 정해집니다. Figma는 두 모양을 보여 주려고 Variant로 둡니다.
4. **Text 하나가 코드에서는 둘입니다.** 비어 있을 때 보이는 안내 문구는 `placeholder`, 사용자가 쓴 글자는 `value`로 성격이 다릅니다.
5. **제목은 코드에서 항상 필요합니다.** Figma `Label`을 끄면 제목이 안 보이지만, 코드에서 제목이 없으면 스크린리더가 이 칸이 무엇인지 읽지 못합니다. 그래서 `label`은 필수로 받고, 화면에서 숨길 때만 `hideLabel`을 씁니다. 그래서 Figma `Label`과 `hideLabel`은 뜻이 반대입니다.
6. **켜고 끄기 + 글자/아이콘 두 속성이 코드에서는 하나입니다.** Figma는 Boolean과 내용을 따로 두지만, 코드에서는 값을 주면 켜지고 안 주면 꺼집니다.
7. **뒤 아이콘은 코드에서 버튼입니다.** Figma에는 아이콘 모양만 있지만, 코드에서는 누를 수 있어야 하므로 버튼 이름(`label`)과 동작(`onClick`)이 필수입니다. 모양은 IconButton Plain 24로 고정이라 Style·Size를 고르는 Prop은 없습니다.
8. **`type`은 코드에만 있습니다.** 이메일·비밀번호처럼 키보드와 자동 완성이 달라지는 동작이라 모양과 상관없습니다. 한 줄 입력창에 맞는 6종만 허용합니다.

## 4. 시안 쓰임별 정답 조합

새 화면도 이 표의 조합을 그대로 씁니다. 표에 없는 쓰임이 생기면 가장 가까운 줄을 따르고, 스펙 문서에 줄을 추가합니다.

| 쓰임 | Size | 제목 | 그 밖 | 코드 |
|---|---|---|---|---|
| 로그인 이메일 | Large | 숨김(`Label` 끔) | 안내 문구 `이메일` | `size="large" label="이메일" hideLabel type="email" autoComplete="email"` |
| 로그인 비밀번호 | Large | 숨김 | 뒤 아이콘 `VisibilityOff`/`Visibility` | `type="password"` + `trailingAction`(상태에 따라 아이콘·이름 교체) |
| 회원가입 각 칸 | Large | 보임, 필요하면 `Required` | 안내·오류·성공 문구 | `label="이름" required message=…` |
| 회원가입 비밀번호 확인 | Large | 숨김(비밀번호 제목 아래에 붙음) | 뒤 아이콘 | `label="비밀번호 확인" hideLabel` |
| 회원가입 이메일 + 중복확인 | Large | 보임 | 옆에 Button `Large` | 두 컴포넌트를 나란히 |
| 차량 검색 | Medium | 숨김 | 앞 아이콘 `Search` | `size="medium" type="search" hideLabel leadingIcon="action_search"` |
| 콘텐츠 업로드 제목 등 | Small | 숨김. 화면 왼쪽 제목은 **화면에서 배치**(컴포넌트 옵션 아님) | — | `<span aria-hidden>제목</span>` + `<TextField size="small" label="제목" hideLabel />` |
| 시간 입력(잠김) | Small | — | `Disabled` | `disabled` |
| GPS 위치명 고치기 | XSmall | 숨김 | 칸 210 · 8 · 확인 24 · 8 · 취소 24, 높이 32 | Figma `gps_textfield`. 코드: TextField `xsmall` + IconButton Outline 24 두 개 |

## 5. 사용 규칙

1. 높이는 `Size`로만 고릅니다. 인스턴스 높이를 직접 늘리거나 줄이지 않습니다. 너비는 자유롭게 바꿉니다(Fill 권장).
2. 입력칸 옆에 버튼을 붙일 때는 같은 이름의 크기를 씁니다(TextField `Large` + Button `Large`, 둘 다 52).
3. 제목이 화면에 없어도 Figma 레이어 이름 또는 `Label Text`에 칸의 뜻을 적어 둡니다. 코드에서는 이 글자가 `label`이 됩니다.
4. 안내 문구(placeholder)에 꼭 필요한 정보(형식 규칙 등)만 넣지 않습니다. 입력을 시작하면 사라지므로 규칙은 아래 문구(`Message`)에 둡니다.
5. 오류 문구는 무엇이 틀렸고 어떻게 고치는지 적습니다(예: "영문, 특수문자, 숫자를 섞어 8~12자로 써 주세요").
6. 뒤 아이콘은 누르는 기능이 있을 때만 켭니다(비밀번호 보기). 장식용 아이콘은 앞 아이콘에 둡니다.
7. 아이콘은 24 한 크기만 씁니다. 작은 입력칸에 작은 아이콘이 꼭 필요해지면 그때 아이콘을 추가합니다(15 스펙안 7절).
8. 화면 시안에는 `Default`, `Focus`(설명이 필요할 때), `Error`, `Success`, `Disabled`를 씁니다. `Hover`는 상호작용 설명용 프레임에만 씁니다.
9. 여러 줄 입력, 숫자 조절, 날짜·드롭다운 고르기는 TextField로 만들지 않습니다(다른 컴포넌트).
10. 제목을 칸 왼쪽에 두는 화면(콘텐츠 업로드)은 컴포넌트 옵션이 아니라 화면에서 배치합니다. TextField는 `Label`을 끄고, 왼쪽 제목은 화면의 일반 글자로 둡니다. 코드에서는 그 글자에 `aria-hidden`, TextField `label`에 같은 글자를 넣습니다.

## 6. 제대로 썼는지 확인하는 방법

### 6-1. Figma

**눈으로 확인**
- [ ] 레이어 패널에서 입력칸이 `TextField` 인스턴스(◇)입니다. 이전 컴포넌트(1-1)가 아닙니다.
- [ ] 높이가 32·40·48·52 중 하나이고, 4절 표와 Size가 같습니다.
- [ ] 제목을 껐으면 `Label Text`나 레이어 이름에 칸의 뜻이 적혀 있습니다.
- [ ] 오류·성공 칸에는 `Message`가 켜져 있고 문구가 있습니다.
- [ ] 뒤 아이콘은 비밀번호 보기·숨기기처럼 누르는 기능이 있는 곳에만 켜져 있습니다.
- [ ] 인스턴스 메뉴의 "Reset all changes"를 눌러도 글자·아이콘·켜고 끄기 말고는 바뀌지 않습니다.

**스크립트로 확인(Figma 플러그인 API)**

```js
const TEXT_FIELD_SET_KEY = "3bacaf49170cda62bfa0bf99c0ef06970f5e4dba";
// 허용: 글자(속성), 켜고 끄기, 아이콘 교체, 레이어 이름, 너비
// 너비를 바꾸면 Figma가 height도 바뀐 것으로 기록하므로 허용하고, 실제 높이 변경은 아래 resized로 잡습니다.
const ALLOWED = new Set(["characters", "visible", "mainComponent", "name", "width", "height", "layoutSizingHorizontal", "layoutGrow", "componentProperties"]);
const problems = [], noMessage = [], resized = [];
for (const inst of figma.currentPage.findAllWithCriteria({ types: ["INSTANCE"] })) {
  const main = await inst.getMainComponentAsync();
  if (main?.parent?.type !== "COMPONENT_SET" || main.parent.key !== TEXT_FIELD_SET_KEY) continue;
  for (const o of inst.overrides) {
    const bad = o.overriddenFields.filter(f => !ALLOWED.has(f));
    if (bad.length) problems.push(`${inst.name} (${inst.id}): ${bad.join(", ")}`);
  }
  const p = inst.componentProperties, v = inst.variantProperties;
  const msgKey = Object.keys(p).find(k => k.startsWith("Message#"));
  if ((v.State === "Error" || v.State === "Success") && !p[msgKey].value) noMessage.push(inst.id); // 오류·성공인데 문구 없음
  if (![32, 40, 48, 52].includes(Math.round(inst.findOne(n => n.name === "Field").height))) resized.push(inst.id); // 높이를 직접 바꿈
}
return { problems, noMessage, resized };
```

## 7. 예시

### 7-1. 정상 사용

**Figma**
- 로그인: `Large / Default / Empty`, `Text` `이메일`, `Label` 끔, 레이어 이름 `이메일`
- 회원가입 비밀번호 오류: `Large / Error / Filled`, `Label` 켬 `비밀번호`, `Required` 켬, `Message` 켬 `영문, 특수문자, 숫자 혼합 8~12자`, `Trailing Icon` 켬 `Visibility`
- 차량 검색: `Medium / Default / Empty`, `Leading Icon` 켬 `Search`, `Text` `차량번호, 운전자 검색하기`

**코드**

```tsx
import { TextField } from "@/components/TextField";

<TextField size="large" label="이메일" hideLabel type="email" autoComplete="email" placeholder="이메일" />

<TextField
  size="large"
  label="비밀번호"
  required
  type={visible ? "text" : "password"}
  autoComplete="new-password"
  status={pwError ? "error" : undefined}
  message={pwError ?? "영문, 특수문자, 숫자 혼합 8~12자"}
  trailingAction={{
    icon: visible ? "action_visibility" : "action_visibility_off",
    label: visible ? "비밀번호 숨기기" : "비밀번호 보기",
    onClick: () => setVisible((v) => !v),
  }}
/>

<TextField size="medium" label="차량 검색" hideLabel type="search" leadingIcon="action_search" placeholder="차량번호, 운전자 검색하기" />

<TextField size="small" label="시작 시간" disabled value="00 : 00 : 00" readOnly />
```

### 7-2. 시스템을 우회하는 반례

| 반례 | 왜 문제인지 | 바르게 |
|---|---|---|
| Figma: 이전 `textInput-M/Empty`를 그대로 씀 | 토큰이 연결돼 있지 않고 테두리 대비가 1.45로 부족함 | `TextField` `Large` |
| Figma: 인스턴스 높이를 44로 늘림 | 코드에 없는 높이라 구현과 달라짐 | `Size`에서 48 또는 52 |
| Figma: 테두리 색을 직접 칠해 오류 표시 | 문구 색·코드 상태와 연결이 끊김 | `State=Error` + `Message` |
| Figma: 장식용 아이콘을 뒤 아이콘에 넣음 | 개발자가 누르는 버튼으로 구현함 | 앞 아이콘(`Leading Icon`)에 둠 |
| 코드: `<input className="border …" />` | 상태 색·제목 연결·문구 연결이 없음 | `<TextField label=… />` |
| 코드: `<TextField label="" placeholder="이메일" />` | 이름이 빈 칸이라 스크린리더가 무엇인지 모름 | `label="이메일" hideLabel` |
| 코드: 형식 규칙을 `placeholder`에만 적음 | 입력을 시작하면 규칙이 사라짐 | 규칙은 `message`에 |
| 코드: 오류일 때 `message`만 빨갛게 바꾸고 `status`는 안 줌 | 테두리가 안 바뀌고 `aria-invalid`도 없음 | `status="error"` + `message` |
| 코드: 비밀번호 보기 버튼을 `<Icon onClick>`으로 직접 만듦 | 키보드로 못 누르고 이름이 없음 | `trailingAction={{ icon, label, onClick }}` |
| 코드: 같은 `label`로 아이콘만 바꿔 토글 | 스크린리더가 지금 상태를 모름 | 상태에 따라 `label`도 바꿈 |
| 코드: `<TextField type="number" />` | 컴파일 오류. 한 줄 글자 입력이 아님 | 숫자 조절은 다른 컴포넌트 |

### 8-1. 필수
