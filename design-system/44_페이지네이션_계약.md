# Pagination 계약 (Contract)

표 아래에서 페이지를 넘기는 컨트롤의 사용 규칙입니다.

- 기준일: 2026-10-27
- 근거: Figma `Pagination`·`Pagination Item`, 코드 `src/components/Pagination/`, 조사 `29_페이지네이션_조사.md`, 스펙 `30_페이지네이션_스펙안.md`(5~7절), 대응표 `39_코드구현_대응표.md`
- 상태: Figma 완료, 코드 구현 완료

**핵심 원칙:** 번호는 최대 5개, 넘으면 처음·끝 번호와 "…". 첫·마지막 페이지에서 이전·다음은 비활성. 이전·다음은 `Button` Plain을 그대로 씁니다.

## 2. 속성과 넣을 수 있는 값

| Figma | 속성 | 값 | 기본값 |
|---|---|---|---|
| `Pagination Item` | `State` | `Default`, `Hover`, `Selected` | `Default` |
| | `Number` | 번호 글자 | `1` |
| `Pagination` | (속성 없음) | 번호 칸을 켜고 끄고, 이전·다음 `Button`의 `State`를 바꿈 | 1 선택, "이전" 비활성 |

```ts
interface PaginationProps {
  page: number;                        // 지금 페이지(1부터)
  totalPages: number;
  onPageChange: (page: number) => void;
  label?: string;                      // 기본 "페이지 이동"
  className?: string;
}
// pageItems(page, total) → 보여 줄 번호와 "ellipsis-start"/"ellipsis-end"
```

| 항목 | 값 | 토큰 |
|---|---|---|
| 번호 칸 높이 · 최소 너비 | 40 · 40(숫자가 길면 늘어남) | `Size/Height/ControlSmall` |
| 번호 좌우 여백 | 12 | `Spacing/Scale/12` |
| 번호 글자 | `14/Medium`, 지금 페이지 `14/SemiBold` | Text Style |
| 부품 사이 | 8 | `Spacing/Scale/8` |
| 이전·다음 | `Button` Plain Small + `arrow_left`·`arrow_right` | 버튼 계약 |

| `State` | 배경 | 글자 |
|---|---|---|
| `Default` | 없음 | `Foreground/Neutral/Quaternary` `#767676` |
| `Hover` | `Interaction/Brand/SubtleHover` `#F3F3FF`(테두리 없음) | `Foreground/Neutral/Tertiary` `#494949` |
| `Selected` | `Surface/Brand/Strong` `#5D5FEF` | `Foreground/Neutral/Inverse` 흰색 |

## 3. Figma 속성 ↔ 코드 Prop 대응표

| Figma | 코드 | 대응 |
|---|---|---|
| `Pagination Item` `State=Selected` | `page`와 같은 번호(`aria-current="page"`) | 상태 → 값 |
| `State=Hover` | CSS `:hover` | 상태 → 브라우저 |
| `Number` · 번호 칸 켜고 끄기 | `pageItems(page, totalPages)`로 계산 | 계산 |
| 이전·다음 `Button` `State=Disabled` | 첫·마지막 페이지에서 자동 | 계산 |
| (없음) | `totalPages`, `onPageChange`, `label` | 코드에만 |

**일대일이 아닌 이유:** 어떤 번호를 보일지, 이전·다음을 막을지는 페이지 수로 정해지는 계산이라 코드가 맡습니다. Figma는 몇 가지 모습을 그려 보여 주는 용도입니다.

## 4. 정답 조합 · 5. 사용 규칙

| 쓰임 | Figma | 코드 |
|---|---|---|
| 표 아래 가운데(차량·콘텐츠·그룹 목록) | `Pagination`, 지금 번호 `Selected` | `<Pagination page={p} totalPages={n} onPageChange={setP} />` |

1. 표 아래에만 씁니다. 페이지가 1개면 그리지 않습니다(화면 판단).
2. 번호 칸 색을 바꾸지 않습니다. 이전·다음은 다른 버튼 Style로 바꾸지 않습니다.
3. "…" 칸은 누를 수 없습니다.

## 6. 제대로 썼는지 확인하는 방법

- Figma: 이전 `Pagenation`이 아닌지, `Selected`가 하나인지, 첫 페이지에서 "이전"이 `Disabled`인지.
- 코드: `npm run typecheck`(필수값 누락·숫자 아닌 페이지 컴파일 오류), `npm test`(번호 계산 4가지, `aria-current`, 첫·마지막 비활성, 지금 페이지 다시 누르면 무시).
- 손으로: Tab으로 이전 → 번호 → 다음 순서로 이동, 스크린리더가 "페이지 이동 탐색, 1페이지 현재 페이지"를 읽음.

## 7. 예시

```tsx
<Pagination page={page} totalPages={20} onPageChange={setPage} />   // 1 … 9 10 11 … 20
```

| 반례 | 왜 문제인지 | 바르게 |
|---|---|---|
| 번호를 버튼 여러 개로 직접 | 현재 페이지 표시·비활성 규칙 빠짐 | `<Pagination>` |
| 첫 페이지에서 "이전"을 숨김 | 위치가 흔들림(결정 C) | 비활성 |
| 번호 20개를 모두 나열 | 결정 D(최대 5개) 위반 | 자동 줄임 |
